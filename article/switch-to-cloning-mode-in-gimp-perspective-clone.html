Switch to Cloning Mode in GIMP Perspective Clone

The GIMP Perspective Clone tool allows you to replicate areas of an image while respecting perspective angles and vanishing points. Utilizing this tool requires a two-step process: mapping the perspective plane and executing the clone stamp. This guide details the exact steps to switch from the perspective plane definition mode to the active cloning mode using GIMP's interface settings.

1. Access the Tool Options Dialog

Ensure the Tool Options dock is visible. If it is not on your screen:

  • Double-click the Perspective Clone Tool icon in the main Toolbox.
  • Alternatively, navigate to the top menu and select Windows > Dockable Dialogs > Tool Options.

2. Locate the Mode Settings

Look at the top section of the Perspective Clone's Tool Options panel. You will see two radio button choices under the tool header:

  • Modify Perspective: The default mode, which displays a rectangular grid with corner handles allowing you to align the plane to your image's perspective.
  • Perspective Clone: The operational mode that applies the clone stamp along the defined plane.

3. Switch to Cloning Mode

Click the radio button labeled Perspective Clone.

Once selected, the perspective handles on your canvas will lock into place, and your cursor will transform into the standard clone brush cursor.

4. Set the Source and Paint

With Perspective Clone mode active:

  1. Hold down the Ctrl key (or Cmd on macOS) and click on the area of the canvas you wish to sample.
  2. Release the key, move your cursor to the destination area within the perspective boundaries, and click and drag to paint.

To readjust your perspective plane at any point, simply click back on the Modify Perspective radio button in the Tool Options dock to reveal the corner handles again.

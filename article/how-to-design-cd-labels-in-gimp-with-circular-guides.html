How to Design CD Labels in GIMP with Circular Guides

Designing custom printable CD label art requires precise dimensions and clear alignment boundaries to ensure your artwork prints accurately without critical elements being cut off by the outer edge or center hole. This guide explains how to set up a high-resolution square canvas in GIMP, generate exact circular boundary guides for standard and full-face discs, organize your design within safe printing zones, and export the final file ready for printing.

1. Set Up the Canvas Dimensions and Resolution

  1. Open GIMP and navigate to File > New.
  2. Set the Template or change the unit dropdown from pixels (px) to millimeters (mm).
  3. Enter 120 mm for Width and 120 mm for Height (standard CD dimension). If your label paper includes extra bleed, you can increase this to 125 mm or 130 mm.
  4. Click Advanced Options and set both the X resolution and Y resolution to 300 pixels/in (DPI) for high-quality printing.
  5. Set Color space to RGB color and Fill with to White or Transparency, then click OK.

2. Establish Center Guides

  1. Go to Image > Guides > New Guide by Percent.
  2. Select Horizontal, set the position to 50%, and click OK.
  3. Go back to Image > Guides > New Guide by Percent, select Vertical, set the position to 50%, and click OK.
  4. You now have an exact intersection at the center of the canvas.

3. Create Circular Boundary Guides

To accurately visualize the printable area, create path-based circular guides for the outer edge, inner hole, and safety margins.

Create the Outer Boundary (118 mm to 120 mm)

  1. Select the Ellipse Select Tool (E).
  2. In the Tool Options dock on the left, check Expand from center and Fixed: Size.
  3. Set the fixed size to 118mm x 118mm (standard outer printable boundary) or 1400px x 1400px at 300 DPI.
  4. Click directly on the center guide intersection.
  5. Go to Select > To Path. This saves the circular boundary as a reusable vector guide in your Paths dock.

Create the Inner Hole Boundary (15 mm to 40 mm)

  1. Determine if your media is standard (approx. 40 mm hole) or hub-printable (approx. 15–20 mm hole).
  2. With the Ellipse Select Tool active, change the Fixed: Size in the Tool Options to 40mm x 40mm (or 20mm x 20mm for full-face printable discs).
  3. Click the center intersection.
  4. Go to Select > To Path.
  5. Go to Select > None (Ctrl + Shift + A) to clear the active selection.

View the Circular Guides

  1. Open the Paths panel (Windows > Dockable Dialogs > Paths).
  2. Click the eye icon next to your created paths to make the circular outlines visible on your canvas at all times.

4. Add Design Layers and Safe Zones

  1. Go to the Layers panel and create a new layer for your background art.
  2. Extend background images, patterns, and colors completely across the canvas to account for print bleed.
  3. Keep all essential elements (titles, tracklists, logos) at least 2–3 mm inside the outer path and 2–3 mm outside the inner hole path to prevent them from being cut off during alignment shifts.
  4. Use the Text Tool (T) to add disc details, arranging them around the central circular guide.

5. Export for Printing

  1. Ensure the paths are purely vector guides on your screen and not drawn onto the artwork layer itself.
  2. If you created any dedicated reference/template layers with colored borders, hide or delete them before exporting.
  3. Navigate to File > Export As....
  4. Choose a high-quality format such as PNG, TIFF, or PDF.
  5. When printing, configure your printer software to print at 100% Scale (Actual Size) without page scaling or "Fit to Page" enabled.

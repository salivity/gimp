How to Adjust Brush Spacing in GIMP for Smooth Lines

When drawing rapid strokes in GIMP, brushes often produce broken, dotted, or segmented lines instead of a single fluid mark. This happens because digital brushes operate by depositing repeated stamps along your stroke path; if the distance between these stamps is too wide, fast hand movements outpace the brush engine and leave visible gaps. By lowering the brush spacing parameter in the tool settings, you force the stamps to overlap tightly, creating clean, continuous, and gap-free lines regardless of your drawing speed.

Accessing the Brush Spacing Setting

To modify spacing for your active drawing session:

  1. Select your preferred drawing tool from the Toolbox, such as the Paintbrush Tool (P), Pencil Tool (N), or Airbrush Tool (A).
  2. Open the Tool Options dock. If this panel is not visible, navigate to the top menu and select Windows > Dockable Dialogs > Tool Options.
  3. Scroll down the panel until you locate the Spacing slider, positioned beneath the Brush selector and Size settings.

Setting the Optimal Spacing Value

By default, many GIMP brushes use a spacing value between 10.0 and 20.0. While this conserves processing power, it causes gaps during swift hand movements.

  • For Inking and Sketching: Drag the Spacing slider down to a value between 1.0 and 5.0. A value around 2.0 to 3.0 generally provides completely gap-free lines while maintaining optimal responsiveness.
  • Direct Input: Click directly on the numerical value next to the slider, type 2.0, and press Enter for precise configuration.

Test your stroke on the canvas by making rapid zigzag or circular motions. If gaps or scalloped edges are still noticeable, reduce the value closer to 1.0.

Permanently Modifying Brush Defaults

If you want a specific brush preset to always load with low spacing:

  1. Open the Brushes dialog via Windows > Dockable Dialogs > Brushes.
  2. Select the brush you want to edit. If it is a built-in brush, click the Duplicate Brush icon at the bottom of the dialog, as system brushes cannot be overwritten directly.
  3. Double-click your duplicated brush to open the Brush Editor.
  4. Adjust the Spacing slider to your preferred low setting (e.g., 2.0). The brush will now automatically retain this value whenever selected.

Balancing Spacing with Performance

Extremely low spacing (such as 1.0) forces the application to render significantly more dabs per second. While this guarantees continuous lines, using a 1.0 spacing setting on an exceptionally large brush (over 500 pixels) can cause input lag or brush latency on some hardware. If you experience performance drops, increase the spacing slightly until you find the highest value that still yields a completely seamless line at your fastest drawing speed.

Tint Images Without Changing Luminance in GIMP

Tinting an image without distorting its underlying brightness is essential for maintaining natural contrast, depth, and detail. By using the Color (LCH) blend mode in GIMP, you can replace or modify the hue and chroma of an image while locking in its perceptual luminance. This guide explains how the LCH model works and outlines the step-by-step process to apply a clean color tint to any photograph without altering its tonal structure.

Why Use Color (LCH) Instead of Standard Color

Standard blending modes often rely on the HSV (Hue, Saturation, Value) or HSL (Hue, Saturation, Lightness) models. In these spaces, changing a color to pure yellow artificially increases perceived brightness, while changing it to pure blue makes the area appear significantly darker.

GIMP’s Color (LCH) mode is based on the CIE LCH color space, which separates:

  • L (Lightness): Perceptual luminance matched to human vision.
  • C (Chroma): Purity or saturation of the color.
  • H (Hue): The actual color shade.

When set to Color (LCH), a layer transfers both its Hue and Chroma to the layer below while completely ignoring the top layer’s brightness. The bottom layer's perceived luminance remains 100% intact.

Step-by-Step: Tinting an Image with Color (LCH)

1. Open Your Base Image

Launch GIMP and open the image you want to tint via File > Open.

2. Add a New Tint Layer

  1. In the Layers panel on the right, click the Create a new layer button (or press Shift + Ctrl + N).
  2. Name the layer something descriptive, such as "Color Tint".
  3. Set the Fill with option to Transparency and click OK.

3. Choose Your Tint Color

  1. Select the Foreground Color swatch in the toolbox.
  2. Pick the color you want to use for the tint and click OK.
  3. Select the Bucket Fill Tool (Shift + B) and click inside the canvas to flood-fill the new layer with your chosen color. Alternatively, you can use the Gradient Tool (G) or a soft Paintbrush (P) if you want selective or multi-tone tinting.

4. Change the Blend Mode to Color (LCH)

  1. Ensure your tint layer is selected in the Layers panel.
  2. Click the Mode dropdown menu located at the top of the Layers panel (it defaults to "Normal").
  3. Scroll down to the LCh category.
  4. Select Color (LCH).

Your image will immediately reflect the new color tone, but all highlights, shadows, and midtones will retain their exact original visual weights.

5. Adjust the Tint Intensity

Because solid colors can sometimes look overly stylized, you can fine-tune the result:

  • Opacity Slider: Lower the tint layer's opacity (e.g., between 20% and 50%) to blend the new color subtly over the image's original colors.
  • Layer Masks: Add a layer mask (Right-click layer > Add Layer Mask) to paint away the tint from specific subjects, such as skin tones or backgrounds.

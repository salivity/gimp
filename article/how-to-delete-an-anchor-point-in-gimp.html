How to Delete an Anchor Point in GIMP

Deleting unnecessary anchor points in GIMP allows you to refine vector paths, smooth out curves, and correct drafting mistakes without redrawing an entire shape. This guide explains the exact keyboard modifier required to remove an unwanted anchor point from a path, how the tool responds visually, and step-by-step instructions for managing path nodes efficiently using the Paths tool.

The Keyboard Modifier to Delete Anchor Points

To delete an unwanted anchor point from a path in GIMP, the required keyboard modifier combination is Ctrl + Shift on Windows and Linux, or Cmd + Shift on macOS.

When you hold down these keys while using the Paths tool and hover over an existing anchor point, the cursor changes to indicate deletion mode (typically showing a minus sign or an anchor next to a minus symbol). Clicking the point while holding this modifier immediately removes it from the path.

Step-by-Step Instructions

  1. Activate the Paths Tool: Select the Paths tool from the Toolbox or press the shortcut key B.
  2. Select Your Path: Open the Paths dialog (dockable dialog) and click on the path you want to modify to make it active and visible.
  3. Set Mode to Design: In the Tool Options dock, ensure the mode is set to Design (this is the default mode).
  4. Locate the Anchor Point: Move your mouse cursor directly over the anchor point (node) you wish to remove.
  5. Apply the Modifier and Click: Hold down Ctrl + Shift (or Cmd + Shift on Mac). You will see the cursor transform into a deletion indicator. Left-click the anchor point.

The selected anchor point will instantly disappear, and GIMP will automatically reconnect the adjacent anchor points with a direct segment, preserving the continuity of your path.

Additional Path Editing Modifiers

  • Delete a Segment: Hold Shift alone and click on the line segment connecting two anchor points to remove the connection without deleting the points themselves.
  • Add a Point to an Existing Segment: Hold Ctrl and click anywhere on an existing line segment to insert a new anchor point.
  • Close an Open Path: Hold Ctrl and click the starting anchor point to connect the end of the path back to the beginning.

How to Configure Brush Jitter in GIMP

Configuring dynamic brush jitter in GIMP allows you to scatter brush strokes randomly across a canvas to create natural effects like foliage, stars, dust, or texture. This guide details how to enable basic brush jitter using built-in tool options, as well as how to build custom paint dynamics to control scattering based on pressure, speed, or true randomness.

Method 1: Using the Built-In Brush Jitter Setting

The fastest way to scatter brush marks is through the Paintbrush tool's native options.

  1. Select the Paintbrush tool from the Toolbox (shortcut: P).
  2. Look at the Tool Options panel (typically docked on the left).
  3. Scroll down to locate the Apply Jitter checkbox.
  4. Check the Apply Jitter box to enable scattering.
  5. Adjust the Amount slider directly below it:
    • Low values (0.10 to 1.00): Produce subtle, tight dispersion.
    • High values (2.00 to 5.00+): Scatter brush stamps widely across the canvas area.

Method 2: Creating a Custom Scatter Dynamic

For advanced scattering that responds to tablet pressure, stroke speed, or complete randomization across multiple properties (such as size and angle alongside jitter), create a custom Paint Dynamic.

Step 1: Open the Paint Dynamics Panel

  1. Go to the top menu and select Windows > Dockable Dialogs > Paint Dynamics.
  2. Click the Create a new dynamics button (the page icon at the bottom of the panel).

Step 2: Configure the Dynamic Matrix

In the Paint Dynamics Editor that opens:

  1. Locate the Jitter column in the matrix.
  2. Check the box under the Random row for the Jitter column to scatter stamps randomly along the stroke.
  3. (Optional) Check the Pressure or Velocity boxes under Jitter if you want the dispersion to increase based on stylus pressure or drawing speed.
  4. (Optional) Check the Random box for Size and Angle to rotate and scale each scattered particle independently.

Step 3: Apply the Dynamic to Your Brush

  1. Return to the Tool Options panel for the Paintbrush.
  2. Click the Dynamics dropdown menu.
  3. Select your newly created dynamic preset from the list.
  4. Draw on the canvas to paint with dynamic scattering.

Tips for Optimizing Scattered Painting

  • Adjust Spacing: In the Tool Options or brush selector, increase the Spacing slider (e.g., 50% to 150%) so individual scattered marks do not overlap into a solid line.
  • Control Density with Opacity: Lower the base Opacity in the Tool Options to allow scattered particles to layer smoothly over one another.
  • Use Clipboard Brushes: Copy any custom shape or texture to your clipboard (Ctrl + C), and GIMP will automatically turn it into the first selectable brush in your brush palette, which can immediately be scattered using jitter.

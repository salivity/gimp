How to Create Multi-Page PDFs Using GIMP Layers

This article explains how the "Layers as pages" option in GIMP's PDF export dialog transforms individual image layers into sequential pages of a single PDF document. You will learn how the layer stack dictates the sequence of pages, how visibility and layer dimensions affect the final output, and the exact process to export your document cleanly.

How the Feature Works

When you export an image as a Portable Document Format (PDF) file in GIMP, enabling the Layers as pages option instructs GIMP to parse each individual layer in your project as a separate page, rather than flattening the entire layer stack into a single image. The export engine evaluates each layer sequentially, writing its raster data and dimensions into distinct page objects within the PDF file structure.

Page Sequencing and Layer Hierarchy

The order of pages in the exported PDF is directly determined by the visual hierarchy of your layers in the Layers panel:

  • Default Order: By default, GIMP reads the layer stack from top to bottom. The uppermost layer becomes Page 1, the layer beneath it becomes Page 2, and the bottom layer becomes the final page of the document.
  • Reverse Order: The export dialog includes a Reverse the pages order checkbox. Enabling this option inverts the sequence, making the bottom-most layer Page 1 and the top layer the final page. This is particularly useful if you build your document sequentially from bottom to top.

Layer Visibility and Sizing

GIMP’s PDF engine relies on specific layer attributes to generate each page:

  • Visibility: By default, the export dialog offers an option to apply pages only to visible layers. Hidden layers (those with the eye icon toggled off) can be excluded from the generated PDF entirely, allowing you to keep draft layers or reference materials in your .xcf file without having them appear in the final export.
  • Canvas and Layer Dimensions: Each page in the resulting PDF adopts the dimensions of the respective layer. If all layers match the overall canvas size, every page in the PDF will be uniform. If individual layers are smaller or larger than the canvas, each PDF page will scale to fit the bounding box of that specific layer, which can result in mixed page dimensions in the final document.

Steps to Export a Multi-Page PDF

  1. Arrange your content so that each page of your intended document exists as its own layer in the Layers panel.
  2. Ensure layer boundaries match your desired page dimensions by navigating to Layer > Layer to Canvas Size for each layer if uniform dimensions are required.
  3. Go to File > Export As....
  4. In the export window, type a filename ending in .pdf or select Portable Document Format (PDF) from the file type menu, then click Export.
  5. In the PDF Export dialog box, check the box labeled Layers as pages.
  6. Choose whether to check Reverse the pages order based on your preferred reading direction.
  7. Uncheck Omit hidden layers and layers with zero opacity if you intend to include every layer, or leave it checked to export visible pages only.
  8. Click Export to generate the multi-page PDF document.

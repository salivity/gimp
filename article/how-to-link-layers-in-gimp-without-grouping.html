How to Link Layers in GIMP Without Grouping

This guide explains how to use GIMP's built-in layer-linking feature to manipulate multiple layers simultaneously without placing them inside a layer group. By activating the chain icon beside specific layers, you can seamlessly move, scale, rotate, and transform them as a unified object while preserving your existing layer hierarchy and independent blend modes.

Step 1: Open the Layers Dialog

Ensure your Layers dialog is visible. If it is hidden, press Ctrl + L (or Cmd + L on macOS) or navigate to Windows > Dockable Dialogs > Layers in the top menu.

Step 2: Enable the Link Icon on Desired Layers

  1. Locate the layers you wish to transform together in the Layers list.
  2. Look at the empty space between the layer visibility icon (the eye) and the layer preview thumbnail.
  3. Click in this space on each layer you want to connect.
  4. A chain link icon will appear. Any layer displaying this visible chain icon is now part of the active transform set.

Step 3: Apply Your Transformations

With the layers linked, select any one of the linked layers and choose your desired transform tool from the Toolbox or via shortcut:

  • Move Tool (M): Dragging any linked layer on the canvas moves all other linked layers in unison, maintaining their relative positions. Note: Ensure the Move Tool options are set to "Pick a layer or guide" or "Move the active layer."
  • Scale Tool (Shift + S): Scaling one linked layer scales all linked layers proportionally across the canvas.
  • Rotate Tool (Shift + R): Rotating one layer pivots all linked layers around the shared center of rotation.
  • Unified Transform Tool (Shift + T): Applies simultaneous scaling, shearing, perspective changes, and rotation across all linked elements.

Step 4: Unlink the Layers

Once your adjustments are complete, click the chain icon on each layer to disable the link. This prevents accidental transformations later in your editing workflow.

Install Plugins with GIMP 3.0 Extension Manager

GIMP 3.0 introduces a dedicated Extension Manager that simplifies how users discover, install, and maintain third-party add-ons. Unlike older releases that required manual file extraction into obscure system directories, the new system handles packages formatted as GIMP Extensions (.gex) with minimal friction. This guide explains how to access the Extension Manager, install new extensions, and update or remove existing plugins directly within the application.

Accessing the Extension Manager

To open the management interface in GIMP 3.0:

  1. Launch GIMP 3.0.
  2. Navigate to the top menu bar and select Edit (or GIMP on macOS).
  3. Click on Manage Extensions to open the Extension Manager dialog window.

Installing Third-Party Plugins

The Extension Manager supports packaged .gex files, which bundle scripts, binaries, data, and metadata into a single archive.

  1. Download the Extension: Obtain a verified .gex extension package from a trusted developer or repository.
  2. Open the Extension Manager: Go to Edit > Manage Extensions.
  3. Import the Package: Click the Install from File... button (usually located in the lower or upper toolbar of the dialog).
  4. Select the File: Browse to your downloaded .gex file, select it, and click Open.
  5. Confirm Installation: GIMP will extract the required assets, verify dependencies, and register the new plugin. If prompted, restart GIMP to complete the initialization process.

Managing and Updating Extensions

Once installed, extensions appear in the main list inside the Extension Manager dialog. From this panel, you can control their operational state:

  • Enable or Disable: Use the toggle switch or checkbox next to any extension to temporarily deactivate it without deleting its files. This is useful for troubleshooting performance issues or plugin conflicts.
  • View Details: Select an extension to inspect its version, author, description, and the specific menu locations where its tools will appear.
  • Update Extensions: If an updated .gex package is available, install it using the same Install from File... method; the Extension Manager will overwrite the outdated files while preserving your settings.
  • Uninstall Extensions: Select the unwanted plugin from the list and click the Remove or Uninstall button. GIMP will cleanly remove all associated scripts and resources from your user profile.

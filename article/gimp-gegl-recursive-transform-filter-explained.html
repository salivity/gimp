GIMP GEGL Recursive Transform Filter Explained

The GEGL Recursive Transform filter in GIMP is a powerful distortion and pattern-generation tool designed to apply repetitive, iterative transformations to an image layer. By continually taking the result of a transformation and applying the same modification to it again, this filter allows graphic designers and digital artists to generate complex geometric fractals, infinite tunnel illusions, Droste effects, and seamless repetitive textures automatically without manual layering.

Understanding the Recursive Transform Filter

The fundamental purpose of the GEGL Recursive Transform tool is to automate iteration. In standard editing, creating a repeating pattern where each duplicate is smaller and slightly rotated requires manually duplicating layers, scaling, rotating, and repositioning them one by one. The Recursive Transform filter condenses this entire workflow into a single, interactive filter interface powered by GIMP's GEGL (Generic Graphical Library) engine.

How the Filter Operates

When applied, the filter captures the selected layer or region and applies a baseline transformation defined by the user—such as translation (moving), scaling (resizing), shearing, or rotation. Instead of stopping after one transformation, the filter feeds the transformed result back into itself for a designated number of iterations.

Key parameters that define the filter's behavior include:

  • Iterations: Controls the recursion depth, determining how many times the transformation repeats.
  • Transform Points / Matrix: Interactive on-canvas handles that allow you to skew, rotate, resize, and translate the transformation boundary visually.
  • Opacity and Fade: Adjusts the transparency across consecutive iterations, allowing distant recursive copies to fade out smoothly.
  • Paste Below/Above: Determines whether recursive copies are placed in front of or behind preceding iterations, altering the depth of the effect.

Primary Use Cases

  • Fractals and Mathematical Art: Creating intricate self-similar geometric patterns such as Sierpinski triangles, recursive spirals, and abstract shapes.
  • Droste and Mirror Tunnel Effects: Simulating the visual effect of standing between two mirrors or creating an image that recursively appears within itself.
  • Abstract Backgrounds: Transforming simple shapes or brushstrokes into intricate mandalas, floral geometric arrangements, or kaleidoscopic visuals.
  • Motion and Echo Effects: Producing stylized trailing echoes, zoom-blur simulations, and speed lines behind subjects.

Accessing the Tool in GIMP

To use this feature, open your project in GIMP, select the layer you wish to transform, and navigate to Filters > Map > Recursive Transform. You can then adjust the on-canvas bounding box and properties dialog to preview and apply the recursive patterns in real time.

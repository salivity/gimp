Create an Abstract Low-Poly Portrait in GIMP

Creating an abstract geometric low-poly portrait in GIMP involves converting a standard photographic portrait into a stylized mosaic of flat-colored polygons, typically triangles. This tutorial breaks down the essential process, from preparing your source image and mapping out the geometric grid to sampling colors and refining the final vector-like aesthetic.

Step 1: Prepare the Source Image

  1. Open GIMP and load your reference portrait via File > Open.
  2. Crop the image tightly around the face using the Crop Tool (Shift + C) to eliminate unnecessary background distractions.
  3. Enhance the contrast by going to Colors > Curves or Colors > Levels. Sharply defined highlights and shadows make it significantly easier to determine where the boundaries of your geometric shapes should go.

Step 2: Set Up Your Working Layers

  1. Open the Layers dialog (Ctrl + L).
  2. Right-click your image layer and select Duplicate Layer. Keep the original locked as a backup.
  3. Create a new transparent layer on top by clicking the New Layer icon. Name this layer "Low Poly".

Step 3: Map the Geometric Grid with the Free Select Tool

  1. Select the Free Select Tool (F) from the toolbox.
  2. In the Tool Options panel, ensure Antialiasing is checked and Feather edges is unchecked.
  3. Begin plotting triangles over distinct facial features:
    • Small Triangles: Use smaller shapes for complex, detailed areas like the eyes, nose, and lips.
    • Large Triangles: Use larger shapes for flatter areas like the forehead, cheeks, and neck.
  4. Ensure the vertices (corners) of neighboring triangles touch each other precisely to prevent transparent gaps in the final image.

Step 4: Fill Polygons with Average Color

For each drawn triangle, you must fill the selection with the average color of the underlying photograph:

  1. With a triangle selected, click on your photo layer in the Layers panel.
  2. Go to Filters > Blur > Pixelize or use Filters > Blur > Gaussian Blur with a high radius to blend the area within the selection into a single tone.
  3. Alternatively, select the Color Picker Tool (O), set Sample Average in the Tool Options, click inside the selection to pick the dominant color, select your "Low Poly" layer, and fill the selection using the Bucket Fill Tool (Shift + B).
  4. Repeat this process methodically across the entire face.

Step 5: Eliminate Seams and Gaps

  1. Zoom in closely (Z) to inspect the intersections of your polygons.
  2. If tiny background gaps or transparent lines appear between triangles, select the Smudge Tool or a small, hard-edged Paintbrush (P) to lightly patch the seams using the adjacent colors.
  3. Alternatively, slightly expand overlapping selections before filling by using Select > Grow by 1 pixel.

Step 6: Final Grading and Export

  1. Hide or delete the original reference photo layer once the entire portrait is covered.
  2. Add a new layer at the bottom of the stack to create a solid color or gradient background that complements your portrait.
  3. Select your low-poly layer and go to Colors > Color Temperature or Colors > Hue-Chroma to adjust the mood and vibrant tones of the portrait.
  4. Save your master file as an .XCF project, then export your final artwork via File > Export As in your preferred format (e.g., PNG or JPEG).

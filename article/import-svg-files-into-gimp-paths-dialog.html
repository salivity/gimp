Import SVG Files into GIMP Paths Dialog

Importing Scalable Vector Graphics (SVG) directly into GIMP's Paths dialog allows you to manipulate vector outlines, create precise selections, or stroke shapes without rasterizing the original vectors upon import. This guide explains the exact steps required to load an external SVG file directly into the Paths dialog of an active GIMP project.

Step 1: Open or Create a Canvas

Paths must exist within an active image document. Before importing:

  1. Launch GIMP.
  2. Open an existing project via File > Open or create a new blank canvas via File > New.

Step 2: Open the Paths Dialog

If the Paths dockable dialog is not already visible in your workspace:

  1. Go to the top menu and select Windows.
  2. Hover over Dockable Dialogs.
  3. Click on Paths to open the panel.

Step 3: Access the Import Path Function

  1. In the Paths panel, right-click anywhere within the empty area of the path list (or click the small menu arrow located in the top-right corner of the tab).
  2. From the context menu, select Import Path....

Step 4: Select and Configure the SVG File

  1. Use the file browser dialog that appears to navigate to your external SVG file.
  2. Select the SVG file.
  3. In the lower section of the file dialog, configure the import settings as needed:
    • Merge imported paths: Check this if the SVG contains multiple paths that you want combined into a single path layer.
    • Scale imported paths to fit image: Check this if you want GIMP to automatically resize the vector to match the dimensions of your active canvas.
  4. Click Open.

Step 5: View and Use the Imported Path

The imported SVG vector will now appear as an entry in the Paths dialog. By default, it may be invisible on the canvas:

  • Click the eye icon space next to the path thumbnail to make the path outline visible on your canvas.
  • Right-click the path name to access options such as Path to Selection, Stroke Path, or Export Path.
  • Select the Paths Tool (shortcut key B) from the main toolbox to edit the imported vector nodes directly.

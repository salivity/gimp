How to Scale GIMP Icons on 4K Displays

High-resolution 4K and HiDPI monitors often cause the user interface in GIMP to appear tiny and difficult to navigate. This guide explains the exact setting responsible for automatic icon scaling in GIMP, where to find it in the preferences menu, and how to configure it to match your display resolution.

The Setting: "Guess icon size from resolution"

In GIMP, the setting that controls whether icons scale automatically based on display pixel density is located in the Icon Theme settings and is called Guess icon size from resolution.

When enabled, GIMP inspects your system's DPI settings to determine whether standard, medium, large, or huge icons should be rendered on the interface.

How to Enable Automatic Icon Scaling

  1. Open GIMP.
  2. Go to the top menu and select Edit > Preferences (on macOS, select GIMP > Preferences).
  3. In the left sidebar, expand the Interface section and click on Icon Theme.
  4. Look below the list of available themes for the Icon size options.
  5. Select Guess icon size from resolution to allow GIMP to detect and scale icons for your 4K monitor automatically.
  6. Click OK to save and apply the changes.

Alternative: Custom Icon Size

If your operating system does not report resolution scale factors properly, automatic detection may fail to enlarge the icons. In this case, choose Custom icon size in the same menu and use the slider to manually select Large or Huge to achieve the desired visibility on a 4K screen.

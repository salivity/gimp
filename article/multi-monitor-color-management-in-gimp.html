Multi-Monitor Color Management in GIMP

Managing accurate colors across multiple screens requires aligning GIMP's internal settings with your operating system's display profiles. This guide explains how to configure independent multi-monitor color management in GIMP by establishing per-display operating system profiles and enabling GIMP's automatic display detection.

How GIMP Handles Multiple Monitors

GIMP does not provide separate manual profile dropdowns for individual monitors within its preferences interface. Instead, GIMP relies on your operating system's windowing system to detect which monitor a window is currently placed on. When configured properly, GIMP dynamically applies the appropriate ICC color profile as you move image windows from one display to another.

Step 1: Assign ICC Profiles in the Operating System

Before GIMP can apply distinct profiles per screen, your operating system must associate specific ICC/ICM profiles with each physical monitor.

  • Windows 10 / 11:

    1. Open the Start menu, type Color Management, and press Enter.
    2. Select your first monitor from the Device drop-down menu.
    3. Check the box labeled Use my settings for this device.
    4. Click Add..., browse to select your calibrated ICC profile, and set it as the default.
    5. Repeat this process for your second and any additional monitors.

  • Linux (GNOME / KDE):

    1. Open your system settings and navigate to Color.
    2. Select your first display, click Add Profile, and assign your calibrated .icc file.
    3. Select your second display and assign its respective profile.
    4. On lightweight X11 window managers, install and run a daemon like xiccd to write the _ICC_PROFILE atom to each screen output automatically.

  • macOS:

    1. Open System Settings and go to Displays.
    2. Select each connected display individually and choose its designated calibrated profile from the Color Profile menu.

Step 2: Enable System Profile Detection in GIMP

Once the operating system is mapping profiles to individual displays, instruct GIMP to read these profiles dynamically.

  1. Launch GIMP.
  2. Go to Edit > Preferences (or GIMP > Preferences on macOS).
  3. In the left panel, click on Color Management.
  4. Set the Color management mode dropdown to Color managed display.
  5. Locate the Monitor profile section and check the box labeled Try to use the system monitor profile.
  6. Leave the manual Monitor profile field blank or set to None to prevent GIMP from overriding OS-level assignments with a single static profile.
  7. Click OK to save your settings.

Step 3: Verify Multi-Monitor Behavior

To confirm that the profiles update across screens:

  1. Restart GIMP to ensure all profile hooks are loaded.
  2. Open a test image with distinct, saturated colors.
  3. If using Single-Window Mode, move the entire GIMP window between monitors; the canvas colors will subtly shift to adjust for the target monitor's ICC profile.
  4. If using multi-window mode, each detached image window will automatically adopt the color profile of the monitor it rests upon.

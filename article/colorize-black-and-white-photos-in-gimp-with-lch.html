Colorize Black and White Photos in GIMP with LCH

Colorizing historic black-and-white photographs requires precise control over tonality to avoid artificial-looking results. By leveraging GIMP’s LCH (Lightness, Chroma, Hue) color processing, you can alter hues and saturation without destroying the original exposure, contrast, or underlying luminosity of vintage prints. This workflow outlines the exact steps to isolate image zones, apply LCH-based color balance adjustments, and blend natural tones into monochrome imagery.

1. Image Preparation and Color Space Setup

Historic scans often open in GIMP as single-channel grayscale files. You must convert the image mode to accept color data before making any adjustments:

  1. Open your black-and-white photograph in GIMP.
  2. Navigate to Image > Mode and select RGB.
  3. Go to Image > Precision and set it to 32-bit floating point and Linear light to ensure smooth gradients and prevent banding during tinting.
  4. Duplicate the original layer by pressing Shift + Ctrl + D to serve as your preserved base plate.

2. Isolate Elements with Masks

Natural colorization requires treating individual elements—such as skin, hair, fabric, foliage, and skies—on separate layers to prevent color bleeding.

  1. Create a new transparent layer above the base photograph for each specific element (e.g., name one "Skin", one "Clothing", and one "Background").
  2. Set the Mode dropdown at the top of the Layers panel to Color (LCH). Unlike standard RGB color modes, Color (LCH) applies hue and chroma while strictly retaining the base image's perceptual lightness.
  3. Select the base layer and use the Free Select Tool or Paths Tool to outline the target area.
  4. Select the corresponding transparent layer, go to Layer > Mask > Add Layer Mask, and choose Selection.

3. Apply Selective Color via LCH Adjustments

Once masked, introduce color into the target area using targeted brushwork or fill adjustments:

  1. Select the layer thumbnail (not the mask thumbnail) of your target layer.
  2. Select the Bucket Fill Tool or a soft Paintbrush Tool.
  3. Choose a base reference color from your palette.
  4. Apply the color over the masked region. The underlying detail, grain, and lighting will immediately show through due to the Color (LCH) blend mode.

4. Refine Tones Using LCH Color Balance

To achieve realism, color values must shift across shadows, midtones, and highlights (for example, skin shadows typically carry cooler or redder hues than highlighted areas).

  1. Select the colored layer and navigate to Colors > Color Balance.
  2. Ensure the preview is active. The tool divides tone evaluation across Shadows, Midtones, and Highlights.
  3. Adjust the sliders for each tonal range:
    • Shadows: Introduce cooler, deeper tones to reflect atmospheric occlusion.
    • Midtones: Anchor the primary local color.
    • Highlights: Shift slightly warmer to emulate natural sunlight or ambient illumination.
  4. For deeper chromatic control, navigate to Colors > Hue-Chroma to directly adjust the Hue angle and fine-tune the Chroma intensity to keep historical tones muted and period-accurate.

5. Final Balancing and Blending

  1. Lower the Opacity of individual colored layers (typically between 60% and 85%) to prevent unnatural oversaturation.
  2. Soften hard transitions by clicking on the layer mask, navigating to Filters > Blur > Gaussian Blur, and applying a subtle 1–3 pixel radius.
  3. Repeat the process for all remaining elements until the entire photograph is unified.

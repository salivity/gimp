Edge-Lit Acrylic Sign Mockup Guide in GIMP

Creating a realistic edge-lit cast acrylic sign mockup in GIMP requires simulating optical physics, specifically how light travels through polished polymer and catches on engraved surfaces and outer borders. This guide outlines the exact workflow for establishing a dark environment, rendering the clear acrylic panel, applying engraved vector artwork, and generating multi-layered LED diffusion glows using native GIMP tools like blend modes, layer masks, and Gaussian blur.

Step 1: Canvas Setup and Background

  1. Open GIMP and create a new project with dimensions suited for display mockups, such as 3840×2160 or 1920×1080 pixels at 300 DPI.
  2. Fill the background layer with a dark tone, such as charcoal gray, dark brick, or a textured wall. Edge-lit acrylic requires high contrast to appear photorealistic, as the light effect is barely visible on bright backgrounds.
  3. Lower the exposure or brightness of the background slightly to ensure the light source will pop.

Step 2: Construct the Clear Acrylic Panel

  1. Create a new transparent layer named Acrylic Base.
  2. Use the Rectangle Select Tool (with rounded corners enabled, radius set around 15–25 px) to draw the shape of your acrylic sheet.
  3. Fill the selection with white, then lower the layer Opacity to roughly 3% to 5%.
  4. Right-click the layer, select Alpha to Selection, and create a new layer named Panel Edge.
  5. Go to Select > Border and set the border width to 2 or 3 pixels. Fill this border with white and set the layer opacity to 25% with the blend mode set to Screen. This defines the polished outer boundary of the cast acrylic plate.

Step 3: Insert the Engraved Graphic

  1. Import your logo, typography, or vector design onto a new layer named Engraving and position it centered on the panel.
  2. Convert the graphic to pure white (#FFFFFF).
  3. Set the layer blend mode to Screen or Normal with an opacity between 70% and 85%.
  4. Cast acrylic laser engravings appear frosty and semi-opaque. To simulate this texture, go to Filters > Noise > CIE lch Noise and add a microscopic amount of lightness noise (under 2%) to scatter the light across the engraved area.

Step 4: Generate the LED Light Source

Edge illumination originates from an LED strip, typically mounted in an aluminum base or standoffs at the bottom or top of the sign.

  1. Create a new transparent layer named LED Core Light directly beneath the Engraving layer.
  2. Choose your LED accent color (such as cyan, warm white, or neon green) as your foreground color.
  3. Select the Gradient Tool, set the shape to Linear, and configure the gradient to transition from the chosen color to transparent.
  4. Drag the gradient upward from the base of the sign toward the top, covering about one-third of the panel height. Set this layer mode to Linear Light or Addition, lowering opacity to 40%.

Step 5: Render the Internal Glow on Engravings

Light in clear acrylic only scatters where the surface is broken by engraving.

  1. Duplicate the Engraving layer twice.
  2. Name the first duplicate Inner Glow and the second Scatter Glow.
  3. Select Inner Glow, lock its alpha channel, fill it completely with your chosen LED color, and unlock the alpha channel.
  4. Apply a tight blur via Filters > Blur > Gaussian Blur with a radius between 3 and 6 pixels. Set the blend mode to Addition with 100% opacity.
  5. Select Scatter Glow, fill it with the same LED color, and apply a wide Gaussian Blur with a radius between 25 and 40 pixels. Set the blend mode to Screen and reduce the opacity to 50%. This simulates light dispersing into the surrounding transparent medium.

Step 6: Illuminate the Outer Acrylic Edges

  1. Return to the Panel Edge layer created in Step 2.
  2. Duplicate it and rename it Illuminated Edge.
  3. Lock the alpha channel, fill it with your LED color, and unlock it.
  4. Use the Eraser Tool with a soft brush to remove the color from edges that are farthest from the LED source, leaving the most intense illumination closest to the light strip mount.
  5. Apply a Gaussian Blur of 4 to 8 pixels to give the illuminated rim a soft bloom, and set the blend mode to Addition.

Step 7: Final Specular Highlights and Polish

  1. Create a top layer set to Addition (Glow) mode.
  2. Use a soft, circular white brush with low opacity to tap single highlights on the corners of the panel closest to the light source, as well as the sharpest apexes of the engraved graphic.
  3. If mounting hardware like aluminum standoffs or a bottom track is present, cast a subtle drop shadow beneath them using a soft black brush on a layer set to Multiply placed right above the background.

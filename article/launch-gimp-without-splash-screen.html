Launch GIMP Without Splash Screen

GIMP displays a splash screen by default while loading its core components, brushes, and plugins during startup. If you want a faster, cleaner launch experience or need to automate image processing tasks in the background, GIMP provides built-in command-line parameters to suppress this startup window completely.

The Command-Line Parameters

To disable the splash screen when starting GIMP, use either of the following command-line flags:

  • Short form: -s
  • Long form: --no-splash

Both parameters perform the exact same function: instructing the program to initialize without displaying the splash dialog.

How to Use Them Across Operating Systems

Linux

Open your terminal and run:

gimp -s

or

gimp --no-splash

Windows

Open Command Prompt or PowerShell and navigate to the GIMP installation directory (typically C:\Program Files\GIMP 2\bin\), then run:

gimp-2.10.exe -s

To make this permanent on Windows without opening the command prompt every time:

  1. Right-click the GIMP shortcut and select Properties.
  2. Go to the Shortcut tab.
  3. Locate the Target field.
  4. Add a space followed by -s to the very end of the path (outside the quotation marks):
    "C:\Program Files\GIMP 2\bin\gimp-2.10.exe" -s
  5. Click Apply and then OK.

macOS

Open Terminal and invoke the executable inside the application bundle:

/Applications/GIMP.app/Contents/MacOS/gimp -s

How to Export GIMP Paths to Inkscape as SVG

This guide explains how to export vector paths created in GIMP as a Scalable Vector Graphics (SVG) file and open them for editing in Inkscape. While GIMP is primarily a raster image editor, its Paths Tool generates true vector curves that can be seamlessly transferred to dedicated vector software like Inkscape without any loss of quality.

Step 1: Create or Locate Your Path in GIMP

  1. Use the Paths Tool (shortcut: B) to draw your vector shape or trace an element in your GIMP workspace.
  2. Open the Paths Dialog if it is not already visible by navigating to Windows > Dockable Dialogs > Paths.

Step 2: Export the Path as an SVG File

  1. In the Paths Dialog, locate the path layer you want to export.
  2. Right-click on the specific path and select Export Path... from the context menu.
    • Note: If you want to export all paths in your document simultaneously, right-click any blank area in the Paths Dialog and select Export Path..., then check the Export all paths option in the save dialog.
  3. In the export window, choose your destination folder.
  4. Enter a name for your file, ensuring it ends with the .svg extension (for example, mypath.svg).
  5. Click Save.

Step 3: Open the SVG in Inkscape

  1. Launch Inkscape.
  2. Go to File > Open, locate your exported .svg file, and click Open.
    • Alternatively, you can use File > Import (Ctrl + I) if you want to insert the path into an existing Inkscape project.
  3. The path will appear on your canvas as a native vector object. Select the Edit paths by nodes tool (shortcut: N) to view, adjust, and manipulate the nodes and curves directly within Inkscape.

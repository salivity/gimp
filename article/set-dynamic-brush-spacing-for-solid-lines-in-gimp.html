Set Dynamic Brush Spacing for Solid Lines in GIMP

Achieving clean, continuous solid line work in GIMP requires fine-tuning brush spacing and dynamics to prevent gaps, "beading," or broken strokes during fast movements. This guide walks you through reducing base brush spacing, creating a custom Paint Dynamic, and configuring settings to ensure your linework remains completely solid regardless of drawing speed or stylus pressure.

Step 1: Lower the Base Brush Spacing

By default, GIMP brushes use a spacing setting of 10% to 20%, which separates brush stamps during rapid strokes.

  1. Select the Paintbrush Tool (P) from the Toolbox.
  2. In the Tool Options dockable dialog, locate the Spacing slider.
  3. Lower the Spacing value to 1.0 (or between 1.0% and 5.0%).
  4. Note: Setting spacing to 1.0 provides the smoothest line, but may increase CPU usage with very large brush sizes.

Step 2: Create a Custom Paint Dynamic

To control how spacing behaves dynamically with your drawing tablet or mouse input, create a dedicated dynamic preset.

  1. Open the Dynamics dialog via Windows > Dockable Dialogs > Paint Dynamics.
  2. Click the Create a new dynamics button (the blank page icon) at the bottom of the panel.
  3. Name your new dynamic (e.g., Solid Line Art).
  4. Open the Dynamic Editor via Windows > Dockable Dialogs > Paint Dynamics Editor.

Step 3: Configure the Dynamics Matrix

In the Paint Dynamics Editor, you will see a matrix mapping inputs (Pressure, Velocity, Direction, etc.) to brush properties (Opacity, Size, Spacing, etc.).

  1. Disable Spacing Dynamics: Ensure that the Spacing row has all checkboxes unchecked. This prevents GIMP from widening brush stamp gaps when stroke velocity increases.
  2. Configure Pressure and Size (Optional): If you use a graphics tablet, check the box at the intersection of Pressure and Size for responsive line weight variations while maintaining a solid stroke.
  3. Lock Opacity: Uncheck all boxes under Opacity to guarantee a fully opaque, solid mark throughout the stroke.

Step 4: Apply and Test the Preset

  1. Return to the Tool Options panel with the Paintbrush selected.
  2. Under the Dynamics dropdown menu, select your newly created dynamic (Solid Line Art).
  3. Test your brush on the canvas by drawing rapid, varied-pressure strokes.

Step 5: Enable Smooth Stroke for Stability

If your lines still show slight jitter or roughness:

  1. In the Tool Options panel, check the Smooth Stroke box.
  2. Adjust the Quality slider to a value between 20 and 50.
  3. Adjust the Weight slider to balance responsiveness with line stabilization.

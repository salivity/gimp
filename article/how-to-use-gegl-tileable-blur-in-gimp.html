How to Use GEGL Tileable Blur in GIMP

This guide explains how to use GIMP's GEGL Tileable Blur filter to eliminate visible boundary seams in repeating textures. You will learn the process of testing your texture for edge mismatches, configuring the Tileable Blur filter to smooth opposing edges, and verifying the final result to produce seamless assets for 3D modeling, game design, or web backgrounds.

Step 1: Prepare the Source Image

  1. Open GIMP and load your texture image via File > Open.
  2. Crop the image to your desired dimensions using the Crop Tool (Shift + C). For game engines or standard 3D workflows, consider scaling to power-of-two dimensions (such as 1024×1024 or 2048×2048) by selecting Image > Scale Image.
  3. Ensure the layer matches the image size by right-clicking the layer in the Layers panel and choosing Layer to Image Size.

Step 2: Apply the Tileable Blur Filter

Unlike a standard Gaussian blur that softens the entire canvas, the Tileable Blur filter blends opposing boundaries (left with right, top with bottom) so that the edges transition smoothly when placed side by side.

  1. Navigate to the top menu and select Filters > Blur > Tileable Blur...
  2. In the dialog box, ensure the Preview checkbox is enabled to monitor your changes in real time.
  3. Configure the blur parameters:
    • Radius: Determines how far into the image the blur extends from the borders. Set a value that is large enough to disguise harsh seams without washing out the texture details in the interior.
    • Horizontal / Vertical: You can unchain these values if your texture tiles in only one direction (e.g., horizontal floorboards or vertical stripes). Keep them chained for two-dimensional tiling.
    • Blur Type: Choose between IIR (Infinite Impulse Response) and RLE (Run-Length Encoded). IIR is best suited for photographic textures and smooth gradients, while RLE works better for sharper, computer-generated graphics.
  4. Click OK to apply the filter.

Step 3: Inspect the Texture Using the Offset Tool

To verify that the boundary seams have been fully eliminated, offset the texture so that its borders meet at the center of the canvas.

  1. Go to Layer > Transform > Offset... (or press Shift + Ctrl + O).
  2. Click the By width/2, height/2 button. This shifts the layer so the outer edges run directly across the middle of the screen.
  3. Set the Edge Behavior to Wrap around and click OK.
  4. Examine the center horizontal and vertical cross-sections of the image:
    • If the seams are invisible, your texture is seamless.
    • If a visible line remains, use the Clone Tool (C) or Healing Tool (H) at low opacity to blend any remaining hard edges across the cross-section.

Step 4: Export the Seamless Texture

Once the borders blend cleanly without visible lines:

  1. Optionally offset the image once more using the Offset tool to return it to its original layout, or leave it as is, since the texture now wraps perfectly regardless of alignment.
  2. Go to File > Export As...
  3. Choose your preferred format (such as PNG for lossless quality or JPEG for compressed web assets) and save the final file.

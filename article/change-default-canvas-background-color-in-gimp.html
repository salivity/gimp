Change Default Canvas Background Color in GIMP

In GIMP, the empty space displayed around your active image workspace is called the canvas padding. This article explains how to locate and configure the "Canvas padding color" setting within GIMP's Preferences to permanently change the default background color, as well as how to toggle it temporarily for individual project windows.

The Setting: Canvas Padding Color

The setting that controls the default background color around images is called Canvas padding color. It dictates the color of the empty workspace surrounding an image layer in both standard and fullscreen editing modes.

How to Change the Default Canvas Background Color

To permanently set the default canvas padding color for all future sessions:

  1. Open GIMP.
  2. Navigate to the top menu and select Edit > Preferences (on macOS, select GIMP > Preferences).
  3. In the left sidebar of the Preferences window, locate the Image Windows section and click on Appearance.
  4. On the right side, you will see settings split into Normal mode and Fullscreen mode. Locate the Canvas padding color dropdown menu under the mode you wish to modify.
  5. Choose one of the preset options:
    • From theme: Uses the background tone dictated by your current GIMP UI theme.
    • Light check color: Uses a light checkerboard pattern.
    • Dark check color: Uses a dark checkerboard pattern.
    • Custom color: Allows you to define an exact shade.
  6. If you selected Custom color, click the color swatch box next to the dropdown menu to open the color picker and select your desired tone (such as pure black, white, or neutral gray).
  7. Click OK at the bottom of the Preferences dialog to apply and save your changes.

Quick Change for the Current Window

If you only need to change the background color for the image currently open on your screen without modifying the global defaults:

  1. Click View in the top menu bar of the active image window.
  2. Hover over Padding Color.
  3. Select your preferred color option or choose Select Custom Color... to pick a specific shade on the fly.

How to Move a Selection Outline in GIMP

Moving a selection outline without altering or dragging the underlying image pixels is an essential editing technique in GIMP. This guide covers the exact keyboard shortcuts and tool settings required to reposition your active selection boundary smoothly across your canvas.

The Quick Keyboard Shortcut

To reposition an active selection outline without moving the underlying pixels, select the Move Tool (shortcut: M), then hold Alt while clicking and dragging inside the selection.

Note for Linux users: Because many Linux desktop environments reserve the Alt key for moving application windows, use Shift + Alt while dragging to achieve the same result.

Alternative Method: Using Selection Tools

If you already have a selection tool active (such as the Rectangle Select or Ellipse Select tool):

  1. Hover your cursor over the selection area.
  2. Hold Ctrl + Alt.
  3. Click and drag the selection border to your desired location.

Holding this combination prevents the tool from creating a floating selection and ensures only the boundary moves.

Permanent Toggle via Tool Options

If you prefer not to hold keyboard modifiers while repositioning outlines:

  1. Press M to activate the Move Tool.
  2. Look at the Tool Options panel (usually docked on the left).
  3. Under the Move: section, click the Selection icon (a red dashed square).
  4. Click and drag anywhere inside the selection to move only the outline.

Remember to switch the setting back to the Layer icon when you finish so you can move regular layers again.

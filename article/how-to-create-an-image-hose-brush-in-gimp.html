How to Create an Image Hose Brush in GIMP

This guide explains how to create a custom image hose brush (.gih) in GIMP that randomly scatters various leaf designs across your canvas as you paint. You will learn how to prepare distinct leaf variations across individual layers, export the file using the proper image pipe parameters, and configure brush settings to achieve a natural, organic scattering effect.

1. Set Up the Project Canvas

Open GIMP and go to File > New. Set the canvas dimensions to a square size suitable for a brush, such as 500x500 pixels. In the Advanced Options dropdown, set Fill with to Transparency, then click OK.

2. Add Leaf Variations on Separate Layers

Each variation of your leaf must reside on its own individual transparent layer:

  1. Open the Layers panel (Windows > Dockable Dialogs > Layers).
  2. Draw, paint, or paste your first leaf variation onto the background layer. Ensure the leaf is centered and leaves adequate transparent padding around the borders.
  3. Create a new transparent layer by clicking the Create a new layer icon at the bottom of the Layers panel.
  4. Draw or paste a second leaf variation with a different angle, shape, or color tone on this new layer.
  5. Repeat this process for as many variations as you want (typically 4 to 8 layers produce a convincing random look).
  6. Give the layers descriptive names (e.g., Leaf 1, Leaf 2, Leaf 3) for easier organization.

3. Export as a GIMP Image Hose (.gih)

  1. Go to File > Export As...
  2. In the bottom-right file format selector, select GIMP Image Hose (.gih), or simply type .gih at the end of your filename (e.g., scatter_leaves.gih).
  3. To make the brush immediately available, export it directly into your GIMP brushes directory:
    • Windows: C:\Users\[Username]\AppData\Roaming\GIMP\2.10\brushes
    • macOS: /Users/[Username]/Library/Application Support/GIMP/2.10/brushes
    • Linux: ~/.config/GIMP/2.10/brushes
  4. Click Export.

4. Configure the Image Hose Export Dialog

When the export dialog box appears, configure the image pipe settings:

  • Spacing (%): Set this between 100 and 150. This controls the distance between leaf stamps during a continuous stroke so they do not overlap excessively.
  • Description: Enter a display name for your brush.
  • Cell Size: Leave this at the default values matching your canvas size.
  • Number of Cells: This should match the total number of layers you created.
  • Dimension: Set this to 1.
  • Ranks: Set this to the number of leaf layers you have.
  • Selection: Change the dropdown menu from "incremental" to random. This instructs GIMP to select a random leaf layer each time a mark is laid down.
  • Click Export to finalize the file.

5. Load and Paint with the Brush

  1. Open the Brushes dialog (Windows > Dockable Dialogs > Brushes).
  2. Click the Refresh icon at the bottom of the panel to load the new brush without restarting GIMP.
  3. Select your new leaf brush from the list.
  4. Select the Paintbrush tool from the Toolbox.
  5. In the Tool Options panel, adjust the brush Size, increase the Spacing if you want more air between stamps, and enable Jitter to scatter the leaves perpendicularly along your brush stroke path. Paint on the canvas to scatter the random leaf variations.

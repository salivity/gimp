How to Make Tapered Comic Inking Brushes in GIMP

Creating crisp, expressive comic line art in GIMP requires a responsive brush that produces sharp, tapered ends at the beginning and finish of every stroke. This guide explains how to build a dedicated comic inking preset from scratch by creating a custom Paint Dynamic, fine-tuning the pressure and velocity mapping curves, enabling stroke smoothing for steady lines, and saving the final configuration as a permanent tool preset.

1. Select the Base Inking Tool and Brush

  1. Open GIMP and select the Paintbrush Tool (P) from the Toolbox.
  2. In the Tool Options dockable dialog, click the brush icon and select a solid brush with crisp borders, such as 2. Hardness 100.
  3. Set the Hardness slider to 100.0.
  4. Set the brush Size to your preferred baseline inking width (e.g., between 6 and 12 pixels for high-resolution line art).

2. Create a Custom Paint Dynamic

Standard GIMP dynamics often produce blunt line ends. A custom dynamic gives you precise control over how stylus pressure affects line width.

  1. Go to Windows > Dockable Dialogs > Paint Dynamics to reveal the dynamics list.
  2. Click the Create a new dynamics button (the blank paper icon) at the bottom of the dialog. This opens the Paint Dynamics Editor.
  3. Name the dynamic something recognizable, such as Comic Inker Taper.
  4. In the Mapping Matrix, locate the intersection between the Pressure column and the Size row, then check the box.
  5. (Optional for high-speed strokes) Check the box at the intersection of Velocity and Size if you want your lines to taper automatically during fast flicking motions.

3. Adjust the Dynamic Curves for Extreme Tapering

To ensure lines thin out to a needle-sharp point rather than a rounded stub, you must edit the dynamic curve.

  1. In the Paint Dynamics Editor, select the Size tab below the matrix to view the curve graph.
  2. The default diagonal line represents a linear 1:1 response. Click on the bottom-left point of the curve and drag it down to the absolute bottom edge of the grid.
  3. Add a control point near the bottom left (around 10% to 20% input) and bend the curve slightly downward into an exponential curve (an "S" or "J" curve). This forces the brush to stay extremely thin under light pressure and only widen when deliberate force is applied.
  4. If you mapped Velocity, switch to the Velocity curve tab and adjust it so high velocity drops brush size rapidly, creating sharp tails when you flick your pen.

4. Configure Stroke Smoothing and Spacing

Prevent jagged or jittery lines by configuring the stroke behavior in the Tool Options panel:

  1. Scroll down to Brush Dynamics and select your newly created Comic Inker Taper dynamic.
  2. Expand the Smooth Stroke section and check the box to enable it.
  3. Set Quality to 50 or higher.
  4. Set Weight between 10 and 25. Higher values stabilize hand tremors and help flicked endpoints taper evenly without wobbling.
  5. In the brush settings, ensure Spacing is set to 1.0% or 2.0%. High spacing causes tapered stroke ends to look like a string of dots instead of a continuous sharp line.

5. Save the Inking Setup as a Tool Preset

Save your configuration so you can recall it instantly across different projects without reconfiguring settings.

  1. Go to Windows > Dockable Dialogs > Tool Presets.
  2. Click the Create a new tool preset button at the bottom of the dialog.
  3. In the Tool Preset Editor, enter a name like Comic Inking Pen.
  4. Ensure the checkboxes for Brush, Dynamics, and Color are ticked.
  5. Click the Save button.

Your custom inking pen is now ready for comic production and accessible from the Tool Presets panel at any time.

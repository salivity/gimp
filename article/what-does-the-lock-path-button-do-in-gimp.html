What Does the Lock Path Button Do in GIMP?

The Lock Path feature in GIMP is a critical safeguard designed to protect intricate vector paths from accidental edits, transformations, and deletions. By toggling the lock options in the Paths dialog, users can preserve the precise placement of anchor points and control handles while continuing to work freely on other layers and elements within a project. This article explains how the Lock Path function works, the specific protections it provides, and why it is indispensable when handling complex vector graphics.

Core Functions of the Lock Path Button

In GIMP, the Paths dialog provides dedicated lock icons located at the top of the panel. Activating these toggles on a selected path establishes specific restrictions:

  • Lock Path Strokes: Prevents any manual adjustments to the path's components. When active, you cannot add, delete, or move anchor points or directional handles using the Paths Tool.
  • Lock Position and Size: Prevents transformations. This stops tools like the Move, Rotate, Scale, and Shear tools from shifting or resizing the vector shape, even if the path is active or linked.

Protection for Complex Vector Shapes

Complex vector paths often involve dozens or hundreds of precisely placed nodes to create smooth curves, detailed silhouettes, or intricate masks. Without protection, simple workflow mistakes can compromise this work.

The lock functionality accomplishes the following:

  • Eliminates Accidental Clicks: When switching between tools, clicking on an active, unlocked path with the Path Tool can inadvertently create a new node, split a segment, or shift a control handle. Locking ensures the geometry remains static.
  • Safe Canvas Navigation: Using the Move Tool on the canvas can accidentally grab an active path instead of the intended layer. Locking the position prevents unintended displacement.
  • Preserves Base Shapes During Operations: Locked paths can still be referenced—such as generating a selection from the path, stroking the path onto a raster layer, or duplicating it—without risking alterations to the original vector source.

How to Lock a Path

  1. Open the Paths dialog (Windows > Dockable Dialogs > Paths).
  2. Click on the path you want to protect to highlight it.
  3. At the top of the Paths tab, click the Lock pixels/strokes icon (paintbrush with a cross) or the Lock position and size icon (four-way arrow with a cross) depending on the level of protection needed.

Once engaged, the path remains fully visible and usable as a guide or selection source, but its geometry and placement are completely shielded from unintended modifications.

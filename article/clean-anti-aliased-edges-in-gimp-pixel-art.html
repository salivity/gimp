Clean Anti-Aliased Edges in GIMP Pixel Art

Creating clean pixel art requires rigid, single-pixel borders, but scaling artwork or using standard brushes often introduces semi-transparent, anti-aliased fringes. This guide demonstrates how to use GIMP's "Sharpen" selection command to remove unwanted blur, snap feathered outlines to hard boundaries, and restore crisp lines essential for authentic pixel art.

Step 1: Select the Artwork Boundary

To sharpen blurry edges, first convert the subject's opaque pixels into a selection:

  1. Open your pixel art project in GIMP.
  2. In the Layers panel, right-click the layer containing your art.
  3. Select Alpha to Selection. This selects all non-transparent pixels, including the semi-transparent anti-aliased edges.

Step 2: Use the Sharpen Selection Command

The default selection will include partial transparency data, creating a soft edge. The Sharpen tool converts this into an absolute 1-bit boundary.

  1. Go to the top menu and click Select.
  2. Click Sharpen.

GIMP automatically calculates a 50% opacity threshold across the selected boundary. Pixels with over 50% opacity become fully selected, while pixels below 50% are excluded.

Step 3: Remove the Semi-Transparent Fringe

Now that the selection contains sharp, aliased borders, you can eliminate the blurry fringe left behind:

  1. Invert the selection by navigating to Select > Invert (or press Ctrl + I on Windows / Cmd + I on macOS).
  2. Press the Delete key to erase all semi-transparent stray pixels resting outside the sharp boundary.
  3. Deselect your canvas by going to Select > None (or press Shift + Ctrl + A).

Step 4: Re-Fill Flat Colors (Optional)

If the inner edges of your artwork lost color density due to partial transparency:

  1. Re-select the subject (Layer > Alpha to Selection).
  2. Use the Bucket Fill Tool with Threshold set to 0 and Fill whole selection enabled.
  3. Click inside the selection to restore flat, solid color values without introducing new anti-aliasing.

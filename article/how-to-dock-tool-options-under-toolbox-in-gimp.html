How to Dock Tool Options Under Toolbox in GIMP

Docking the Tool Options dialog directly beneath the Toolbox in GIMP creates a streamlined, unified workspace that keeps essential brush and tool settings easily accessible. If the Tool Options dialog was accidentally closed or detached into a floating window, you can quickly restore it to its standard position using GIMP's drag-and-drop docking system.

Step 1: Open the Tool Options Dialog

If the Tool Options tab is not currently visible on your screen:

  1. Click Windows in the top menu bar.
  2. Navigate to Dockable Dialogs.
  3. Select Tool Options. The panel will appear either as a floating window or inside an existing dock.

Step 2: Drag the Tool Options Tab

  1. Locate the Tool Options tab at the top of its current dialog window (look for the text "Tool Options" accompanied by the icon of the currently active tool).
  2. Click and hold the mouse button directly on the tab itself (not the title bar of the floating window).

Step 3: Dock Beneath the Toolbox

  1. Drag the tab over to the main Toolbox area (the panel containing all your selection, paint, and transform tool icons).
  2. Move your cursor toward the bottom edge of the Toolbox panel.
  3. Watch for a horizontal highlight line or shaded box to appear across the bottom boundary of the Toolbox. This indicates the drop zone for docking underneath the tools.
  4. Release the mouse button once the highlight appears. The Tool Options panel is now anchored beneath the Toolbox.

Step 4: Lock the Layout (Optional)

To prevent the dialog from accidentally moving in the future:

  1. Click the small Configure this tab icon (an arrow pointing left or a small wrench icon) in the top-right corner of the newly docked Tool Options panel.
  2. Select Lock Tab to Dock.
  3. To ensure this layout loads every time GIMP starts, go to Edit > Preferences > Window Management and click Save Window Positions Now.

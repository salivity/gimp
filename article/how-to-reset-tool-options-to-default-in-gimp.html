How to Reset Tool Options to Default in GIMP

This guide explains how to restore your tool settings in GIMP back to their original factory defaults. If you have modified brush sizes, opacities, dynamics, or other settings and want a clean slate, you can instantly revert all tools at once through the application preferences or reset individual tools directly from the workspace.

Reset All Tool Options via Preferences

To reset every tool in GIMP back to its default state simultaneously, use the main Preferences menu:

  1. Open GIMP.
  2. Open the Preferences window:
    • Windows/Linux: Click Edit in the top menu and select Preferences.
    • macOS: Click GIMP in the top menu bar and select Preferences.
  3. In the left-hand sidebar of the Preferences window, locate and click on Tool Options.
  4. In the main panel, look for the Reset Tool Options section.
  5. Click the button labeled Reset Saved Tool Options to Default Values.
  6. A confirmation prompt will appear asking if you are sure you want to reset all options. Click Reset.
  7. Click OK at the bottom of the Preferences dialog to save the changes and close the window.

All tools across the entire program will now be restored to their original factory configurations.

Reset a Single Active Tool

If you only need to fix the tool you are currently using without altering your settings for other tools:

  1. Ensure the Tool Options dock is visible (if missing, open it via Windows > Dockable Dialogs > Tool Options).
  2. Look at the bottom bar of the Tool Options panel.
  3. Click the circular arrow icon labeled Reset to default values.

This action immediately reverts only the currently selected tool to its default behavior while leaving your other custom configurations intact.

How to Create a Custom Brush from Selection in GIMP

Creating a custom brush from an existing canvas selection in GIMP is a quick way to add personalized stamps, textures, and shapes to your digital artwork. This guide explains how to convert any canvas selection into an immediate temporary brush using the clipboard, as well as how to export and save it permanently as a GIMP brush file (.gbr) for future use.

Method 1: Create an Instant Temporary Brush (Clipboard)

The fastest way to use a selection as a brush is via the Clipboard Brush feature.

  1. Make a Selection: Use any selection tool (such as the Rectangle Select, Ellipse Select, or Free Select Tool) to outline the area of your canvas you want to use.
  2. Copy the Selection: Press Ctrl + C (Windows/Linux) or Cmd + C (macOS), or go to Edit > Copy.
  3. Select the Paintbrush: Activate the Paintbrush Tool (P).
  4. Choose the Clipboard Brush: Open the Brushes dialog dock. The very first brush displayed will be the Clipboard Image (or Clipboard Mask). Select it to immediately start painting with your copied canvas region.

Note: This brush remains available until you copy something else to your clipboard.

Method 2: Save a Permanent Custom Brush (.gbr)

To keep your custom brush permanently across all future GIMP sessions, save it as a .gbr file.

Step 1: Isolate the Selection

  1. Select the desired area on your canvas.
  2. Copy it by pressing Ctrl + C or Cmd + C.
  3. Go to Edit > Paste As > New Image (or press Shift + Ctrl + V).
  4. (Optional) If you want the brush to change color with your active foreground color, convert the image to grayscale by navigating to Image > Mode > Grayscale. White areas will be fully transparent, black areas will be fully opaque, and gray tones will have varying levels of opacity.

Step 2: Export the Brush

  1. Go to File > Export As....
  2. Name your file and add the .gbr extension (for example, my_custom_brush.gbr).
  3. Set the save destination to GIMP's brushes folder:
    • Windows: C:\Users\[Username]\AppData\Roaming\GIMP\2.10\brushes
    • macOS: /Users/[Username]/Library/Application Support/GIMP/2.10/brushes
    • Linux: ~/.config/GIMP/2.10/brushes
  4. Click Export. A dialog box will appear asking for Spacing (set between 10% and 25% for general painting) and a Description (the name displayed in the brush menu).
  5. Click Export to finalize.

Step 3: Refresh the Brush List

  1. Open the Brushes dock (Windows > Dockable Dialogs > Brushes).
  2. Click the Refresh icon (two curved arrows) at the bottom of the panel.
  3. Your new custom brush will appear in the list, ready for permanent use.

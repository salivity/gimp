Configure Pressure Size and Tilt Angle in GIMP

This guide explains how to create and configure custom brush dynamics in GIMP, mapping stylus pressure to brush size and pen tilt to brush angle. Following these steps will allow you to access the Paint Dynamics Editor, configure the input-output matrix, and assign the custom dynamic to your painting tools for responsive, natural strokes.

Step 1: Open the Paint Dynamics Dialog

  1. Launch GIMP.
  2. Navigate to the top menu and select Windows > Dockable Dialogs > Paint Dynamics.
  3. To keep the editor accessible, also navigate to Windows > Dockable Dialogs > Paint Dynamics Editor.

Step 2: Create a New Brush Dynamic

GIMP's default dynamics presets are write-protected, meaning you must create a new dynamic preset to configure custom behaviors:

  1. In the Paint Dynamics dialog, click the Create a new dynamics button (the paper icon with a plus sign) located at the bottom of the panel.
  2. A new preset will appear in the list, and the Paint Dynamics Editor will automatically focus on it.
  3. Rename the dynamic at the top of the editor (e.g., "Pressure Size + Tilt Angle") so it is easy to find later.

Step 3: Configure the Matrix Mapping

The Paint Dynamics Editor features a grid where rows represent stylus inputs (Pressure, Velocity, Direction, Tilt, etc.) and columns represent brush outputs (Opacity, Size, Angle, Color, etc.).

  1. Locate the Pressure row and find where it intersects with the Size column. Check the box at this intersection.
  2. Locate the Tilt row and find where it intersects with the Angle column. Check the box at this intersection.
  3. Uncheck all other boxes in the grid to ensure no other inputs interfere with the brush behavior.

Step 4: Apply the Dynamics to Your Tool

  1. Select the Paintbrush, Airbrush, or MyPaint Brush tool from the Toolbox.
  2. Look at the Tool Options panel (usually docked beneath the Toolbox on the left).
  3. Expand the Dynamics section.
  4. Click the dynamics preview button to open the list of available presets.
  5. Select the custom dynamic you created in Step 2.

Step 5: Verify Tablet Configuration

If the brush does not respond to tilt or pressure:

  1. Go to Edit > Input Devices.
  2. Locate your graphics tablet stylus in the device list.
  3. Ensure the Mode dropdown is set to Screen instead of Disabled.
  4. Click Save and test the brush on an open canvas.

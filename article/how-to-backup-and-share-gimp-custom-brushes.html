How to Backup and Share GIMP Custom Brushes

Backing up and sharing custom brush packs in GIMP is a simple process that involves finding your local brush directory, copying the relevant brush files, and compressing them into an archive for distribution. This guide explains how to identify your GIMP brush directory, which file formats to include, how to create a shareable backup pack, and how another user can import those brushes into their own installation.

Locating Your GIMP Brushes Folder

To access your custom brushes, you must first find the folder where GIMP stores them:

  1. Open GIMP.
  2. Navigate to Edit > Preferences (on macOS, GIMP > Preferences).
  3. In the left panel, expand the Folders menu by clicking the arrow next to it.
  4. Click on Brushes.
  5. You will see two or more directory paths. Select the path located in your user profile folder (not the system installation folder, which contains default brushes).
  6. Click the file cabinet icon on the right labeled Show file location in the file manager to open the folder directly on your system.

Default paths generally follow these formats:

  • Windows: C:\Users\[Username]\AppData\Roaming\GIMP\2.10\brushes
  • Linux: /home/[username]/.config/GIMP/2.10/brushes
  • macOS: /Users/[username]/Library/Application Support/GIMP/2.10/brushes

Identifying Brush File Formats

Before copying, identify the files you want to include. GIMP uses three primary formats for brushes:

  • .gbr (GIMP Brush): Standard static brushes.
  • .gih (GIMP Image Hose): Dynamic or animated brushes containing multiple layers.
  • .vbr (Parametric Brush): Vector-based brushes created directly in GIMP's Brush Editor.

Select the specific brush files you wish to back up or share. You can also include subfolders if your brushes are organized by category.

Backing Up and Packaging for Sharing

  1. Create a Backup Folder: Create a new folder on your desktop or external drive (e.g., My_Custom_Brushes_Backup).
  2. Copy the Files: Copy your .gbr, .gih, or .vbr files from the GIMP brushes folder and paste them into your new backup folder.
  3. Compress into an Archive: Right-click the backup folder and compress it into a .zip archive.
  4. Share the Archive: You can now upload this .zip file to cloud storage (Google Drive, Dropbox), email it, or host it on creative asset platforms for other users to download.

How Recipients Install the Brush Pack

To load the shared brushes into their system, the recipient should follow these steps:

  1. Extract the downloaded .zip file to access the brush files.
  2. Open GIMP and locate their user brush folder via Edit > Preferences > Folders > Brushes.
  3. Paste the extracted brush files or folder into their brushes directory.
  4. Return to GIMP, open the Brushes dockable dialog (Windows > Dockable Dialogs > Brushes), and click the Refresh brushes button (the circular arrow icon at the bottom of the dialog).

The new brushes will immediately appear in the panel without needing to restart the application.

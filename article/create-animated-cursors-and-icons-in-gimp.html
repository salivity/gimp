Create Animated Cursors and Icons in GIMP

Creating custom animated cursors and multi-resolution application icons requires leveraging GIMP’s layer hierarchy to store multiple states and sizes within a single file. By structuring individual layers as distinct animation frames or discrete icon resolutions, you can export fully compliant Windows Icon (.ico) files and animated cursor formats without relying on specialized external editors.

Building Multi-Size Application Icons (.ico)

A functional Windows icon file (.ico) is a container that packages multiple square dimensions of the same graphic, allowing the operating system to display the optimal resolution depending on the view scale.

1. Canvas and Layer Setup

  1. Create a new document (File > New) with dimensions of 256 × 256 pixels, a transparent background, and an RGB color profile.
  2. Design your master icon graphic on this 256 × 256 canvas. This acts as the highest-resolution tier.
  3. Duplicate your primary layer or layer group for each standard icon size:
    • 128 × 128
    • 64 × 64
    • 48 × 48
    • 32 × 32
    • 16 × 16

2. Scaling Layers Individually

GIMP determines icon frame dimensions directly from layer boundaries rather than canvas boundaries:

  1. Select a layer assigned to a smaller dimension.
  2. Go to Layer > Scale Layer....
  3. Set the desired target width and height (e.g., 48 × 48 px).
  4. Set the Interpolation method:
    • Choose NoHalo or LoHalo for smooth vector-like artwork.
    • Choose None to preserve crisp edges for pixel art.
  5. Repeat this scaling process for each layer corresponding to the target resolutions.

3. Layer Stack Hierarchy

Organize the layer panel sequentially from largest to smallest (or smallest to largest). Ensure every layer has an active alpha channel by right-clicking each layer and selecting Add Alpha Channel if it is not already bolded.

4. Exporting the Icon

  1. Go to File > Export As... and set the file extension to .ico (e.g., app-icon.ico).
  2. Click Export.
  3. In the Windows Icon export dialog, verify each layer entry. Check the 32-bit (24-bit color + 8-bit alpha) bpp setting for larger layers, and enable PNG compression for 256 × 256 layers to reduce total file size.

Designing Animated Cursors

Animated cursors rely on sequential layers representing time-based frames, configured with specific frame durations and click coordinates (hotspots).

1. Document Configuration

  1. Open a new document sized to standard cursor specifications: 32 × 32 pixels (standard DPI) or 48 × 48 / 64 × 64 pixels (high DPI).
  2. Ensure the background is transparent.

2. Layer Sequence and Timing

GIMP renders animations from the bottom layer up:

  • Bottom layer: Frame 1 (Start of animation)
  • Middle layers: Sequential intermediate frames
  • Top layer: Final frame

To define individual frame timing directly in the layer hierarchy, rename the layers using GIMP's animation syntax:

  1. Double-click the layer name in the Layers dialog.
  2. Append the duration in milliseconds within parentheses, along with the frame disposal method:
    • Pointer Frame 1 (100ms) (replace)
    • Pointer Frame 2 (100ms) (replace)
    • Pointer Frame 3 (100ms) (replace)
  3. The (replace) tag ensures previous frames are cleared before rendering the next one, preventing visual artifacts.

3. Previewing the Cursor Animation

Test the animation smoothness before exporting:

  1. Navigate to Filters > Animation > Playback....
  2. Click Play to review the loop, speed, and frame transitions.

4. Exporting Cursor Assets

For Linux (X11 Mouse Cursor - .xmc):

  1. Navigate to File > Export As... and name the file with the .xmc extension.
  2. In the export dialog:
    • Set the Hotspot X and Hotspot Y coordinates (the exact pixel location that registers clicks, typically 0, 0 for standard pointers).
    • Confirm the frame delay defaults to your layer metadata.
  3. Click Export.

For Windows Animated Cursors (.ani):

GIMP does not natively export the proprietary Windows .ani container directly:

  1. Export the layer sequence as an animated GIF (File > Export As > .gif) with As Animation checked, or export as a horizontal PNG sprite sheet using Image > Canvas Size.
  2. Import the resulting GIF or sprite sheet into an open-source cursor compiler (such as anicursorgen) to assign the click hotspot and output the final .ani binary.

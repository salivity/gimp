How to Link Vector Paths to Layers in GIMP

In GIMP, transforming a vector path and a raster layer simultaneously is achieved by using the application's built-in transform lock feature. By linking elements together across the Layers and Paths dialogs, any transformation—such as moving, scaling, rotating, or perspective shifting—applied to one element is immediately mirrored on the other. This guide covers the exact steps required to link and manipulate both elements in unison.

Step 1: Open the Layers and Paths Dialogs

To link the items, you need access to both the Layers tab and the Paths tab.

  1. Open your project in GIMP.
  2. Ensure the Layers dock is visible. If not, open it via Windows > Dockable Dialogs > Layers (or press Ctrl + L).
  3. Ensure the Paths dock is visible. If not, open it via Windows > Dockable Dialogs > Paths.

Step 2: Enable the Transform Lock on the Raster Layer

  1. Go to the Layers dialog.
  2. Find the raster layer you want to transform.
  3. In the space between the eye icon (visibility) and the layer thumbnail, click to reveal the chain-link icon. This icon toggles the "Lock transform" state for that layer.

Step 3: Enable the Transform Lock on the Vector Path

  1. Switch to the Paths dialog.
  2. Locate the vector path you want to pair with the raster layer.
  3. Click the empty space between the eye icon and the path preview to reveal the chain-link icon for the path.

Step 4: Perform the Transformation

Once both items display the chain-link icon, any transformation tool will affect them together automatically.

  1. Select any transformation tool from the Tools panel (e.g., Move Tool, Scale Tool, Rotate Tool, or Unified Transform Tool).
  2. In the Tool Options panel, ensure the Transform mode is set to Layer (the default setting).
  3. Click on your canvas and execute the transformation.

Both the raster layer and the linked vector path will transform simultaneously, maintaining their exact spatial relationship and proportions.

Step 5: Unlink the Elements

Once you have finished the operation, click the chain-link icons in both the Layers and Paths dialogs to disable them. Disabling the lock ensures you do not accidentally move or alter one element when editing the other later.

Design Print-Ready CD Jewel Case Inserts in GIMP

Designing professional, print-ready CD jewel case inserts in GIMP requires precise dimensions, high-resolution canvas settings, and proper bleed management. This guide walks you through the step-by-step process of creating both the front cover booklet and the back tray inlay (including side spines), setting up guides for safe printing zones, and exporting your final graphics for optimal print quality.

1. Determine Standard CD Insert Dimensions

Standard jewel cases require two separate inserts: the front cover and the back tray card. To ensure high-quality printing, always work at 300 DPI (dots per inch) and include a 1/8-inch (3mm) bleed on all sides to prevent white edges after cutting.

  • Front Cover (Single Sheet):
    • Trim Size: 4.75" x 4.75" (120mm x 120mm)
    • Bleed Size: 5.00" x 5.00" (127mm x 127mm)
  • Back Tray Inlay (with Spines):
    • Trim Size: 5.90" x 4.625" (150mm x 117.5mm)
    • Bleed Size: 6.15" x 4.875" (156mm x 123.5mm)
    • Spine Widths: 0.25" (6.5mm) on both the left and right sides.

2. Set Up the Canvas in GIMP

  1. Open GIMP and navigate to File > New.
  2. Set the unit selector from pixels to Inches or Millimeters.
  3. For the Front Cover, enter 5.0 in width and 5.0 in height (including bleed).
  4. Expand Advanced Options:
    • Set X resolution and Y resolution to 300.000 pixels/in.
    • Set Color space to RGB color.
    • Set Fill with to White.
  5. Click OK.

3. Add Bleed and Safe Zone Guides

Guides keep your artwork aligned and prevent critical text from getting trimmed off during production.

  1. Go to Image > Guides > New Guide (by Percent).
    • Add a horizontal guide at 50% and a vertical guide at 50% for centering.
  2. Go to Image > Guides > New Guide... to create bleed lines:
    • Horizontal: 0.125 in and 4.875 in.
    • Vertical: 0.125 in and 4.875 in.
  3. Add a Safe Zone guide 0.125 inches inside the trim lines (0.25 in and 4.75 in from the canvas edges). Keep all important text, logos, and tracklists inside this safe boundary.

4. Design the Artwork

  1. Use Layer > New Layer to keep your elements separated (backgrounds, artwork, typography).
  2. Extend background colors and images fully to the edges of the canvas (into the bleed area).
  3. Place main titles, album artwork, and copyright notices within the safe zone guides.
  4. Use the Text Tool (T) to add your typography, adjusting kerning and line spacing via the Tool Options panel.

5. Set Up the Back Tray Inlay

  1. Create a new document: File > New.
  2. Set dimensions to 6.15 inches width and 4.875 inches height at 300 DPI.
  3. Add trim guides (0.125" from each outer edge).
  4. Add vertical spine guides to mark the fold lines:
    • Left Spine Fold: 0.375 in (0.125" bleed + 0.25" spine width).
    • Right Spine Fold: 5.775 in (6.15" canvas - 0.125" bleed - 0.25" spine width).
  5. Rotate spine text 90 degrees using the Rotate Tool (Shift + R) to run vertically down the left and right edges. Ensure the barcode and tracklist sit comfortably in the center panel between the spine folds.

6. Export for Print

  1. Save a master project file via File > Save As (.xcf format) to preserve your editable layers.
  2. Flatten or merge unnecessary layers if required by your print shop.
  3. Go to File > Export As....
  4. Select TIFF image or PDF from the file format dropdown.
  5. If exporting as TIFF, choose None or LZW for compression to avoid quality loss.
  6. If exporting as PDF, check the option to Apply layer masks before saving and ensure high-resolution rasterization is enabled.

Configure JPEG 2000 for Archival in GIMP

This guide explains how to properly configure JPEG 2000 (JP2) export settings in the GNU Image Manipulation Program (GIMP) to meet standard digital preservation requirements. Long-term archival preservation mandates zero image degradation, complete color fidelity, and the retention of technical and descriptive metadata. By configuring GIMP's OpenJPEG export engine correctly, you can create compliant master preservation files.

Step 1: Open the Export Dialog

  1. Open your master image in GIMP.
  2. Navigate to File > Export As....
  3. In the export window, type a file name ending in .jp2 (e.g., archival_master.jp2), or expand Select File Type (By Extension) at the bottom and select JPEG 2000 image.
  4. Click Export to bring up the JPEG 2000 options dialog.

Step 2: Configure Critical Archival Settings

In the Export Image as JPEG 2000 dialog, configure the following options to guarantee archival standards:

  • Format: Select jp2. The standard .jp2 container format supports essential color profile definitions and metadata wrappers, whereas raw codestreams (.j2k) do not.
  • Lossless: Enable (Check) this option. This is the single most critical setting for preservation. Enabling "Lossless" forces reversible 5/3 wavelet filter compression, ensuring that every pixel is preserved identically with zero visual or mathematical degradation.
  • Quality: When "Lossless" is checked, quality is locked or mathematically irrelevant. If the slider is active, set it to 100 to ensure no lossy rate-allocation algorithms are applied.
  • Tile size: Leave set to 0 (or disabled) unless standard multi-resolution streaming is explicitly required by your repository. A single-tile codestream prevents tiling artifacts and ensures simpler decodability for future software implementations.

Step 3: Retain Metadata and Color Profiles

Archival standards require embedded provenance and rendering data. Expand the Advanced Options and Metadata sections (if presented separately depending on your GIMP version):

  • Save color profile: Enable (Check). Archival master files must contain the embedded ICC profile (such as Adobe RGB 1998, ProPhoto RGB, or sRGB) to ensure accurate color reproduction across different display and print devices over time.
  • Save Exif data: Enable (Check) to retain hardware and capture settings.
  • Save XMP data: Enable (Check) to maintain preservation metadata, rights information, and structural schemas.
  • Save IPTC data: Enable (Check) to preserve cataloging and editorial tags.

Step 4: Finalize the Export

Click Export to generate your archival master file. Once exported, reopen the .jp2 file in GIMP and check Image > Image Properties to verify that dimensions, color profiles, and metadata channels remain intact.

Control Color Profiles and Thumbnails in GIMP JPEGs

When exporting JPEG images from GIMP, you can reduce file size or maintain color consistency by deciding whether to embed ICC color profiles and thumbnail previews. These settings are located within the JPEG export window under the expandable advanced parameters. This article explains how to find and configure the specific options that control both features, as well as how to set your preferences as defaults.

Accessing the JPEG Export Settings

To access the options for color profiles and thumbnails, initiate a standard export:

  1. Open your image in GIMP and go to File > Export As...
  2. Enter a filename ending in .jpg or .jpeg (or select JPEG from the file type list) and click Export.
  3. The Export Image as JPEG dialog box will appear.
  4. Click the small arrow or plus sign next to Advanced Options to expand the full list of export controls.

The Options Controlling Profiles and Thumbnails

Inside the Advanced Options section, two specific checkboxes determine whether this data is included:

  • Save color profile: Checking this box embeds the image's current ICC color profile (such as sRGB or Adobe RGB) directly into the JPEG file. This ensures that web browsers, operating systems, and image viewers interpret the colors correctly. If you uncheck this box, the color profile is discarded, slightly reducing the file size, though colors may render inconsistently on non-standard displays.
  • Save thumbnail: Checking this box generates and embeds a tiny, low-resolution preview image within the JPEG's metadata. File managers and image viewing software use this embedded thumbnail to display quick previews without decoding the entire image. Unchecking this box removes the thumbnail to save a small amount of disk space.

Making Settings Permanent

If you frequently export images with the same settings, adjust the Save color profile and Save thumbnail checkboxes to your liking, then click the Save Defaults button at the bottom of the dialog. GIMP will remember your selections for all subsequent JPEG exports.

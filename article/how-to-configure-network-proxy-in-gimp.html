How to Configure Network Proxy in GIMP

GIMP provides dedicated network configuration options within its preferences menu to manage how the application connects to the internet for remote update checks and online resources. Configuring these proxy settings allows users operating behind corporate firewalls, VPNs, or private proxy servers to ensure GIMP can securely fetch software update notifications and download external resources without connectivity interruptions.

Accessing Network Preferences in GIMP

To view and modify proxy settings in GIMP:

  1. Open GIMP.
  2. Navigate to Edit > Preferences (on macOS, select GIMP > Preferences).
  3. In the left-hand sidebar of the Preferences dialog, scroll down and click on Network.

Available Proxy Configuration Options

Under the Network tab, GIMP offers three primary modes for handling network traffic:

  • Direct connection to the Internet: GIMP bypasses any local proxy servers and connects directly to the web. This is the default setting for standard home connections.
  • System proxy configuration: GIMP inherits and applies the network proxy settings already defined by your operating system (such as system settings in Windows, macOS, or desktop environments like GNOME/KDE in Linux).
  • Manual proxy configuration: Allows you to explicitly specify custom proxy servers and authentication details.

Manual Proxy Settings

Selecting the manual option unlocks several specific configuration fields:

  • HTTP Proxy: The hostname or IP address and the port number used for standard HTTP traffic (e.g., proxy.example.com and port 8080).
  • Secure HTTP (HTTPS) Proxy: The hostname or IP address and port number used for encrypted HTTPS connections, which are typically required for secure update checks and package downloads.
  • Proxy Authentication: If your network's proxy server requires credentials to grant access, you can input:
    • Username: The account name registered with the proxy service.
    • Password: The corresponding password.
  • Ignore Proxy For: A field allowing you to specify a comma-separated list of hostnames, IP addresses, or local domains (such as localhost, 127.0.0.1) that should be accessed directly without routing through the proxy.

Remote Update Options

Directly above the proxy settings in the same menu is the Check for updates option. Enabling this toggle allows GIMP to query remote servers via the configured proxy to check whether a newer version of the application has been released.

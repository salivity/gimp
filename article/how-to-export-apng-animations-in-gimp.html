How to Export APNG Animations in GIMP

Exporting layered animations as Animated Portable Network Graphics (APNG) in GIMP allows you to create high-quality, 24-bit color animations with full alpha transparency, surpassing the limitations of traditional GIFs. This guide provides a direct, step-by-step walkthrough on organizing your project layers, configuring frame timing and disposal methods, and saving your final animation using GIMP's native PNG export settings.

1. Arrange and Name Your Layers

GIMP reads layers from the bottom up to generate animation frames. The lowest layer in the Layers panel serves as the first frame, and the top layer serves as the last.

  1. Open your project or create your artwork with each frame placed on an individual layer.
  2. Order your layers from bottom (Frame 1) to top (final Frame).
  3. (Optional) Set specific frame durations and disposal methods by renaming your layers. Double-click a layer name and append the duration in milliseconds and the mode in parentheses:
    • Timing: Add (100ms) to set that specific frame's display time to 100 milliseconds.
    • Disposal Mode: Add (combine) to overlay the frame onto the previous one, or (replace) to clear the previous frame before displaying the new one.
    • Example Layer Name: Frame 1 (150ms) (replace)

2. Preview the Animation

Before exporting, verify the timing and motion:

  1. Go to the top menu and select Filters > Animation > Playback...
  2. Click Play in the playback window to review your animation speed and transitions.
  3. Close the playback dialog once you are satisfied.

3. Export as APNG

  1. Click File > Export As...
  2. In the Name field, enter your file name ending with the .png extension (e.g., animation.png). Alternatively, expand Select File Type (By Extension) at the bottom and choose PNG Image.
  3. Click Export. The Export Image as PNG options dialog will appear.

4. Configure Export Settings

In the PNG export dialog window, enable the animation features:

  1. Check the box labeled As animation.
  2. Check Loop forever if you want the animation to repeat continuously, or leave it unchecked for a single playback.
  3. Set the Delay between frames where unspecified (default is usually 100 milliseconds). This value applies to any layer where a specific millisecond duration was not written into the layer name.
  4. Set the Frame disposal where unspecified to either Cumulative layers (combine) or One frame per layer (replace) based on your project design.
  5. Check Use delay entered above for all frames or Use disposal entered above for all frames only if you wish to override custom layer names.
  6. Click Export to finalize and generate your APNG file.

Configure Custom Search Paths in GIMP

Configuring custom search paths in GIMP allows you to store brushes, patterns, scripts, and plug-ins in custom directories—such as secondary storage drives or cloud-synced folders—without altering the default installation files. This guide explains how to define custom folder locations within GIMP's interface preferences, as well as how to configure system-level environment variables for advanced or automated setups.

Method 1: Configuring Custom Paths via Preferences (GUI)

The most direct way to add custom directories is through GIMP's internal preferences menu.

  1. Open the Preferences Dialog:

    • On Windows and Linux: Navigate to Edit > Preferences.
    • On macOS: Navigate to GIMP > Preferences.

  2. Locate the Folders Tree:

    • In the left sidebar of the Preferences window, scroll down to the bottom and find the Folders category.
    • Click the arrow or plus sign next to Folders to expand the list of resource types.

  3. Select Your Resource Type:

    • Click on the specific asset type you wish to manage: Brushes, Patterns, or Scripts.

  4. Add a New Directory:

    • In the right panel, you will see the default paths used by GIMP. Click the Add a new folder icon (represented by an empty sheet or a folder with a plus mark).
    • Click the Open a file selector button (the folder icon on the far right) to browse your computer and choose the custom folder.
    • Select the target directory and click OK.

  5. Set Permissions (Optional):

    • Next to each path, you can toggle the writable checkbox (a pencil icon). Enable this only if you want GIMP to save newly created or exported assets directly into that specific directory.

  6. Apply Changes:

    • Click OK at the bottom of the Preferences dialog to save the configuration.
    • Reload the assets immediately by clicking the Refresh button at the bottom of the respective dockable dialog (Brushes, Patterns, or Script-Fu menu via Filters > Script-Fu > Refresh Scripts), or restart GIMP.

Method 2: Configuring Paths via Environment Variables

For advanced multi-user environments, portable installations, or automated workflows, you can override default search paths using operating system environment variables before launching GIMP.

User Profile Root Override

To redirect GIMP's entire user directory (which contains scripts, brushes, and the gimprc configuration):

  • Variable: GIMP2_DIRECTORY (for GIMP 2.10) or GIMP3_DIRECTORY (for GIMP 3.x)
  • Value: Set this to your desired root path (e.g., D:\GIMP_Profile). GIMP will automatically look for brushes/, patterns/, and scripts/ subdirectories inside this folder.

Plug-in and Script Path Overrides

To append additional locations for plug-ins and Python scripts specifically:

  • Variable: GIMP_PLUGIN_PATH
  • Value: A delimited list of folder paths (use a semicolon ; on Windows, or a colon : on Linux and macOS).

Setting the Variable

  • Windows: Open System Properties > Environment Variables, then add the variable under User variables or System variables.
  • Linux/macOS: Add the export command to your ~/.bashrc, ~/.zshrc, or launcher script: 
    export GIMP2_DIRECTORY="/path/to/custom_gimp_directory"

Method 3: Editing the gimprc Configuration File

If you manage environments via text configurations or scripts, you can edit the gimprc file directly instead of using the GUI.

  1. Locate your gimprc file inside the GIMP user profile folder:

    • Windows: %APPDATA%\GIMP\2.10\gimprc
    • Linux: ~/.config/GIMP/2.10/gimprc
    • macOS: ~/Library/Application Support/GIMP/2.10/gimprc

  2. Open the file in a plain text editor and append or modify the path directives:

    • Brushes: (brush-path "${gimp_dir}/brushes:/path/to/custom/brushes")
    • Patterns: (pattern-path "${gimp_dir}/patterns:/path/to/custom/patterns")
    • Scripts: (script-fu-path "${gimp_dir}/scripts:/path/to/custom/scripts")

  3. Save the file and start GIMP. The application will scan all defined paths sequentially on startup.

GIMP: Assign vs Convert to Color Profile

Understanding the difference between "Assign Color Profile" and "Convert to Color Profile" in GIMP is essential for maintaining accurate colors in your images. In short, Assign Color Profile changes how GIMP interprets the image's existing color data without altering the underlying pixel values, which usually changes the image's visual appearance. In contrast, Convert to Color Profile recalculates and changes the underlying pixel values to preserve the visual appearance of the image as closely as possible within a new color space.

What Does "Assign Color Profile" Do?

Every digital image is made of pixel values (such as specific RGB numbers). A color profile acts like a dictionary that tells GIMP how those numbers should look in the real world.

When you use Image > Color Management > Assign Color Profile:

  • Pixel data remains unchanged: The raw RGB numbers of each pixel stay exactly the same.
  • Interpretation changes: GIMP replaces the current profile "tag" with a new one.
  • Visual appearance changes: Because the same numbers are now being read through a different color profile, the colors on your screen will shift, often becoming significantly more saturated, desaturated, or shifting in hue.

When to Use Assign Color Profile

Use this option when an image has the wrong color profile attached or has no profile embedded at all. For example, if you open a photograph taken in the Adobe RGB color space, but GIMP opened it as untagged sRGB (making it look flat and washed out), assigning Adobe RGB restores the intended colors.

What Does "Convert to Color Profile" Do?

When you use Image > Color Management > Convert to Color Profile:

  • Visual appearance is preserved: GIMP's primary goal during conversion is to keep the image looking identical (or as close as possible) to how it currently looks.
  • Pixel data changes: GIMP recalculates the actual RGB numbers of the pixels so they represent the same visual colors within the target color space.
  • Gamut mapping occurs: If the new color space is smaller than the original (for example, moving from Adobe RGB to sRGB), GIMP maps out-of-gamut colors to the closest available equivalents using the chosen rendering intent (such as Perceptual or Relative Colorimetric).

When to Use Convert to Color Profile

Use this option whenever an image already looks correct, but you need it in a different color space for a specific workflow. The most common scenario is converting an image from a wide-gamut profile (like ProPhoto RGB or Adobe RGB) to sRGB so it displays properly on web browsers and standard monitors.

Summary of Differences

  • Assign Color Profile: Keeps the numbers, changes the look. Use it to fix an image that has been assigned the incorrect profile.
  • Convert to Color Profile: Keeps the look, changes the numbers. Use it to prepare an image for a specific destination (such as the web or print).

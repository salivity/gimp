How to Create Interlocking Knotwork in GIMP

This guide explains how to design seamless, interlocking vector knotwork in GIMP using the Paths tool, stroke styling, and layer masking. By plotting a geometric skeleton of paths and systematically breaking intersections through selection and mask operations, you can produce intricate, interwoven designs with precise over-and-under transitions directly within GIMP's raster-vector hybrid environment.

1. Configure the Canvas and Grid

Accurate knotwork requires geometric precision. Create a new image with equal dimensions (for example, 1000 x 1000 pixels). Navigate to Image > Configure Grid and set the grid spacing to a uniform size, such as 50 pixels. Enable visibility and snapping by checking both View > Show Grid and View > Snap to Grid.

2. Design the Path Framework

Select the Paths Tool (shortcut: B). Click along the grid intersections to plot the central axes of your knot ribbons. Keep the curves smooth by clicking and dragging handles tangentially to the grid lines. Ensure your paths cross each other at clear angles where the weave will occur. If your knotwork is symmetrical, plot one quadrant or half, duplicate the path in the Paths Dialog, and use the Flip Tool (set to "Path" mode) to mirror the framework.

3. Generate the Base Ribbons

Knotwork requires both a body width and distinct borderlines.

  1. Create a new transparent layer named "Ribbon Base."
  2. Open the Paths Dialog, right-click your combined path, and choose Stroke Path.
  3. Choose Stroke line, set the line style to a solid line with a round cap and join, and assign a generous width (e.g., 30 pixels). Select a fill color and click Stroke.
  4. Create another layer above it named "Ribbon Outlines."
  5. Right-click the path again, select Stroke Path, set the width slightly larger than the base (e.g., 36 pixels), and stroke using a contrasting outline color (such as black). Move the "Ribbon Outlines" layer below "Ribbon Base" to create a defined border, or use Edit > Stroke Selection after converting the path to an outline selection.

4. Separate Path Segments for Interlocking

To make paths weave over and under one another, the continuous strokes must be broken at intersection points.

  1. Determine the alternating pattern (Over, Under, Over, Under) for every crossing point along the ribbon.
  2. In the Paths Dialog, click Path to Selection (or Shift + V) to load the shape of the knot.
  3. Select the Free Select (Lasso) Tool or Rectangle Select Tool.
  4. Hold Ctrl (or set mode to "Intersect with the current selection") and drag a selection boundary tightly around an intersection where the ribbon must pass underneath another segment.
  5. With the target area selected, add a Layer Mask to the "Ribbon Base" and "Ribbon Outlines" layers (set to "White / Full Opacity").
  6. Paint with black inside the selection on the layer mask to hide the segment, allowing the crossing ribbon to appear uninterrupted on top.

5. Create Depth with Gap Offsets

To emphasize the over-under vector appearance, introduce a visual gap between the overlapping ribbons:

  1. Turn the crossing path segment into a selection via the Paths tool or by using Alpha to Selection on the top-layer ribbon.
  2. Expand the selection slightly by going to Select > Grow (e.g., by 3 to 5 pixels).
  3. Switch to the Layer Mask of the underlying ribbon layer and fill this grown selection with black. This creates a clean, uniform gap that cleanly separates the overlapping strands.

6. Export and Finalize

Review all intersections sequentially to verify that the over-under rhythm remains consistent throughout the entire design. Once verified, you can link the layers together, apply shading to the masked borders for added depth, or convert the final silhouette back to a unified vector path using Select > To Path.

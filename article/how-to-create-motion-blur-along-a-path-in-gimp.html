How to Create Motion Blur Along a Path in GIMP

Creating dynamic motion blur along a custom trajectory in GIMP allows you to simulate realistic, curved movement that standard linear blur filters cannot replicate. This guide explains how to isolate your subject, draw a custom trajectory using the Paths Tool, and stroke that path using configured brush dynamics to produce a smooth, directional motion trail.

Step 1: Isolate the Subject on a New Layer

  1. Open your image in GIMP.
  2. Use the Free Select Tool (Lasso) or Paths Tool (B) to trace around the object you want to blur.
  3. Press Ctrl + C to copy the selection and Ctrl + V to paste it.
  4. In the Layers panel, click the green New Layer icon to place the copied subject onto its own transparent layer. Name this layer Subject Blur.

Step 2: Draw Your Custom Motion Path

  1. Select the Paths Tool from the toolbox or press B.
  2. Click on the canvas to place anchor points mapping out the dynamic trajectory of the motion.
  3. Click and drag the handles to bend the path into the desired curve or direction of travel.

Step 3: Configure the Paint Tool and Dynamics

  1. Select the Smudge Tool or the Paintbrush Tool from the toolbox.
  2. Choose a soft-edged brush (such as 2. Hardness 050).
  3. In the Tool Options panel:
    • Set the brush size relative to the thickness of the blur you want.
    • Open the Dynamics dropdown and select Track Direction or Dynamics Random depending on the desired texture.
    • Under Dynamics Options, ensure the fade length and direction correspond to the speed and length of the movement.
  4. Set the Rate or Opacity to roughly 40–60% to maintain a translucent trail.

Step 4: Stroke the Path

  1. Ensure the Subject Blur layer is active in the Layers panel.
  2. Open the Paths panel (Windows > Dockable Dialogs > Paths).
  3. Right-click your custom path and select Stroke Path.
  4. In the dialog box, select Stroke with a paint tool.
  5. Set the tool dropdown to the tool you configured (Smudge or Paintbrush).
  6. Check the box for Emulate brush dynamics and click Stroke.

Step 5: Refine and Blend the Effect

  1. If the blur trail is too subtle, right-click the path and repeat the Stroke Path operation, or duplicate the blurred layer (Ctrl + Shift + D) and merge down.
  2. To enhance the sense of speed, apply a subtle standard blur by going to Filters > Blur > Linear Motion Blur and matching the angle to the start of the path.
  3. Add a Layer Mask to the Subject Blur layer by right-clicking the layer and selecting Add Layer Mask > White (full opacity).
  4. Use a soft black brush on the mask to reveal crisp details on the leading edge of the moving object while keeping the trailing path blurred.

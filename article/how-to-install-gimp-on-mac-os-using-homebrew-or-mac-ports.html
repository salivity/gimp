How to Install GIMP on macOS Using Homebrew or MacPorts

This guide provides a straightforward walkthrough on how to install the GNU Image Manipulation Program (GIMP) on macOS using two leading command-line package managers: Homebrew and MacPorts. Using a package manager automates the download, dependency resolution, and installation process, allowing you to install, update, and manage GIMP directly from your macOS Terminal.

Installing GIMP with Homebrew

Homebrew installs GIMP as a macOS application bundle using the Homebrew Cask repository.

Step 1: Open Terminal

Launch the Terminal application on your Mac by pressing Cmd + Space to open Spotlight, typing Terminal, and pressing Enter.

Step 2: Update Homebrew

Ensure Homebrew and its package definitions are up to date by running:

brew update

Step 3: Install GIMP

Execute the following command to download and install the official GIMP application:

brew install --cask gimp

Once the command finishes, GIMP will be located in your /Applications directory and can be launched via Spotlight or Finder.

Useful Homebrew Commands for GIMP

  • Update GIMP: brew upgrade --cask gimp
  • Uninstall GIMP: brew uninstall --cask gimp

Installing GIMP with MacPorts

MacPorts builds GIMP from source or installs pre-compiled binary packages alongside required dependencies.

Step 1: Open Terminal

Open your Terminal application.

Step 2: Update MacPorts

Make sure your MacPorts tree and base system are completely updated:

sudo port selfupdate

(Enter your macOS administrator password when prompted.)

Step 3: Install GIMP

Run the installation command:

sudo port install gimp

MacPorts will resolve and install all underlying dependencies before installing GIMP. Because of the number of dependencies, this process may take several minutes. Once complete, you can launch GIMP directly from your terminal by typing gimp or find the shortcut within your /Applications/MacPorts folder.

Useful MacPorts Commands for GIMP

  • Update GIMP: sudo port upgrade gimp
  • Uninstall GIMP: sudo port uninstall gimp

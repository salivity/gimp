Import RAW Images in GIMP with Darktable or RawTherapee

GIMP does not natively decode camera RAW files on its own, relying instead on integrated open-source RAW processors like Darktable or RawTherapee. This guide details how to install, configure, and use either processor to seamlessly import, develop, and edit RAW photographs inside GIMP.

Prerequisites

Before starting, ensure that:

  • You have a modern version of GIMP installed (version 2.10 or later).
  • You have either Darktable or RawTherapee installed on the same computer.
  • Both GIMP and the chosen RAW developer share the same architecture (for example, both must be 64-bit).

Method 1: Importing RAW Files Using Darktable

Darktable is often the default RAW plug-in for GIMP on most operating systems.

  1. Install Darktable: Download and install Darktable using the standard installer for your operating system.
  2. Open the RAW File in GIMP:
    • Launch GIMP.
    • Go to File > Open.
    • Browse to your RAW image (.CR2, .CR3, .NEF, .ARW, .DNG, etc.) and click Open.
  3. Develop in Darktable:
    • GIMP will automatically detect the RAW file and launch the Darktable interface in a separate window.
    • Apply your desired adjustments such as exposure, white balance, lens correction, and noise reduction.
  4. Export Back to GIMP:
    • When finished editing, close the Darktable application window (click the X in the top corner).
    • Darktable will automatically process the image and send the resulting full-resolution image directly into GIMP as a new layer.

Method 2: Importing RAW Files Using RawTherapee

If you prefer RawTherapee over Darktable, GIMP supports it natively as well.

  1. Install RawTherapee: Download and install the latest stable version of RawTherapee.
  2. Open the RAW File in GIMP:
    • Launch GIMP and go to File > Open.
    • Select your RAW file and click Open.
  3. Develop in RawTherapee:
    • RawTherapee will launch automatically with the image loaded into the editor panel.
    • Make your exposure, color, and sharpening corrections.
  4. Send to GIMP:
    • Click the Send to external editor icon (located at the bottom-left corner of the image preview area, typically represented by a painter's palette or an external application icon) or press Ctrl + E (Windows/Linux) / Cmd + E (macOS).
    • RawTherapee processes the changes and opens the photo inside GIMP. Close RawTherapee once the transfer is complete.

How to Switch Between Darktable and RawTherapee in GIMP

If you have both applications installed, you can choose which one GIMP uses by default:

  1. In GIMP, navigate to Edit > Preferences (or GIMP > Preferences on macOS).
  2. In the left sidebar, click on Image Import & Export.
  3. Under the Raw Image Importer section, select either darktable or RawTherapee from the dropdown menu.
  4. Click OK to save your selection.

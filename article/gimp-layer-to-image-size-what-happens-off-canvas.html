GIMP Layer to Image Size: What Happens Off-Canvas

When you invoke the "Layer to Image Size" command in GIMP, the software resizes the active layer's boundary to match the exact dimensions and position of the current image canvas. Consequently, any layer content or pixels located outside the canvas boundary are permanently cropped and discarded.

Immediate Pixel Deletion

In GIMP, layers can naturally exist with dimensions larger than the canvas itself, allowing you to store and move elements outside the visible viewport without losing data. However, the Layer > Layer to Image Size command forces the active layer to match the image canvas boundaries.

Any visual content that extends beyond the canvas edge is severed during this operation. This means:

  • Irreversible Cropping: The clipped pixels are completely deleted from the layer, not merely masked or hidden.
  • Loss on Future Canvas Expansion: If you later increase the image canvas size using Image > Canvas Size, the cropped areas will remain empty transparent space rather than revealing the previously existing off-canvas pixels.
  • Loss on Movement: If you use the Move tool to drag the layer across the canvas, the cut-off portions will no longer exist.

Expansion of Smaller Layers

If a layer is smaller than the image canvas or positioned offset from the corners, the command expands the layer boundary outward to fill the canvas. The newly added area surrounding the original layer content becomes transparent. In this scenario, existing pixels are preserved, but the layer boundary is enlarged to match the project frame.

Alternatives to Prevent Data Loss

If your goal is to align or organize layers without permanently destroying off-canvas data, consider the following alternatives:

  • Use Layer Masks: If you only want to hide parts of a layer outside a certain region, apply a layer mask instead. Masks visually conceal data without deleting the underlying pixels.
  • Fit Canvas to Layers: If you want all off-canvas content visible without losing anything, select Image > Fit Canvas to Layers, which expands the canvas to encompass the largest layer boundaries.
  • Undo Immediately: If you invoke the command by mistake, press Ctrl + Z (Windows/Linux) or Cmd + Z (macOS) immediately to restore the cropped off-canvas pixels.

Configure GIMP Ink Tool for Asian Calligraphy

This guide explains how to configure the Ink tool in GIMP to simulate the expressive, dynamic strokes of traditional East Asian calligraphy (such as Chinese Shufa or Japanese Shodo). By fine-tuning the Ink tool's specialized velocity controls, nib geometry, and sensitivity settings, you can replicate the organic behavior of a sumi brush, where stroke width dynamically responds to your drawing speed and direction.

1. Select the Ink Tool and Set the Base Parameters

Activate the Ink tool from the toolbox or by pressing the K key. In the Tool Options dock, begin with these foundational settings:

  • Size: Set between 15.0 and 25.0 pixels depending on your canvas resolution. This defines the maximum stroke width achievable during slow, deliberate presses.
  • Angle: Set to roughly -45° to -30°. Traditional calligraphy brushes meet the paper at a natural diagonal slant, producing broad diagonal strokes and razor-thin cross-strokes.

2. Configure the Nib Shape

Traditional brush tufts deform into asymmetric, pointed profiles when dragged across rice paper. In the Shape section:

  • Type: Choose Diamond or Circle. The Diamond type yields crisp, authentic directional transitions similar to stiffer weasel-hair brushes (langhao), while Circle behaves more like softer goat-hair brushes (yanghao).
  • Shape (Aspect Ratio): Drag the slider to flatten the nib horizontally, creating an elliptical or diamond profile. An aspect ratio value between 0.20 and 0.40 provides strong contrast between thick vertical downstrokes and thin horizontal transitions.

3. Adjust Velocity and Size Sensitivity

The Ink tool uses an internal algorithmic curve to calculate stroke width based on cursor velocity rather than standard tablet pressure dynamics. Expand the Sensitivity settings within the Ink Tool Options:

  • Size (Velocity Sensitivity): Set this slider between 0.70 and 0.90. A higher value increases the disparity between fast and slow movements. Slow movements will allow the stroke to swell to its maximum width, mimicking ink pooling during deliberate brush contact.
  • Tilt Sensitivity: If using a mouse or non-tilt stylus, leave this at 0.00. If using a stylus with tilt capability, set it to 0.20 to introduce subtle line variations when tilting the pen.
  • Speed: Set between 0.60 and 0.80. This slider dictates how quickly the brush reaches its minimum stroke size as hand speed increases. A higher value ensures that swift flicking motions taper smoothly into sharp, wispy points.

4. Calibrating Stroke Mechanics

To write authentically with these settings, adjust your stroke mechanics to match traditional calligraphy principles:

  • Tome (Stops): Pause momentarily at the beginning and end of strokes. The low velocity triggers maximum ink expansion, forming the distinct, weighted anchor points typical of standard script (Kaishu).
  • Harau (Sweeps) and Hane (Hooks): Accelerate your stroke rapidly off the canvas. As speed peaks, the velocity curve forces the ink profile down to its minimum width, rendering sharp, natural points without requiring manual opacity or size adjustments.

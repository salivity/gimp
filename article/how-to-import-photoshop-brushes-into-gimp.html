How to Import Photoshop Brushes into GIMP

This guide explains how to import Adobe Photoshop brush libraries (.abr files) directly into GIMP. Because GIMP includes native support for the .abr file format, you do not need third-party conversion tools to expand your digital painting toolkit. By copying your brush files into the designated GIMP directory and refreshing your brush palette, you can start using Photoshop brushes in your GIMP projects within minutes.

Step 1: Prepare Your Photoshop Brush Files

  1. Download the Photoshop brush file to your computer.
  2. If the brush comes in a compressed archive (such as a .zip, .rar, or .7z file), extract it to reveal the .abr file inside.

Step 2: Locate the GIMP Brushes Directory

The easiest and most accurate way to find your brushes folder is directly through the GIMP interface:

  1. Open GIMP.
  2. Go to Edit > Preferences (on macOS, select GIMP > Preferences).
  3. In the left panel, scroll down to the Folders section and click the arrow or plus icon to expand it.
  4. Select Brushes.
  5. You will see two folder paths listed:
    • System folder: Read-only directory used by the program installation.
    • User folder: Writable directory associated with your user account.
  6. Click the user folder path to highlight it, then click the Show file location in the file manager button (represented by a file cabinet or folder icon) in the top-right corner of the window. This opens the folder directly in your operating system's file explorer.

Alternatively, navigate to the default paths manually:

  • Windows: C:\Users\<Your_Username>\AppData\Roaming\GIMP\2.10\brushes
  • macOS: /Users/<Your_Username>/Library/Application Support/GIMP/2.10/brushes
  • Linux: /home/<Your_Username>/.config/GIMP/2.10/brushes

Step 3: Copy the .abr File

  1. Open the folder containing your downloaded .abr file.
  2. Copy the .abr file (or files).
  3. Paste the file directly into the GIMP brushes folder you opened in Step 2.

Step 4: Refresh Brushes in GIMP

You do not need to restart GIMP for the changes to take effect:

  1. Return to the GIMP interface.
  2. Open the Brushes dockable dialog by navigating to Windows > Dockable Dialogs > Brushes.
  3. At the bottom of the Brushes dialog, click the Refresh brushes icon (a circular arrow).

Your imported Photoshop brushes will appear immediately in the brush list, ready for use with the Paintbrush, Pencil, Airbrush, or Eraser tools.

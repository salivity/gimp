How to Split or Cut a Vector Path in GIMP

Cutting a vector path into separate segments in GIMP is a simple process once you understand how the Paths tool handles anchor points and line segments. This guide explains how to split an open or closed path into distinct sections by inserting target nodes, deleting connecting line segments using keyboard shortcuts, and optionally separating the results into individual path layers.

Step 1: Select the Path and the Paths Tool

  1. Open your project in GIMP and navigate to the Paths dockable dialog (go to Windows > Dockable Dialogs > Paths if it is not visible).
  2. Click on the path you want to modify to make it active, and click the eye icon next to it to ensure it is visible on the canvas.
  3. Select the Paths Tool from the Toolbox or press the shortcut key B.

Step 2: Add Anchor Points (If Necessary)

If you want to cut the path at a location where no anchor point currently exists:

  1. Ensure the Paths tool mode is set to Design in the Tool Options panel.
  2. Click directly on the path line where you want the split to occur. This creates a new anchor node at the desired cut point.

Step 3: Delete the Connecting Segment

To split a continuous line into two separate segments, you must remove the line segment connecting two nodes:

  1. Hover your mouse over the line segment directly adjacent to the point where you want the cut.
  2. Press and hold Ctrl + Shift on Windows/Linux (or Cmd + Shift on macOS). The cursor will change, displaying a small minus or scissor symbol.
  3. With the keys held down, click the line segment.

The connecting line will disappear immediately, leaving two separate endpoints and effectively cutting the path into two distinct segments.

Step 4: Separate into Distinct Path Layers (Optional)

Deleting a segment splits the line visually, but both segments remain part of the same path object in the Paths dialog. If you need them as completely separate path layers:

  1. Ensure the path is active and go to the Paths tool options.
  2. Choose Path from Selection or manually copy and paste the desired segment components:
    • In the Paths dialog, right-click your path and choose Path to Selection.
    • Switch to a selection tool (like the Rectangle Select tool), hold Ctrl to subtract the unwanted portion of the selection.
    • Go back to the Paths dialog and click the Selection to Path button at the bottom.
  3. Repeat the process for the second half to obtain two independent path items in your list.

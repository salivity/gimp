Understanding GIMP Vivid Light Blend Mode

The Vivid Light blend mode in GIMP is an extreme contrast-enhancing tool that dynamically alters an image's tonal values based on the brightness of the active layer. By using neutral 50% gray as a threshold, Vivid Light applies Color Burn to darken tones beneath pixels darker than mid-gray and Color Dodge to brighten tones beneath pixels lighter than mid-gray. This dual-action approach produces intense, punchy results characterized by deeply saturated colors and high contrast.

The 50% Gray Threshold

In digital imaging, neutral gray represents a luminance value of 50% (an RGB value of 128 on an 8-bit scale from 0 to 255). In GIMP's Vivid Light mode, this mid-point serves as the neutral dividing line:

  • Blend pixels at exactly 50% gray have no effect on the underlying base layer.
  • Blend pixels darker than 50% gray trigger the Color Burn algorithm.
  • Blend pixels lighter than 50% gray trigger the Color Dodge algorithm.

Darker Pixels: Activating Color Burn

When a pixel on the blend layer has a brightness value below 50% gray, Vivid Light behaves like an intensified Color Burn.

Instead of standard darkening methods like Multiply, Color Burn increases contrast by heavily compressing midtones and driving darker values toward pure black. As a result, any areas on the base layer corresponding to dark areas on the blend layer experience significant darkening, shadow crushing, and an increase in color saturation. Pure black on the blend layer forces the underlying base pixel directly to black.

Lighter Pixels: Activating Color Dodge

When a pixel on the blend layer has a brightness value above 50% gray, Vivid Light transitions to an intensified Color Dodge.

Unlike gentle brightening methods like Screen, Color Dodge decreases contrast in the upper midtones while aggressively pushing highlights toward pure white. Base layer pixels under light blend pixels are blown out and brightened rapidly, creating vivid, high-key highlights. Pure white on the blend layer forces the underlying base pixel directly to white.

Comparison to Other Contrast Modes

Vivid Light belongs to the contrast-blending family alongside Overlay, Soft Light, Hard Light, and Linear Light. While Overlay and Hard Light combine Multiply and Screen for a natural tonal curve, Vivid Light combines the harsher curves of Color Burn and Color Dodge. This makes Vivid Light far less subtle, producing sharp cutoffs, clipped highlights, deep shadows, and extreme saturation shifts unless the layer opacity is significantly reduced.

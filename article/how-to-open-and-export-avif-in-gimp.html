How to Open and Export AVIF in GIMP

This article explains how GIMP handles the modern AVIF image format and identifies the specific library responsible for enabling its support. Starting with version 2.10.22, GIMP can natively read and export AVIF files without requiring third-party plugins, relying directly on the open-source libheif library. Below is a breakdown of the library dependencies, version requirements, and the direct steps to view and save AVIF images in GIMP.

The Library Behind GIMP's AVIF Support

GIMP relies on the libheif library to read and export AVIF files. Within GIMP's source architecture, this is implemented through a built-in plug-in called file-heif.

libheif acts as a container parser and multiplexer for both HEIC and AVIF file formats. To handle AV1 image data inside the AVIF container, libheif relies on underlying AV1 codec libraries:

  • Encoding/Decoding: libaom (Alliance for Open Media reference codec)
  • Fast Decoding: dav1d
  • Fast Encoding: rav1e or SVT-AV1

As long as libheif is compiled with an active AV1 codec, GIMP can seamlessly load, edit, and save AVIF files.

System and Version Requirements

  • GIMP 2.10.22 or Newer: Native AVIF reading and writing is bundled out of the box in the official GIMP installers for Windows and macOS, as well as the official Flathub builds for Linux.
  • Linux Distribution Repositories: If you compile GIMP from source or install it via distribution package managers (such as APT, Pacman, or DNF), ensure that your system has libheif installed along with its AVIF decoding/encoding plugins (such as libheif-plugins or specific aom plugins depending on your distribution).

How to Open AVIF Files in GIMP

  1. Launch GIMP.
  2. Go to File > Open.
  3. Select your .avif file and click Open. GIMP processes the image through libheif and displays it directly on the canvas.

How to Export Images as AVIF in GIMP

  1. Open or create an image in GIMP.
  2. Go to File > Export As....
  3. In the export dialog, either type .avif at the end of the file name or expand the Select File Type (By Extension) menu and select HEIF/AVIF.
  4. Click Export.
  5. An export dialogue box will appear. Ensure the format/container is set to AVIF.
  6. Adjust your export settings:
    • Lossless: Check this box for mathematically identical compression.
    • Quality: Adjust the slider (lower values reduce file size, higher values preserve detail).
    • Bit Depth: Choose between 8-bit, 10-bit, or 12-bit color depth depending on your source material.
  7. Click Export to finalize the file.

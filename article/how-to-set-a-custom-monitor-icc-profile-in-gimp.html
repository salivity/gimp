How to Set a Custom Monitor ICC Profile in GIMP

Configuring GIMP to use a specialized monitor ICC profile ensures that the colors displayed on your screen precisely match the measurements captured by your hardware colorimeter. This guide walks through locating your calibrated profile, accessing GIMP's color management settings, selecting the custom profile, and choosing the appropriate rendering intent for consistent, color-accurate photo editing and digital artwork.

Step 1: Locate Your Calibrated ICC Profile

Hardware calibration tools (such as Datacolor Spyder, Calibrite Display, or open-source software like DisplayCAL) automatically generate and save an .icc or .icm profile to your operating system's default color directory. Ensure you know the file path:

  • Windows: C:\Windows\System32\spool\drivers\color
  • macOS: /Library/ColorSync/Profiles or ~/Library/ColorSync/Profiles
  • Linux: ~/.local/share/icc or /usr/share/color/icc

Step 2: Open GIMP's Color Management Preferences

  1. Launch GIMP.
  2. Open the Preferences window:
    • On Windows and Linux, click Edit in the top menu bar and select Preferences.
    • On macOS, click GIMP in the application menu bar and select Preferences.
  3. In the left-hand sidebar of the Preferences dialog, click on Color Management.

Step 3: Configure Color Management Mode

At the top of the Color Management pane, locate the Image display mode (or Color management mode depending on the GIMP version) dropdown menu. Set this option to Color managed display.

Step 4: Assign the Monitor ICC Profile

Under the Monitor profile section, you have two approaches:

  • Automatic Detection: Check the box labeled Try to use the system monitor profile. If your operating system already has the hardware calibration profile assigned as the active display profile, GIMP will detect and use it automatically.
  • Manual Selection: If GIMP does not recognize the profile, or if you want to ensure the exact profile is used:
    1. Uncheck Try to use the system monitor profile.
    2. Click the dropdown menu next to Monitor profile and select Select color profile from disk....
    3. Navigate to your operating system's color directory identified in Step 1.
    4. Select your custom .icc or .icm file generated by your colorimeter and click Open.

Step 5: Configure Rendering Intent

Adjust the rendering settings to control how out-of-gamut colors are handled:

  1. Locate Monitor rendering intent.
  2. Select Relative colorimetric (recommended for standard photography and graphic design) or Perceptual.
  3. Check the box labeled Use black point compensation to prevent shadow clipping and maintain detail in deep darks.

Step 6: Save and Apply

Click OK at the bottom of the Preferences dialog to apply the changes. Restart GIMP to ensure the display engine fully initializes the selected ICC profile across all active image windows.

How to Create a Custom Brush from Text in GIMP

Converting an active text layer into a reusable custom brush in GIMP allows you to stamp watermarks, logos, or typography directly onto your canvas with customized color and scaling. This workflow involves preparing your text with the proper transparency and tonal values, cropping the canvas to fit the design, exporting the layer in GIMP’s native brush format (.gbr), and refreshing the brush library so the new preset is instantly accessible.

Step 1: Format the Text Layer

  1. Select the Text Tool (T) and type your desired text onto the canvas.
  2. Choose your font, size, and styling using the Tool Options or on-canvas text editor.
  3. Ensure the text color is set appropriately:
    • Pure Black (#000000) on transparency: Best for standard brushes. This allows you to dynamically change the brush color using GIMP's active Foreground Color.
    • Grayscale: Lighter grays will act as varying levels of brush opacity.
    • Full Color: If you keep colors, the brush will stamp those exact colors regardless of the active Foreground Color.

Step 2: Isolate and Crop the Text

  1. Hide or delete any background layers so that your text sits over a transparent checkerboard pattern.
  2. In the Layers panel, right-click the text layer and select Discard Text Information if you want to flatten it to a standard raster layer (optional, but ensures rendering consistency).
  3. Go to Image > Crop to Content (or Autocrop Image in older versions) to shrink the canvas boundaries tightly around the text. This eliminates unnecessary blank space around the brush tip.

Step 3: Export as a GIMP Brush File

  1. Go to File > Export As...
  2. In the export dialog, expand Select File Type (By Extension) and choose GIMP brush (*.gbr).
  3. Navigate to your user brushes directory. If you do not know the path, locate it via Edit > Preferences > Folders > Brushes.
    • Windows typical path: C:\Users\[Username]\AppData\Roaming\GIMP\2.10\brushes
    • macOS typical path: /Users/[Username]/Library/Application Support/GIMP/2.10/brushes
    • Linux typical path: /home/[username]/.config/GIMP/2.10/brushes
  4. Name your file with the .gbr extension (e.g., my_text_brush.gbr) and click Export.
  5. In the pop-up window:
    • Description: Enter the display name that will appear in the GIMP interface.
    • Spacing: Set the default distance between brush stamps (typically 10% to 25% for text stamps to prevent overlap).
  6. Click Export.

Step 4: Refresh and Activate the Brush

  1. Open the Brushes dialog dock (Windows > Dockable Dialogs > Brushes).
  2. Click the Refresh Brushes icon (two looping arrows) at the bottom of the dialog to reload the brush folder without restarting GIMP.
  3. Search for the name you entered in the description field.
  4. Select the Paintbrush Tool (P), choose your new text brush, set your desired size and color, and click on any canvas to stamp your custom text.

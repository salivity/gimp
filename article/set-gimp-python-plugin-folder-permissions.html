Set GIMP Python Plugin Folder Permissions

To make GIMP recognize newly added Python plugins, the host folder must have directory read and execute permissions, while the plugin file itself must have explicit execute permissions enabled. Unlike standard Scheme (.scm) scripts that only require read access, GIMP treats Python plugins as external executables. Without the correct file system permissions—specifically the executable bit on Unix-like systems—GIMP will silently skip the plugin during startup, preventing it from appearing in the application's menus.

Required Directory Permissions

On Linux and macOS, the directory containing your Python plugins must have read, write, and execute permissions for the owner. At a minimum, permission mode 755 (drwxr-xr-x) or 700 (drwx------) must be set on the folder.

  • Read (r): Allows GIMP to list the files inside the directory.
  • Write (w): Allows your user account to add, update, or remove plugins.
  • Execute (x): Crucial for directories; allows the operating system and GIMP to enter the folder and access its metadata and contents.

To set the correct folder permissions via the terminal:

chmod 755 ~/.config/GIMP/2.10/plug-ins

Required Plugin File Permissions

Setting folder permissions alone is not enough for Python scripts. GIMP requires every Python plugin file (.py) to be marked as executable. Without execution rights, GIMP will ignore the file entirely.

The plugin file requires permission mode 755 (-rwxr-xr-x) or 700 (-rwx------). Apply this permission using the following command:

chmod +x ~/.config/GIMP/2.10/plug-ins/your_plugin.py

Note for GIMP 2.10 and later: GIMP often expects individual plugins to reside within their own subdirectories matching the script's name (e.g., plug-ins/my_plugin/my_plugin.py). Ensure both the subfolder and the script file inherit these execution permissions.

Windows Permission Requirements

On Windows, NTFS file systems do not use Unix permission bits, but file access restrictions can still prevent GIMP from running Python scripts:

  1. Right-click the plug-ins folder (typically located at %APPDATA%\GIMP\2.10\plug-ins) and select Properties.
  2. Navigate to the Security tab.
  3. Ensure your Windows user account has Read, Write, and Read & execute permissions set to "Allow".
  4. Ensure the .py script is not blocked by Windows security: right-click the .py file, select Properties, and check the Unblock box if it appears under the General tab.

Verifying Folder Paths in GIMP

After permissions are configured, confirm GIMP is actively scanning the folder:

  1. Open GIMP and navigate to Edit > Preferences.
  2. Expand the Folders list in the left pane and select Plug-ins.
  3. Confirm that the exact path to your permission-configured directory is listed and checked.
  4. Restart GIMP to register the newly recognized Python plugin.

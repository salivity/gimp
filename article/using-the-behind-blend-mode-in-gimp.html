Using the Behind Blend Mode in GIMP

GIMP’s Behind blend mode allows you to paint color exclusively onto transparent or semi-transparent areas of a layer, leaving any existing opaque pixels completely untouched. By effectively applying new strokes beneath your current artwork on the very same layer, this mode simplifies your workflow by eliminating the need to create, manage, and merge separate layers underneath your subject.

How the Behind Mode Works

In GIMP, standard painting with the "Normal" mode replaces or covers existing pixels on the active layer. When you switch a paint tool's mode to "Behind," this behavior is inverted.

The paint tool evaluates the alpha channel of the layer:

  • Fully Opaque Pixels: The tool recognizes existing opaque content as being "in front" of the new brush stroke. Consequently, the existing pixels act as a mask, blocking any new color from altering them.
  • Fully Transparent Pixels: The tool paints as it normally would, filling the transparency with the chosen color and opacity.
  • Semi-Transparent Pixels: The tool blends underneath the existing semi-transparent pixels, allowing anti-aliased edges and translucent colors to composite naturally on top of your new brush strokes.

The Requirement of an Alpha Channel

For the Behind mode to function, the active layer must have an alpha channel. If a layer lacks an alpha channel, GIMP cannot recognize transparency. Without transparency data, the tool interprets the entire layer as a flat, opaque surface, rendering the Behind mode ineffective and causing it to act like the standard Normal mode.

You can ensure your layer has transparency support by right-clicking the layer in the Layers dialog and selecting Add Alpha Channel.

Common Use Cases

  • Coloring Line Art: If you have clean line art on a transparent layer, Behind mode lets you color directly on that layer without worrying about drawing over your lines.
  • Adding Glows and Halos: You can paint light effects directly around a subject's silhouette without disturbing the subject's crisp edges.
  • Edge Cleanup: It enables you to fill gaps beneath soft, anti-aliased borders without creating harsh seams or altering the original foreground art.

How to Use Behind Mode

  1. Select a painting tool from the Toolbox, such as the Paintbrush, Pencil, or Bucket Fill.
  2. Locate the Tool Options dockable dialog.
  3. Open the Mode dropdown menu (which defaults to "Normal").
  4. Select Behind from the list.
  5. Paint directly onto the layer. The strokes will appear only on the transparent areas, flowing beneath the existing foreground pixels.

Design Custom Postage Stamps in GIMP

Creating custom postage stamp graphics in GIMP is a straightforward process that combines digital illustration techniques with simulated paper effects. This guide walks you through setting up a print-ready canvas, laying out the inner artwork and typography, generating realistic perforated borders using spaced brush strokes, and exporting the final design for high-resolution printing.

Step 1: Set Up the Canvas

  1. Open GIMP and go to File > New.
  2. Set the Template or change the units from pixels to Inches or Millimeters. A standard stamp size is roughly 1.0 x 1.5 inches (25.4 x 38.1 mm).
  3. Expand Advanced Options and set both the X resolution and Y resolution to 300 pixels/in to ensure high-quality printing.
  4. Set Fill with to Transparency and click OK.

Step 2: Create the Stamp Base

  1. Create a new layer named Stamp Base.
  2. Select the Rectangle Select Tool (R) and draw a box slightly smaller than your canvas to leave room for the perforations along the edges.
  3. Fill this selection with an off-white or vintage paper color using the Bucket Fill Tool (Shift + B).
  4. Keep the selection active, go to Select > Shrink, enter 15 to 20 pixels, and click OK.
  5. Add guides by going to Image > Guides > New Guide from Selection to mark the boundary for your artwork.

Step 3: Add Artwork and Typography

  1. Create a new layer group named Artwork placed above the Stamp Base layer.
  2. Import or draw your central graphic within the inner guides.
  3. Use the Text Tool (T) to add traditional stamp elements, such as the country of issue, the denomination (monetary value), and an optional year.
  4. Restrict all artwork within the inner margin so it does not interfere with the outer perforated edges.

Step 4: Create the Perforated Border

  1. Select the Stamp Base layer.
  2. Right-click the layer and select Alpha to Selection to select the stamp boundary.
  3. Go to Select > To Path to convert the outer edge into a vector path. You can now deselect by pressing Shift + Ctrl + A.
  4. Select the Paintbrush Tool (P). Choose the 2. Hardness 100 round brush.
  5. In the Tool Options, set the brush size to the desired perforation hole size (typically 12–18 pixels depending on canvas resolution).
  6. Open the Brushes dialog (Windows > Dockable Dialogs > Brushes), double-click the active brush, and adjust the Spacing slider to roughly 160% to 180% so the circles line up with consistent gaps.
  7. Switch the Paintbrush mode in Tool Options to Color Erase (with foreground set to your stamp base color) or apply a Layer Mask to the Stamp Base layer.
  8. Go to the Paths tab, right-click the path created earlier, and choose Stroke Path.
  9. Select Stroke with a paint tool, choose Paintbrush, and click Stroke. The brush will trace the edge, punching out evenly spaced circular notches along the boundary.

Step 5: Add Finishing Details and Export

  1. Add subtle drop shadows or an inner vignette using Filters > Light and Shadow > Drop Shadow to give the stamp a realistic paper depth.
  2. Once the design is complete, go to File > Export As.
  3. Choose PNG to preserve transparency around the perforated edges, or arrange multiple stamps onto a larger document (such as standard Letter or A4 size at 300 DPI) to print full perforated sheets.

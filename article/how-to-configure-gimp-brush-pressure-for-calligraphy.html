How to Configure GIMP Brush Pressure for Calligraphy

Achieving a natural calligraphic taper in GIMP requires creating a custom Paint Dynamic profile and fine-tuning the pressure response curves for brush size and opacity. By altering the default linear pressure response into an exponential or S-curve, you control how the digital ink flows from light entry strokes to heavy swells and sharp exit tapers. This guide outlines the exact steps to configure these dynamic curves, set up the dynamics matrix, and adjust tool smoothing for fluid, realistic calligraphy.

Step 1: Create a New Paint Dynamic

  1. Open GIMP and navigate to Windows > Dockable Dialogs > Paint Dynamics.
  2. Click the Create a new dynamics icon (the document with a plus sign) at the bottom of the dialog.
  3. Name your dynamic preset (for example, Calligraphy Taper).
  4. Open the Paint Dynamics Editor by going to Windows > Dockable Dialogs > Paint Dynamics Editor (or double-clicking your new preset).

Step 2: Configure the Dynamics Matrix

In the Paint Dynamics Editor matrix, define which tablet inputs control which brush outputs:

  • Check the box intersecting Pressure and Size. This scales brush thickness according to stylus force.
  • (Optional) Check the box intersecting Pressure and Opacity or Color if you want heavier pressure to deposit more saturated ink.
  • (Optional) Check Direction or Angle under Aspect Ratio if you are simulating a flat-nib chisel pen rather than a flexible pointed nib.

Step 3: Edit the Dynamic Pressure Curves

To achieve a natural, sharp taper, the relationship between hand pressure and brush size must not be linear.

  1. In the Paint Dynamics Editor, select the Size tab below the matrix to view its response curve.
  2. By default, the curve is a straight diagonal line from the bottom-left \((0,0)\) to the top-right \((1,1)\).
  3. Adjust the low-pressure threshold: Click and drag the lower-left portion of the line slightly downward and to the right, forming a subtle exponential curve. This prevents the brush from bloating instantly upon touching the tablet, allowing for hairline entry and exit strokes.
  4. Adjust the high-pressure swell: Create a slight S-curve by pulling the upper-right section upward. This allows the stroke to reach full width smoothly when intentional pressure is applied, preventing sudden steps in line weight.
  5. Pointed Taper Tuning: If your strokes end abruptly, pull the curve anchor near the bottom-left closer to the bottom axis. This forces the brush size to scale down to zero rapidly as pressure decreases.

Step 4: Configure Tool Options and Smoothing

  1. Select the Paintbrush tool (P).
  2. In the Tool Options panel, select your newly created dynamic from the Dynamics dropdown.
  3. Choose a solid, round brush tip with Hardness set between 0.75 and 1.00.
  4. If using a flat-edge calligraphy effect, set the brush Aspect Ratio to 3.0 or higher and set the Angle to 45.0.
  5. Enable Smooth Stroke in the Tool Options:
    • Set Quality to 30 or higher.
    • Set Weight between 20 and 40.

The smoothing buffer eliminates hand jitter and ensures that the pressure release at the end of a stroke calculates cleanly, producing a crisp, razor-sharp calligraphic taper.

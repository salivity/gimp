How to Export a Selection as an SVG Path in GIMP

Exporting an active selection outline as an SVG vector file in GIMP requires converting your raster selection into a vector path and exporting that path through the Paths dockable dialog. This quick conversion transforms pixel-based boundaries into scalable vector curves that you can use in external vector editing software like Inkscape or Adobe Illustrator.

Step 1: Create and Finalize Your Selection

Use any of GIMP's selection tools (such as the Rectangle Select, Ellipse Select, Free Select, or Fuzzy Select tool) to create your active selection on the canvas. Ensure the "marching ants" outline accurately defines the shape you want to export.

Step 2: Convert the Selection to a Path

Once your selection is active:

  1. Go to the top menu and click Select.
  2. Choose To Path from the dropdown menu.

GIMP will trace the outline of your selection and generate a smooth vector path. The active selection outline will remain on your screen, but a corresponding vector path has now been created in the background.

Step 3: Open the Paths Dialog

To interact with the newly created vector path:

  1. Navigate to Windows > Dockable Dialogs > Paths if the Paths tab is not already visible in your workspace.
  2. In the Paths list, locate your path (it will typically be named "Selection" by default).

Step 4: Export the Path as an SVG File

  1. Right-click on the path entry in the Paths dialog.
  2. Select Export Path... from the context menu.
  3. In the file browser dialog that appears, choose your save directory.
  4. Enter a name for your file, ensuring it ends with the .svg extension (e.g., selection-outline.svg).
  5. Click Save.

The active selection outline is now saved to your computer as an independent, scalable SVG vector file.

Fix Missing Edge Pixels After Rotating in GIMP

Straightening a crooked horizon line in GIMP often tilts the rectangular frame, leaving behind empty, transparent triangular wedges along the outer borders. While cropping the image is a common workaround, it often ruins the framing or cuts off critical compositional elements. This guide demonstrates how to reconstruct these missing edge pixels and seamlessly fill the empty canvas borders using automated plugins, manual restoration tools, and pixel stretching techniques.

Preparing the Canvas

Before reconstructing pixels, ensure the transparent areas are accessible for editing:

  1. Straighten the Image: Select the Rotate Tool (Shift + R) or use the Measure Tool along the crooked horizon and click Straighten.
  2. Preserve Canvas Area: In the Tool Options for the Rotate Tool, ensure the Clipping setting is set to Adjust (which expands the canvas to keep all rotated pixels) or Clip (which keeps the original canvas size with empty corners).
  3. Add an Alpha Channel: Right-click your image layer in the Layers panel and choose Add Alpha Channel so that the missing areas register as true transparency rather than the background color.

Method 1: Automated Inpainting via the Resynthesizer Plugin

The most seamless way to recreate missing boundaries is with the Resynthesizer plugin (specifically the Heal Selection tool), which functions as GIMP’s content-aware fill.

  1. Select the Fuzzy Select Tool (Magic Wand, shortcut U).
  2. Click inside the transparent border areas. Hold Shift and click each corner or edge until all empty spaces are selected.
  3. Go to Select > Grow and expand the selection by 2 to 5 pixels. This ensures the algorithm samples actual image data instead of stopping at the transparent boundary.
  4. Navigate to Filters > Enhance > Heal selection....
  5. Set the sampling width (e.g., 50 pixels) and select All around for the sampling direction.
  6. Click OK. The plugin will analyze nearby textures—such as clouds, sea, or foliage—and synthetically generate matching pixels to fill the void.

Method 2: Manual Repair with the Clone and Healing Tools

When the background consists of complex patterns or when third-party plugins are unavailable, manual retouching provides precise control.

  1. Healing Tool (H): Ideal for skies and water gradients.
    • Hold Ctrl and click a smooth section of the image near the void to establish a source point.
    • Brush into the transparent wedge. The Healing Tool blends color and luminosity variations naturally into the blank area.
  2. Clone Tool (C): Ideal for high-detail textures like grass, sand, or architectural lines.
    • Hold Ctrl and select a reference point that aligns with linear patterns (like a continuing shoreline).
    • Carefully paint the source pixels into the blank corner, resetting your source anchor as needed to avoid repetitive, visible patterns.

Method 3: Edge Stretching for Uniform Horizons

For horizons framed by open sea or clear sky, stretching the outermost row of pixels outward eliminates transparency without altering visual textures.

  1. Choose the Rectangle Select Tool (R).
  2. Select a 1-to-2-pixel wide strip directly adjacent to the transparent edge.
  3. Switch to the Scale Tool (Shift + S).
  4. Pull the outer edge of the selection handles directly into the empty space until it reaches the edge of the canvas.
  5. Hit Scale and use a soft Eraser or Smudge Tool to blend any hard seams where the stretched strip meets the original image.

Method 4: The Warp Transform Tool for Minor Gaps

If the rotation angle was small (less than 1 or 2 degrees), the missing gaps will be slight slivers that can be filled by pushing the existing edge pixels outward.

  1. Select the Warp Transform Tool (W).
  2. In the Tool Options, set the behavior to Move pixels and choose a brush size slightly larger than the missing corner.
  3. Lower the strength to roughly 30–40%.
  4. Click along the edge of the image and nudge the pixels outward into the transparent space until the gap is closed. Because the adjustment is minimal, optical distortion remains imperceptible.

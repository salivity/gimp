How to Create a Custom GIMP Splash Screen

Customizing the GIMP startup splash screen is a simple way to personalize your graphic design workspace. GIMP natively supports custom splash screens by scanning a specific directory in your user profile upon launch. This guide outlines the exact requirements for image preparation, the file directory locations across different operating systems, and how to configure single or multiple splash screens.

1. Prepare Your Custom Image

Create or select the image you want to display when GIMP loads.

  • File Formats: Standard image formats such as PNG, JPG, or BMP are fully supported.
  • Resolution: There is no strict size requirement, but resolutions between 600x400 pixels and 1920x1080 pixels generally display best without consuming excessive screen real estate during startup.
  • Aspect Ratio: A landscape orientation matches standard splash screen dimensions.

2. Locate Your GIMP Preferences Directory

You must place your image inside GIMP’s user configuration folder. Navigate to the path corresponding to your operating system (replace 2.10 with your installed GIMP version if different):

  • Windows:
    %APPDATA%\GIMP\2.10\
    (Usually: C:\Users\<YourUsername>\AppData\Roaming\GIMP\2.10\)

  • macOS:
    ~/Library/Application Support/GIMP/2.10/

  • Linux:
    ~/.config/GIMP/2.10/

3. Create the Splashes Folder

Check inside the configuration directory for a subfolder named splashes. If this folder does not exist:

  1. Right-click and create a new directory.
  2. Name the folder exactly splashes (all lowercase).

4. Move Your Image Files

Place your prepared image into the splashes folder.

  • Single Image: If only one image is placed in the folder, GIMP will display it every time the program launches.
  • Multiple Images: If you place several images in the splashes folder, GIMP will randomly choose one each time you start the application.

5. Launch GIMP

Close GIMP if it is currently open, then start the program. The default startup image will be replaced by your custom splash screen. If the default splash screen still displays, verify that the splashes folder name is spelled correctly and placed directly inside your GIMP version folder.

Map Brush Size to Pen Tilt in GIMP

This guide explains how to configure custom paint dynamics in GIMP to link brush size directly to your stylus pen tilt angle. By creating and editing a custom dynamic profile, users with tilt-supported drawing tablets can intuitively control stroke thickness on the fly without adjusting manual size sliders or keyboard shortcuts.

Step 1: Open the Paint Dynamics Dialog

  1. Launch GIMP and navigate to the top menu bar.
  2. Go to Windows > Dockable Dialogs > Paint Dynamics.
  3. In the Paint Dynamics panel, click the Create a new dynamics button (the paper icon located in the lower-right corner) to generate a custom preset.

Step 2: Configure the Tilt-to-Size Matrix

  1. Once the new preset is created, open the Paint Dynamics Editor (go to Windows > Dockable Dialogs > Paint Dynamics Editor, or double-click your newly created dynamic).
  2. Look at the matrix grid where the rows represent dynamic parameters and the columns represent physical input properties.
  3. Locate the row labeled Size and the column labeled Tilt.
  4. Check the box at the intersection of Tilt and Size.

Step 3: Fine-Tune the Tilt Curve (Optional)

  1. Below the matrix in the Paint Dynamics Editor, locate the Dynamics Curve dropdown menu.
  2. Select Size and then choose the Tilt sub-option.
  3. Adjust the curve points to modify how sensitively GIMP responds to changes in your pen angle. A steeper curve increases size variation with smaller tilt movements, while a linear line provides steady scaling.

Step 4: Apply the Dynamic Profile to a Brush

  1. Select the Paintbrush Tool (or any painting tool such as the Pencil or Airbrush) from the Toolbox.
  2. Go to the Tool Options panel.
  3. Scroll down to the Dynamics section.
  4. Click the dynamic preset icon and select your newly created custom dynamic from the list.

Step 5: Verify Hardware Input Configuration

If the brush does not respond to tilt after setup, verify that GIMP recognizes your tablet's tilt capabilities:

  1. Go to Edit > Input Devices.
  2. Select your tablet stylus from the device list.
  3. Set the Mode to Screen.
  4. Ensure the X Tilt and Y Tilt axes are correctly mapped to their corresponding tablet inputs, then click Save.

How to Configure Auto-Save and Recovery in GIMP

This guide explains how to configure emergency document recovery and set up auto-save functionality in GIMP. While GIMP includes an automated crash recovery mechanism by default, it does not feature a built-in periodic auto-save timer. By optimizing your system resource settings, ensuring crash recovery is active, and utilizing auto-save scripts, you can prevent data loss during unexpected crashes or power interruptions.

Enabling and Using Crash Recovery in GIMP

Modern versions of GIMP (2.10 and later) include an integrated crash recovery system that automatically attempts to backup unsaved image buffers when the application crashes.

  1. Automatic Recovery Prompt: If GIMP closes unexpectedly, reopen the program. GIMP will display a "Crash Recovery" dialog listing any unsaved images it was able to salvage.
  2. Recovering Files: Select the files you want to restore from the list and click Recover to open them in the workspace.
  3. Save Immediately: Immediately navigate to File > Save As to save the recovered files to your preferred directory, as these temporary files are not stored permanently.

Optimizing System Resources and Undo History

To minimize crashes and ensure GIMP retains sufficient data history, configure your memory and cache settings:

  1. Open GIMP and navigate to Edit > Preferences (or GIMP > Preferences on macOS).
  2. In the left sidebar, click on System Resources (or Environment in older versions).
  3. Under the Resource Consumption section:
    • Minimal number of undo levels: Set this to at least 20 to guarantee a baseline of undo history.
    • Maximum undo memory: Increase this value (e.g., 512 MB or 1 GB depending on your total system RAM) so GIMP can retain complex editing steps without dropping history.
    • Tile cache limit: Set this to approximately 50% to 75% of your total available system RAM to prevent out-of-memory crashes during large project rendering.
  4. Click OK to apply the changes.

Setting Up a Timed Auto-Save Using Plugins

Because GIMP lacks a native periodic auto-save timer, adding an auto-save script is the most reliable way to save your work at regular intervals.

  1. Download an Auto-Save Plugin: Download a trusted GIMP auto-save Python script or plug-in (such as gimp-autosave).
  2. Locate GIMP Plug-in Folder:
    • Go to Edit > Preferences > Folders > Plug-ins.
    • Note the folder path listed for user plug-ins.
  3. Install the Script:
    • Place the downloaded .py file into the designated plug-ins folder.
    • If on Linux or macOS, ensure the file has executable permissions (chmod +x filename.py).
  4. Restart GIMP: Close and relaunch GIMP to load the new plugin.
  5. Configure Interval: Access the auto-save settings (typically located under File > Auto-Save or Filters > Generic) to set your desired backup interval (such as every 5 or 10 minutes) and choose a backup directory.

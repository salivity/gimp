How to Set GIF Frame Delay in GIMP Layer Names

Creating animated GIFs with variable frame rates in GIMP is achieved by embedding millisecond durations directly into individual layer names. This guide provides a direct walkthrough on how to format your layer titles with the correct millisecond syntax and how to export the animation so GIMP honors your custom timing settings.

The Layer Name Syntax

GIMP reads the delay duration for any frame from values enclosed in parentheses inside the layer's name. To define the timing, add the number of milliseconds followed immediately by ms inside parentheses at the end of the layer name.

  • Format: Layer Name (###ms)
  • Example: Frame 1 (500ms) sets the frame display time to half a second.
  • Example: Frame 2 (1000ms) sets the frame display time to one full second.

You can also specify the frame disposal method within the same layer name by adding an additional tag:

  • (replace): Replaces the previous frame completely with the current frame.
  • (combine): Superimposes the current frame over the previous frame.
  • Combined Example: Frame 1 (250ms) (replace)

Step-by-Step Instructions

  1. Open the Layers Dialog: If not already visible, open the dockable dialog by navigating to Windows > Dockable Dialogs > Layers (or press Ctrl + L).
  2. Rename the Layers: Double-click the name of the layer you wish to adjust. Type the delay value in parentheses, such as (150ms), and press Enter to confirm. Repeat this for each layer requiring custom timing.
  3. Export as GIF:
    • Navigate to File > Export As...
    • Name your file with the .gif extension and click Export.
  4. Configure Animation Settings:
    • In the export dialog that appears, check the box labeled As animation.
    • Locate the option Frame disposal where unspecified and choose your preferred fallback (typically "One frame per layer (replace)").
    • Note that the global setting Delay between frames where unspecified only applies to layers that do not have custom milliseconds defined in their names. Any layer with (###ms) in its title will automatically override this global default.
  5. Finalize: Click Export to generate your animated GIF.

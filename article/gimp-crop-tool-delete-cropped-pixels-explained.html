GIMP Crop Tool: Delete Cropped Pixels Explained

When using the Crop tool in GIMP, leaving the "Delete cropped pixels" option unchecked alters the visible image area without discarding any underlying image data. This article explains how GIMP manages these hidden off-canvas pixels, how they behave within your project, and how you can access or reveal them later.

Canvas Resizing vs. Layer Cropping

In GIMP, the image canvas and individual layers are separate entities. The canvas represents the visible, active window of your project, while layers can be smaller, equal to, or significantly larger than the canvas itself.

When "Delete cropped pixels" is unchecked:

  • The Canvas Resizes: The canvas shrinks or expands to match your crop boundary.
  • The Layers Remain Intact: Layers are not clipped to the new canvas edges. Instead, any layer pixels falling outside the new crop box simply extend beyond the active canvas boundaries into off-canvas space.

What Happens to the Hidden Pixels

  • They Remain in Memory and the XCF File: Because the pixel data is preserved, the project retains the original detail of all layers. Saving the project as an XCF file will store this hidden information, meaning the file size will reflect the entire uncut layer data rather than just the visible cropped area.
  • They Can Be Re-positioned: You can select the Move tool and drag a cropped layer around within the canvas. As you drag, the previously hidden pixels will slide back into view seamlessly.
  • They Are Ignored During Standard Export: If you export your work to standard formats like PNG, JPEG, or WebP, GIMP only renders what is inside the canvas boundary. Any pixels resting outside the canvas will not appear in the final exported file.

How to Reveal Off-Canvas Pixels

If you later decide that you want to restore the hidden data to the visible workspace, you can expand the canvas without losing quality:

  1. Go to the top menu and select Image > Fit Canvas to Layers. This expands the project boundary to encompass all pixels, including those previously pushed off-canvas.
  2. Alternatively, navigate to Image > Canvas Size to manually expand the canvas dimensions to your preferred width and height.

By keeping "Delete cropped pixels" unchecked, GIMP acts non-destructively, allowing you to crop for framing while safeguarding your raw layer content for future edits.

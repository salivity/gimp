How to Verify GIMP Downloads and Digital Signatures

Official GIMP releases maintain data integrity and security through a multi-tiered verification system consisting of cryptographic hash functions, OpenPGP signatures, and platform-specific code signing certificates. When users download GIMP installers or source packages from the official website, they can independently validate that the files have not been corrupted, tampered with, or injected with malicious code. This guide details how GIMP provides checksums, detached PGP signatures, and operating system certificates to ensure you run authentic software.

Cryptographic Hashes (SHA-256 and SHA-512)

GIMP provides cryptographic hash values directly on its download pages for every released package. A hash is a unique, fixed-length alphanumeric string generated by processing the installation file through a mathematical algorithm. Even a single modified byte in the installer alters the resulting hash completely.

To verify file integrity:

  1. Locate the expected SHA-256 or SHA-512 checksum next to the download link on the official GIMP downloads page.
  2. Generate the hash of your downloaded file locally:
    • Linux: Run sha256sum filename.ext
    • macOS: Run shasum -a 256 filename.dmg
    • Windows: Open PowerShell and execute Get-FileHash filename.exe -Algorithm SHA256
  3. Compare the computed output with the hash published on the website. If the values match identically, the file was downloaded without corruption.

OpenPGP / GPG Digital Signatures

While checksums prove a file is not corrupted, they do not prove authenticity if an attacker modifies both the file and the displayed hash. To solve this, the GIMP team generates detached GPG (GNU Privacy Guard) signatures (typically with a .asc extension) for releases and manifest files.

The verification process involves:

  1. Retrieving the Public Key: Obtain the official GIMP release signing key from a verified keyserver or the official project documentation.
  2. Checking the Fingerprint: Confirm that the public key’s fingerprint matches the known fingerprint advertised by the GIMP development team.
  3. Validating the Signature: Download the detached signature file alongside the installer and run: 
    gpg --verify gimp-version.ext.asc gimp-version.ext

A successful verification reports a "Good signature" from the trusted GIMP release coordinator, guaranteeing that the file originates from the project developers.

Operating System Code Signing

For platforms with built-in application security frameworks, GIMP binaries are signed with validated developer certificates:

  • Windows (Authenticode): Official Windows installers are signed using an Authenticode certificate. Right-click the .exe file, select Properties, and navigate to the Digital Signatures tab to confirm the signature is valid and issued to the official GIMP maintainer.
  • macOS (Gatekeeper and Notarization): Official macOS DMG builds are signed with an Apple Developer ID and notarized by Apple. Gatekeeper automatically scans and verifies the notarization ticket when the installer is mounted. You can verify this manually in the Terminal by running spctl -a -t open --context context:primary-signature filename.dmg.
  • Linux (Flatpak): The primary supported Linux distribution method via Flathub signs flatpak repositories using dedicated GPG keys, which the Flatpak package manager checks automatically prior to installation.

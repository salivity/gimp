Why 50% Gray in Exclusion Mode Yields Gray in GIMP

In GIMP and other digital imaging software, setting a 50% neutral gray layer to the Exclusion blend mode flattens the entire composition into a uniform 50% gray canvas, completely concealing the base image. This article explains the underlying mathematical equation behind the Exclusion blend mode and demonstrates why any underlying pixel value, regardless of its original color or brightness, cancels out entirely when combined with middle gray.

The behavior of the Exclusion blend mode is determined by a standard mathematical formula applied to each color channel (Red, Green, and Blue). In digital color processing, channel values are normalized to a floating-point range from 0.0 (pure black) to 1.0 (pure white). Within this system, 50% neutral gray corresponds precisely to a value of 0.5 across all three channels.

The formula for the Exclusion blend mode is:

Result = Base + Blend - (2 × Base × Blend)

When a 50% gray layer is used as the blend layer, the value 0.5 is substituted for "Blend":

Result = Base + 0.5 - (2 × Base × 0.5)

Multiplying 2 by 0.5 yields 1.0, simplifying the equation:

Result = Base + 0.5 - (1.0 × Base)

Result = Base + 0.5 - Base

Because the positive "Base" and the negative "Base" cancel each other out, the variable representing the underlying image is eliminated from the equation entirely:

Result = 0.5

Because the base value no longer influences the outcome, every pixel on the canvas evaluates to 0.5, regardless of whether the original underlying pixel was black (0.0), white (1.0), or any shade in between. When translated back to standard 8-bit digital color values, 0.5 maps directly to RGB (128, 128, 128), generating an unbroken field of neutral 50% gray across the image.

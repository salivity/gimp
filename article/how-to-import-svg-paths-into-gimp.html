How to Import SVG Paths into GIMP

Importing Scalable Vector Graphics (SVG) paths into GIMP allows you to bring crisp vector outlines created in vector software straight into your raster workflow. This guide explains the exact procedure for loading external SVG files directly into GIMP's dedicated Paths dialog, preserving the vector nodes so you can edit, scale, stroke, or convert the shapes into selections without rasterizing them beforehand.

Step 1: Open or Create a Canvas

Launch GIMP and open an existing project or create a new canvas via File > New. An active canvas is required for GIMP to position and scale the imported vector paths properly.

Step 2: Open the Paths Dialog

If the Paths dialog is not already visible in your workspace docks, enable it:

  1. Go to the top menu and select Windows.
  2. Hover over Dockable Dialogs.
  3. Click on Paths.

Step 3: Access the Import Function

Within the Paths tab:

  1. Right-click anywhere in the empty area of the Paths list. Alternatively, click the small configure menu icon (the small triangle pointing left with horizontal lines) located in the upper-right corner of the Paths dock.
  2. From the context menu, select Import Path....

Step 4: Configure and Select the SVG File

An "Import Paths from SVG" dialog box will appear:

  1. Locate and select the SVG file on your computer using the file browser.
  2. In the bottom section of the dialog, configure the import options:
    • Import to active path: Overwrites or adds to currently active paths if needed.
    • Merge imported paths: Combines all separate vector objects in the SVG into a single GIMP path layer. Leave this unchecked if you want distinct paths for different shapes.
    • Scale to fit image: Automatically resizes the imported vector outlines to match the dimensions of your current canvas. Leave unchecked if you need the original document coordinates preserved.
  3. Click Open.

Step 5: View and Use the Imported Path

The imported vectors will now appear as one or more entries in the Paths dock. Click the eye icon next to the path layer to make the vector outline visible on your canvas. From here, you can use the Paths Tool (shortcut: B) to manipulate individual nodes, click Path to Selection to create pixel selections, or use Stroke Path to render outlines onto an active pixel layer.

GIMP Paths Tool Polygons Option Explained

The Polygons option in GIMP's Paths tool restricts path segments to straight lines, preventing the automatic creation of Bézier curves. This article explains the primary function of this setting, how it alters node behavior, where to find it in the interface, and the specific editing scenarios where it is most beneficial.

Primary Function of the Polygons Option

By default, the Paths tool creates curved segments when you click and drag to add nodes, generating directional handles that bend the path. When the Polygons option is enabled, the tool strictly draws straight lines between consecutive control points. Clicking on the canvas places sharp anchor points without tangent handles, effectively locking each connected segment into a rigid, linear stroke.

How It Changes Path Behavior

  • Disables Bézier Handles: When placing points, you cannot drag out handles to form curved arcs. Every newly created node remains a corner point.
  • Streamlined Clicking: It allows for rapid clicking across the canvas to define outlines without the risk of accidentally pulling out a curve handle on a misdirected click.
  • Post-Creation Flexibility: Although the option forces straight lines during initial placement, disabling the option later allows you to edit those points and manually pull curves from the straight segments if needed.

How to Locate and Enable It

  1. Select the Paths Tool from the Toolbox (keyboard shortcut: B).
  2. Look at the Tool Options dockable dialog, typically located below the toolbox.
  3. Under the Design mode section, check the box labeled Polygons.

Common Use Cases

  • Tracing Geometric Objects: Useful for tracing architectural elements, mechanical parts, boxes, screens, and any subject with sharp, flat edges.
  • Creating Low-Poly Art: Facilitates the creation of faceted, angular designs and triangular mesh artwork.
  • Straight-Edge Selections: Serves as a more precise, editable alternative to the Free Select (Lasso) tool when outlining polygonal subjects to convert into selections.

How to Create Parallel Vector Paths in GIMP

Creating parallel vector strokes in GIMP allows you to design double lines, outlines, and complex geometric shapes using the Paths tool. While GIMP does not include a single-click "offset path" tool, you can achieve exact parallel strokes by duplicating the path layer, translating or scaling the duplicate to your desired offset, merging the components back into a single active path, and applying your stroke settings.

Step 1: Open the Paths Dialog

  1. Go to the Windows menu, select Dockable Dialogs, and click Paths.
  2. Click on the path you want to duplicate to make it active. Ensure the eye icon next to it is toggled on so it remains visible on your canvas.

Step 2: Duplicate the Path

  1. Right-click the active path in the Paths dialog and select Duplicate Path (or click the duplicate icon at the bottom of the dialog).
  2. Make both the original path and the duplicate path visible by toggling their eye icons on.
  3. Select the duplicated path to ensure it is the active layer.

Step 3: Offset to Create the Parallel Distance

  1. Select the Move Tool from the Toolbox (shortcut: M).
  2. In the Tool Options panel, under the Move: section, click the Path icon (the red curve with anchor points).
  3. Click and drag the duplicate path on the canvas to offset it parallel to the original. Hold Ctrl (or Cmd on macOS) while dragging to constrain movement along the horizontal or vertical axis.
  4. Alternatively, if your shape is closed and you need concentric parallel lines, select the Scale Tool (shortcut: Shift + S), set its mode to Path in Tool Options, and resize the duplicate outward or inward.

Step 4: Merge Paths into a Single Vector Item

  1. In the Paths dialog, ensure only the two parallel paths are visible (eye icons enabled).
  2. Right-click either path and choose Merge Visible Paths.
  3. Both strokes now exist as distinct components within a single active path.

Step 5: Render the Parallel Strokes

  1. Create a new raster layer in the Layers dialog where the strokes will be drawn.
  2. Select your merged path in the Paths dialog.
  3. Click Stroke Path at the bottom of the dialog or select Edit > Stroke Path.
  4. Choose Stroke line, define your line width, join style, and cap style, then click Stroke.

GIMP will render both vector components at the same time, producing uniform, parallel raster lines.

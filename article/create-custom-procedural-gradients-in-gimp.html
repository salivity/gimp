Create Custom Procedural Gradients in GIMP

Procedural gradients in GIMP provide mathematically calculated, smooth transitions between multiple color stops, allowing for infinitely scalable and fully editable color blending. This guide walks you through the exact steps to build your own custom procedural gradients using GIMP's built-in Gradient Editor, from initializing a new gradient file to splitting segments, assigning precise color endpoints, and adjusting interpolation functions.

Step 1: Open the Gradients Dialog

  1. Launch GIMP.
  2. Go to the top menu and select Windows > Dockable Dialogs > Gradients.
  3. The Gradients dock will appear, displaying all currently installed system and user gradients.

Step 2: Create a New Gradient

  1. In the bottom bar of the Gradients dockable dialog, click the New Gradient icon (a blank sheet of paper with a plus sign).
  2. This action automatically opens the Gradient Editor window displaying a default black-to-white gradient segment.

Step 3: Configure Segment Colors

The gradient is divided into one or more segments. Each segment contains a left endpoint, a center midpoint marker, and a right endpoint along the bottom bar of the editor.

  1. Set the Left Color: Right-click the segment area and select Left Endpoint's Color. Pick your desired color from the color selection dialog and click OK.
  2. Set the Right Color: Right-click the segment area and choose Right Endpoint's Color. Select the destination color and click OK.
  3. Adjust the Transition Point: Click and drag the small white triangular slider situated between the endpoints at the bottom of the editor to change where the color shift peaks.

Step 4: Add More Color Stops (Split Segments)

To create multi-color gradients, you must divide the gradient into multiple segments:

  1. Right-click the segment you wish to divide.
  2. Select Split Segment at Midpoint (or Split Segment Uniformly to divide it into multiple equal parts).
  3. Click the newly created segment to select it.
  4. Right-click the new segment to assign unique colors to its left and right endpoints.

Step 5: Adjust Blending and Color Models

GIMP allows you to change the mathematical interpolation method for each segment:

  1. Right-click the target segment.
  2. Hover over Blending Function for Segment and choose an interpolation mode:
    • Linear: Standard constant-rate color transition.
    • Curved: Accelerated transition based on the midpoint marker.
    • Sinusoidal: Smooth S-curve transition.
    • Spherical (increasing/decreasing): Rounded transition profile.
  3. Hover over Coloring Type for Segment to choose how colors interact across the spectrum:
    • RGB: Blends directly through standard red, green, and blue channels.
    • HSV (counter-clockwise / clockwise): Transitions across the hue color wheel, creating vibrant intermediate hues.

Step 6: Save and Use the Gradient

  1. Double-click the text box at the top of the Gradient Editor window to give your gradient a unique name.
  2. The gradient saves automatically as a .ggr procedural gradient file in your local GIMP user profile.
  3. Select the Gradient Tool (G) from your toolbox, choose your newly named gradient from the tool options, and click and drag across any active canvas or selection to apply it.

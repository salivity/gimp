How to Crop Canvas to Selection in GIMP

The "Fit Canvas to Selection" command in GIMP is a fast, non-destructive way to resize your entire project workspace to match the exact boundaries of an active selection. This guide explains how the command functions, how it recalculates the canvas dimensions, and how it differs from traditional cropping tools.

What the Command Does

When you execute the "Fit Canvas to Selection" command, GIMP evaluates the outermost boundaries of your current selection and shrinks or expands the global canvas frame to match those exact dimensions. Unlike destructive crop functions that permanently discard image data outside the selected area, this command only modifies the visible project workspace (the canvas), leaving the underlying layer data intact outside the new boundaries.

How to Use Fit Canvas to Selection

  1. Create a Selection: Use any selection tool (Rectangle Select, Ellipse Select, Free Select, or Fuzzy Select) to outline the area you want as your new canvas size.
  2. Apply the Command: Navigate to the top menu and select Image > Fit Canvas to Selection.
  3. Review the Result: The workspace immediately resizes so that the canvas edges align perfectly with the selection's outermost limits.

Bounding Box Mechanics

Because an image canvas must always be rectangular, GIMP uses the bounding box of your selection rather than its exact shape:

  • Non-Rectangular Selections: If you make a circular, elliptical, or freehand selection, GIMP calculates the minimum bounding rectangle that completely encloses that selection. The new canvas dimensions will match the maximum height and width of that bounding box.
  • Layer Independence: Individual layers are not automatically cropped to the new canvas size. Any artwork extending beyond the new canvas boundaries remains intact in the project file, hidden from view unless you move the layer or manually resize it using Layer > Crop to Content.

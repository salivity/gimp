How to Create an Animated Leaf Brush in GIMP

Creating an animated brush hose (.gih) in GIMP allows you to paint rich, natural foliage by automatically cycling through varied textures with each stamp. This guide walks you through setting up transparent layers for individual leaf designs, configuring multi-layer export settings, and establishing random dynamics so that GIMP places a different leaf texture with every brush stroke.

Step 1: Create a New Image

  1. Open GIMP and navigate to File > New.
  2. Set the dimensions to a square size, such as 500 x 500 pixels (or smaller, depending on the desired level of detail).
  3. Expand Advanced Options and set Fill with to Transparency.
  4. Click OK.

Step 2: Draw or Import Your Leaf Variations

  1. Create a distinct leaf design on your base layer using your preferred drawing tools or by pasting an isolated leaf cutout.
  2. Open the Layers panel (Ctrl + L).
  3. Click the Create a new layer button to add another transparent layer.
  4. Draw or paste a second leaf variation on this new layer, changing the angle, shape, or color.
  5. Repeat this process until you have several different leaf layers (typically 4 to 10 layers provide good natural variation).
  6. Ensure each leaf is centered within the canvas boundaries and that all layers have an active alpha channel (right-click each layer and select Add Alpha Channel if it is not grayed out).

Step 3: Export as a GIMP Image Hose (.gih)

  1. Go to File > Export As....
  2. Name your file with the .gih extension (for example, leaf_brush.gih).
  3. Set the save destination to your GIMP user brushes directory:
    • Windows: C:\Users\<Username>\AppData\Roaming\GIMP\2.10\brushes
    • macOS: /Users/<Username>/Library/Application Support/GIMP/2.10/brushes
    • Linux: ~/.config/GIMP/2.10/brushes
  4. Click Export.

Step 4: Configure the Brush Export Dialog

After clicking export, the Export Image as Brush Pipe dialog window will appear. Configure the parameters as follows:

  • Spacing (Percent): Set between 50 and 100. This determines how closely together the leaves stamp when dragging the mouse.
  • Description: Enter a recognizable name for the brush.
  • Cell Size: Leave at default (matches your canvas size).
  • Number of cells: This should automatically match the total number of layers in your project.
  • Ranks: Set to 1 (this defines a 1-dimensional brush array).
  • Dimension: Set to the total number of layers you created (for example, 5 if you have 5 layers).
  • Selection: Change the dropdown menu from incremental to random. This ensures the brush picks a random leaf from your layers during application instead of moving in a fixed sequence.

Click Export to finalize the file.

Step 5: Load and Use the Brush

  1. Open the Brushes dock (Windows > Dockable Dialogs > Brushes).
  2. Click the Refresh brushes icon (circular arrows) at the bottom of the panel to load your newly created .gih file without restarting GIMP.
  3. Select the Paintbrush Tool (P).
  4. Locate and select your new leaf brush from the brush palette.
  5. In the Tool Options panel, adjust size, spacing, and jitter as needed, then paint on the canvas to generate randomized leaf patterns.

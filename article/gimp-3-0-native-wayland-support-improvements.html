GIMP 3.0 Native Wayland Support Improvements

GIMP 3.0 introduces native Wayland display support on Linux desktops by fully migrating its codebase from GTK2 to GTK3. This upgrade resolves longstanding graphical and input issues inherent to running legacy X11 applications through XWayland. With this transition, Linux users benefit from sharp HiDPI and fractional scaling, lower-latency drawing, enhanced graphics tablet and stylus precision, and improved stability across multi-monitor setups with varying refresh rates.

The Core Upgrade: GTK2 to GTK3

GIMP 2.10 relied on GTK2, a legacy toolkit that predates the Wayland display protocol. As a result, modern Linux desktop environments had to run GIMP through the XWayland compatibility layer. GIMP 3.0 completely replaces GTK2 with GTK3, allowing the application to communicate directly with Wayland compositors like GNOME's Mutter and KDE's KWin. This eliminates the middleman layer, streamlining window management and rendering pipelines.

Crisp HiDPI and Fractional Scaling

One of the primary drawbacks of running GIMP under XWayland was pixelated, blurry UI elements and canvas views on high-density displays using fractional scaling (such as 125% or 150%). Under native Wayland:

  • Pixel-Perfect Canvas: Canvases render at native physical resolutions regardless of desktop scaling factors.
  • Independent Monitor Scaling: GIMP 3.0 dynamically adjusts its user interface sharpness when moved between screens with differing scale factors, eliminating distortion.
  • Vector UI Scaling: GTK3 icons and interface themes scale smoothly without blurriness.

Precision Input for Graphics Tablets and Styluses

Input handling via XWayland frequently suffered from dropped events, coordinate offset bugs, or lost pressure sensitivity data on graphic tablets. GIMP 3.0 leverages Wayland's direct input protocols:

  • Direct Device Mapping: Drawing tablets (such as Wacom, Huion, and XP-Pen devices) map directly to window coordinates rather than through a virtualized X11 root window.
  • Accurate Pressure and Tilt: Tablet events, including tilt angle and pressure levels, pass directly to GIMP with lower overhead, resulting in reduced brush stroke latency.
  • Hotplugging Stability: Connecting or disconnecting input devices mid-session no longer causes input freezes or requires application restarts.

Multi-Monitor and Mixed Refresh Rate Handling

Wayland natively supports mixed refresh rates, allowing a 144Hz primary monitor to run alongside a 60Hz secondary display without forcing both to the lowest common denominator. Native Wayland support in GIMP 3.0 ensures:

  • Tear-Free Canvas Redraws: Brush strokes and pan/zoom actions synchronize cleanly with the specific monitor's refresh rate.
  • Proper Window Placement: Transient dialogs, dockable panels, and contextual tooltips appear in their intended positions rather than misaligning due to display boundaries.

Resource Efficiency and Security

Running natively on Wayland reduces system overhead by avoiding the persistent memory and CPU usage required to translate X11 calls. Furthermore, GIMP 3.0 aligns with Wayland's isolation architecture, which prevents unauthorized background applications from snooping on GIMP's canvas buffers or capturing keystrokes and shortcuts assigned inside the editor.

How to Remove Moiré from Fabric in GIMP

Moiré artifacts occur in digital photography when a fine fabric pattern conflicts with a camera sensor's pixel grid, creating unwanted geometric bands or rainbow-colored distortions. This step-by-step guide explains how to effectively eliminate both color (chromatic) and pattern (luminance) moiré from fabric textures in GIMP using targeted blurring, layer blend modes, and the Wavelet Decompose filter while preserving as much original detail as possible.

Method 1: Fixing Color Moiré with the Color Blend Mode

If the moiré appears primarily as rainbow bands or unnatural color shifts across the fabric, this is the quickest method to fix it without softening the underlying weave.

  1. Open your image in GIMP.
  2. Duplicate the base layer by right-clicking it in the Layers panel and selecting Duplicate Layer (or press Ctrl+Shift+D / Cmd+Shift+D).
  3. Change the Layer Mode of the top duplicate layer to Color (or LCH Color) in the Mode dropdown at the top of the Layers panel.
  4. Apply a Gaussian Blur:
    • Go to Filters > Blur > Gaussian Blur...
    • Increase the Size X and Size Y sliders just until the rainbow color banding blends into the surrounding fabric color. Click OK.
  5. Apply a Layer Mask so the blur only affects the fabric:
    • Right-click the blurred layer and select Add Layer Mask...
    • Choose Black (full transparency).
    • Select the Paintbrush Tool (P), set your foreground color to white, and paint over the areas of the fabric affected by the color moiré.

Method 2: Fixing Pattern and Detail Moiré with Wavelet Decompose

When moiré alters the physical texture lines (luminance moiré), you need to separate the image's frequency scales to target the pattern directly.

  1. Duplicate your base layer to keep a non-destructive copy.
  2. Run Wavelet Decompose:
    • Navigate to Filters > Enhance > Wavelet-decompose...
    • Keep the default number of scales (usually 5 to 7) and click OK.
    • GIMP will generate a series of scale layers (from fine details on Scale 1 to coarse details on higher scales) plus a residual layer.
  3. Identify the Problematic Scale:
    • Toggle the visibility (eye icon) of individual Wavelet scale layers to find which scale contains the repetitive moiré lines. Moiré is typically concentrated on Scale 2, Scale 3, or Scale 4.
  4. Smooth the Artifacts:
    • Select the identified scale layer.
    • Go to Filters > Blur > Gaussian Blur... and apply a subtle blur (1 to 4 pixels) to smooth out the unnatural interference pattern.
    • Alternatively, use the Smudge Tool or the Clone Tool set to a low opacity directly on that scale layer to even out irregular patches.
  5. Mask the Group:
    • Add a black layer mask to the created Wavelet group (or merge the group back down) and paint white over only the fabric areas to ensure the rest of your subject remains sharp.

Method 3: Using the Median Blur Filter

For heavy, localized texture conflicts where standard blurring loses too much edge contrast, Median Blur helps eliminate high-frequency repeating lines.

  1. Duplicate the layer and zoom in on the fabric.
  2. Use the Free Select Tool (Lasso) to draw a selection around the affected fabric region.
  3. Feather the selection slightly via Select > Feather... (set to 3–5 pixels) to avoid harsh transition edges.
  4. Go to Filters > Blur > Median Blur...
  5. Adjust the Radius slider incrementally. The median filter discards outliers and repetitive pixel spikes, effectively flattening the moiré while retaining the structural contours of the garment.
  6. Click OK and deselect (Ctrl+Shift+A / Cmd+Shift+A).

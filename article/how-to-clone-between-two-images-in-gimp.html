How to Clone Between Two Images in GIMP

Cloning textures or specific pixel data between two separate image files is a fundamental photo editing technique in GIMP. By using the standard Clone Tool, you can sample an area from a source image and seamlessly paint that exact texture onto a different destination canvas. This step-by-step guide explains how to set up your workspace, sample pixels from your source file, and apply them directly to a separate project.

Step 1: Open Both Images in GIMP

Launch GIMP and open both files by navigating to File > Open. Ensure both the source image (containing the texture you want to copy) and the target image (where you want to paste the texture) are loaded. You can switch between them using the document tabs located directly above the canvas workspace.

Step 2: Select the Clone Tool

Select the Clone Tool from the main Toolbox on the left, or press the shortcut key C on your keyboard. In the Tool Options dockable dialog:

  • Choose a soft-edged brush (such as Hardness 050) to allow for smoother blending along the edges.
  • Adjust the Size slider to match the scale of the texture you need to copy.
  • Set the Alignment option to Aligned if you want the sample point to move continuously relative to your cursor, or None if you want to reuse the exact same sample point with every new brush stroke.

Step 3: Set the Source Point

  1. Click the tab of your source image to make it the active window.
  2. Hold down the Ctrl key (or Cmd on macOS). Your cursor will change into a crosshair icon.
  3. Left-click directly on the specific texture or feature you wish to sample. This locks the coordinates for the source pixels.
  4. Release the Ctrl key.

Step 4: Paint the Texture on the Target Image

  1. Click the tab of your target image to switch canvases.
  2. (Optional but recommended) Create a new transparent layer by clicking Layer > New Layer so your cloned texture does not permanently overwrite the background pixels.
  3. Position your brush cursor over the area where you want the texture applied.
  4. Click and drag the left mouse button to paint. GIMP will continuously sample the pixels from the initial image and render them directly onto the new canvas.

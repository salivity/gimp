Set GIMP as Default App for RAW Images

Configuring your operating system to open RAW camera files directly in GIMP streamlines your photo editing workflow by eliminating the need to manually import files through menus. This guide provides step-by-step instructions for associating common RAW formats (such as .CR2, .NEF, .ARW, and .DNG) with GIMP on Windows, macOS, and Linux. Because GIMP processes RAW files via third-party plugins, ensure you have either Darktable or RawTherapee installed alongside GIMP so the program can successfully interpret your camera's RAW sensor data.

Windows

Using the Context Menu

  1. Locate a RAW image file in File Explorer.
  2. Right-click the file and hover over Open with, then select Choose another app.
  3. Scroll through the list and select GIMP. If it does not appear, click More apps or Look for another app on this PC, then navigate to the GIMP executable (typically located at C:\Program Files\GIMP 2\bin\gimp-2.10.exe).
  4. Check the box labeled Always use this app to open [extension] files.
  5. Click OK. Repeat this process for any other RAW extensions your camera uses.

Using Windows Settings

  1. Open the Start menu and select Settings (gear icon).
  2. Go to Apps > Default apps.
  3. Scroll down and click Choose default apps by file type.
  4. Locate your specific RAW extension (e.g., .cr2, .nef, .dng) in the alphabetical list.
  5. Click the current program next to the extension and choose GIMP from the menu.

macOS

  1. Open Finder and locate the RAW image file.
  2. Right-click (or Control-click) the file and select Get Info.
  3. In the Info window, expand the Open with: section by clicking the arrow next to it.
  4. From the drop-down menu, select GIMP. If GIMP is not listed, select Other..., navigate to your Applications folder, and select GIMP.
  5. Click the Change All... button located directly beneath the drop-down menu.
  6. A confirmation dialog will appear asking if you want to open all similar files with GIMP. Click Continue.
  7. Repeat these steps for any other RAW file types generated by your cameras.

Linux

GNOME Desktop (Ubuntu, Fedora, Debian)

  1. Open the file manager and navigate to your RAW image.
  2. Right-click the file and select Properties.
  3. Navigate to the Open With tab.
  4. Select GNU Image Manipulation Program from the application list.
  5. Click the Set as default button in the lower-right corner.
  6. Close the Properties window.

KDE Plasma

  1. Right-click the RAW file in Dolphin.
  2. Select Properties.
  3. Next to the file type description, click the File Type Options button.
  4. Under the Application Preference Order list, select GIMP and use the Move Up button to place it at the very top.
  5. If GIMP is not listed, click Add..., find GIMP in the application list, add it, and move it to the top.
  6. Click Apply, then OK.

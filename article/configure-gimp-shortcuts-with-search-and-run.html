Configure GIMP Shortcuts with Search and Run

GIMP provides an efficient way to customize your workflow by assigning keyboard shortcuts directly through the Search and Run a Command dialog. Instead of digging through extensive preference menus, you can locate any tool, filter, or command instantly and bind it to a preferred keystroke on the fly.

1. Open the Search and Run Dialog

Launch GIMP and open any image or document. To activate the Search and Run a Command dialog, press the forward slash key (/) on your keyboard. Alternatively, navigate to the main menu and select Help > Search and Run a Command.

2. Locate Your Command

Type the name of the operation, filter, or tool you want to customize into the search bar at the top of the pop-up window. The list updates in real time to display matching actions along with their menu paths and any currently assigned shortcuts.

3. Assign the Keyboard Shortcut

In the search results, look at the rightmost column labeled Shortcut:

  • Locate the specific command you wish to modify.
  • Click directly on the empty space or the existing key combination in the Shortcut column for that row. The field will change to indicate it is listening for user input (often displaying a prompt like "New accelerator...").
  • Press the custom key combination you wish to use (for example, Ctrl + Shift + D or a single function key).

4. Manage Shortcut Conflicts

If the key combination is already assigned to another action, GIMP will alert you of the conflict. You can choose to reassign the shortcut—which removes it from the previous command—or cancel the change to pick a different key combination.

5. Clear or Reset a Shortcut

To remove an assigned shortcut using this dialog, click the shortcut field for the command as if you were editing it, and then press the Backspace key. This clears the assignment and leaves the command without a key binding.

Once your changes are made, press Escape or click outside the dialog to close it. The new shortcuts take effect immediately without requiring a restart of the application.

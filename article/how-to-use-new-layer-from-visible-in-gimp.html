How to Use New Layer from Visible in GIMP

This guide explains how to use the "New Layer from Visible" command in GIMP to merge your project into a single composite layer without flattening or losing your original layer stack. You will learn the exact steps to execute this non-destructive technique, how it differs from traditional merging commands, and when to incorporate it into your photo editing or graphic design workflow.

What is "New Layer from Visible"?

Standard merging tools like "Merge Down" or "Flatten Image" permanently combine elements, making individual layer edits impossible afterward. The "New Layer from Visible" function acts as an internal snapshot tool. It renders everything currently visible on the canvas into a brand-new layer while leaving all underlying layers, layer masks, and blend modes fully intact and editable.

Step-by-Step Instructions

  1. Adjust Layer Visibility: Look at your Layers dialog (Ctrl + L) and ensure that the eye icon is visible next to every layer you want included in the composite. Click the eye icon to hide any draft layers, reference images, or guides you do not want to capture.
  2. Set the Target Location: Click to select the uppermost active layer in your stack. GIMP automatically places the newly generated layer directly above your currently active layer.
  3. Run the Command: You can execute the command using either of these methods:
    • Navigate to the main menu at the top of the screen and select Layer > New Layer from Visible.
    • Right-click any active layer inside the Layers panel and choose New from Visible from the context menu.
  4. Work with the Result: A new layer named "Visible" will appear in your layer stack. This layer contains the complete composite image.

Common Use Cases

  • Global Adjustments: Apply overall sharpening (such as High Pass filters), noise reduction, or final color grading to the whole image without baking those changes destructively into your separate components.
  • Milestone Tracking: Keep a visual history of your progress at different stages of a project without saving multiple project files.
  • Selective Masking: Add a layer mask directly to the new composite layer to paint specific composite effects back into individual sections of your work.

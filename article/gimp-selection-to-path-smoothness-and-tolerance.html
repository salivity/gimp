GIMP Selection to Path Smoothness and Tolerance

Converting an active selection into a vector path in GIMP often produces jagged edges or an excessive number of anchor points if left to default behaviors. By accessing GIMP's advanced conversion dialogue, you can adjust specific parameters that govern error tolerance, curve fitting, and smoothing iterations. This guide details how to access these hidden options and explains the specific settings that control path smoothness and boundary deviation.

To access the advanced parameters, open the Paths Dialog (Windows > Dockable Dialogs > Paths), hold the Shift key, and click the Selection to Path button at the bottom of the panel. This bypasses the default automated conversion and opens the "Selection to Path Advanced Settings" window.

Error Threshold

The Error Threshold is the primary setting governing error tolerance. It defines the maximum deviation (measured in pixels) allowed between the generated vector path and the original pixel selection boundary.

  • Higher values allow the path to deviate further from pixel boundaries, resulting in significantly smoother curves, fewer anchor points, and a cleaner overall shape.
  • Lower values force the path to strictly trace the exact pixels of the selection, preserving fine geometric details at the expense of a rough, stair-stepped appearance.

Spline Threshold

The Spline Threshold dictates how closely a Bezier spline must match the intermediate polygonal points of the selection trace.

  • Increasing this value allows GIMP to approximate complex clusters of points with a single continuous curve, vastly improving path fluidity.
  • Decreasing this value forces GIMP to insert more curve handles and anchor points to maintain strict fidelity to the selection.

Filter Iteration and Filter Epsilon

Before converting straight segments into curves, GIMP runs a smoothing algorithm across the selection perimeter.

  • Filter Iteration: Sets how many times the smoothing filter passes over the raw perimeter coordinates. Increasing this number yields smoother curves before the Bezier path is generated.
  • Filter Epsilon: Works alongside iterations to determine the neighborhood radius used during each smoothing pass. Higher values increase the flattening of minor surface bumps.

Corner Threshold

The Corner Threshold controls whether an angle along the boundary is treated as a sharp corner or smoothed out into a continuous curve.

  • A lower angle value forces more vertices to become sharp corner points.
  • A higher angle value tells GIMP to smooth out sharp directional changes into rounded Bezier curves.

Subdivide Threshold

When GIMP evaluates curve segments, the Subdivide Threshold determines the tolerance for splitting an edge into smaller sub-segments. Lower values create more subdivisions, producing denser and more rigid paths, whereas higher values prevent unnecessary divisions to maintain sweeping, uninterrupted curves.

How to Use Non-Destructive GEGL Filters in GIMP

This article provides a straightforward guide to performing non-destructive editing in GIMP using GEGL (Generic Graphical Library) filters. You will learn how GEGL handles image processing, how to apply dynamic filter effects directly to layers without permanently overwriting original pixels, how to modify filter settings at any time, and best practices for saving your projects to preserve editability.

What Is GEGL Non-Destructive Editing?

GEGL is the core image processing engine behind modern versions of GIMP. Non-destructive editing means applying adjustments, filters, and color corrections as dynamic operations rather than permanently altering the underlying pixel data. This allows you to revisit, adjust, reorder, or completely remove filter effects at any stage of your workflow.

Step-by-Step: Applying Non-Destructive Filters

In modern GIMP releases (starting with the GIMP 2.99 development branch and GIMP 3.0+), GEGL filters can be attached directly to layers as non-destructive effects.

1. Select the Target Layer

Open your project and navigate to the Layers dockable dialog. Click on the layer you wish to modify.

2. Apply a GEGL Filter

  1. Go to the top menu and select Filters (or open Tools > GEGL Operation).
  2. Choose the filter you want to apply, such as Gaussian Blur, Unsharp Mask, or Color Temperature.
  3. A settings dialog will appear. Adjust the sliders to achieve the desired look.
  4. Ensure the dynamic preview is checked so you can view changes in real time.
  5. Click OK to apply the filter.

3. Re-Editing Applied Filters

Because the filter is applied non-destructively, it appears as an attached effect in your layer stack:

  • Locate the effect icon or sub-item directly underneath the target layer in the Layers panel.
  • Double-click the filter entry to reopen its settings dialog.
  • Modify the values, change blend modes, or adjust opacity specific to that effect.
  • Click OK to update the effect instantly.

4. Toggling and Removing Effects

  • Hide an effect: Click the eye icon next to the filter name to temporarily disable it.
  • Delete an effect: Right-click the filter in the layer stack and select Remove Effect, or select it and press the delete icon.

Non-Destructive GEGL Workflow in GIMP 2.10

If you are using GIMP 2.10, which does not fully support persistent layer effect stacks, you can still maintain a non-destructive workflow using duplicate layers and layer masks:

  1. Duplicate the Original Layer: Right-click your base layer and select Duplicate Layer (Ctrl + Shift + D or Cmd + Shift + D).
  2. Apply the GEGL Filter: Select the duplicated layer and run your GEGL filter via the Filters menu.
  3. Add a Layer Mask: Right-click the filtered layer and choose Add Layer Mask. Paint with black to conceal the filter or white to reveal it.
  4. Adjust Opacity and Blending: Tweak the layer’s opacity and blend mode to blend the effect non-destructively with the original layer underneath.

Saving Your Non-Destructive Work

To keep all GEGL filter parameters editable for future sessions:

  • Always save your master project in GIMP's native format by going to File > Save As and selecting the .xcf file extension.
  • Standard export formats such as .png, .jpeg, or .webp will flatten your effects into a single pixel layer, making subsequent non-destructive adjustments impossible.

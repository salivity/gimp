Override GIMP User Configuration Path

This article explains how to redirect GIMP's user settings directory using system environment variables. By understanding and setting the GIMP2_DIRECTORY (or GIMP3_DIRECTORY) variable, you can store your custom brushes, scripts, themes, and configuration files in a custom folder, external drive, or separate profile rather than the operating system's default location.

The Environment Variable

The primary environment variable used to override the default user configuration path for GIMP is GIMP2_DIRECTORY for GIMP 2.x releases. For upcoming or current installations of GIMP 3.x, the corresponding variable is GIMP3_DIRECTORY.

When set, GIMP bypasses its standard configuration lookup and uses the path specified by the variable to read and write all user data, including gimprc, plug-ins, palettes, and tool presets.

Default Locations

Without this variable set, GIMP defaults to standard OS-specific directories:

  • Linux / Unix: ~/.config/GIMP/2.10/
  • Windows: %APPDATA%\GIMP\2.10\
  • macOS: ~/Library/Application Support/GIMP/2.10/

How to Set the Variable

Linux and macOS

To run a single instance of GIMP with a custom configuration directory via the terminal:

GIMP2_DIRECTORY="/path/to/custom/config" gimp

To make the change persistent for your user session, export the variable in your shell profile (~/.bashrc, ~/.zshrc, or ~/.profile):

export GIMP2_DIRECTORY="/path/to/custom/config"

Windows

To launch GIMP with a temporary custom path using Command Prompt:

set GIMP2_DIRECTORY=C:\Path\To\Custom\Config
start gimp-2.10.exe

To set it permanently across the system:

  1. Open the Start menu and search for Environment Variables.
  2. Click Edit the system environment variables.
  3. In the System Properties window, select Environment Variables.
  4. Under User variables, click New.
  5. Set the Variable name to GIMP2_DIRECTORY.
  6. Set the Variable value to your chosen directory path.
  7. Click OK to apply.

Common Use Cases

  • Portable Setups: Running GIMP from a flash drive with all custom assets contained on the drive.
  • Testing and Debugging: Creating clean configuration profiles without deleting existing settings.
  • Multiple Workspaces: Maintaining separate presets and tool configurations for distinct workflows, such as digital painting versus photo editing.

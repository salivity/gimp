How to Set GIMP Brush Spacing and Aspect Ratio

This guide explains how to customize brush spacing and aspect ratio using GIMP’s Brush Editor. Modifying these parameters allows you to control the continuity of your brushstrokes and transform standard circular or square tips into specialized shapes like calligraphic or flat chisel tips.

Opening the Brush Editor

  1. Open GIMP and navigate to the Brushes panel (go to Windows > Dockable Dialogs > Brushes if it is not visible).
  2. Select a parametric brush (generated brushes, typically indicated by a blue icon) or click the Create a new brush button at the bottom of the Brushes dock. Note that predefined bitmap brushes cannot be modified directly in the Brush Editor; you must use a parametric brush or create a new one.
  3. Open the Brush Editor by double-clicking the brush icon or by clicking the Edit this brush button at the bottom of the Brushes dialog.

Adjusting Brush Spacing

The Spacing setting controls the distance between individual brush marks along a stroke:

  1. Locate the Spacing slider at the bottom of the Brush Editor dialog.
  2. Drag the slider to the left (between 1.0 and 10.0) to decrease spacing. This creates a solid, unbroken, and smooth line.
  3. Drag the slider to the right (above 20.0) to increase spacing. This separates the individual stamps, creating a dashed or dotted effect.
  4. You can also enter an exact numerical percentage directly into the input box.

Adjusting Aspect Ratio

The Aspect Ratio setting alters the proportion between the width and height of the brush tip:

  1. Locate the Aspect Ratio slider in the Brush Editor dialog.
  2. Move the slider to flatten or elongate the brush tip. A value of 0 represents a standard, symmetrical shape (1:1 ratio).
  3. Moving the slider changes the brush into an elliptical or rectangular shape.
  4. Combine this adjustment with the Angle slider just below it to tilt the flattened brush tip, which is ideal for creating calligraphy or ribbon-style strokes.

Quick Adjustments in Tool Options

If you need temporary adjustments without modifying the brush preset itself, you can also alter these properties directly in the Tool Options panel whenever a painting tool (such as the Paintbrush or Pencil) is active:

  • Adjust the Aspect Ratio slider to squash or stretch the brush on the fly.
  • Expand the Spacing property to increase or decrease stamp distance for the active session.

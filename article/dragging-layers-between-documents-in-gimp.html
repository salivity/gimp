Dragging Layers Between Documents in GIMP

Dragging a layer thumbnail from one open document tab onto another canvas in GIMP duplicates that layer into the destination project without altering the original file. This action serves as a quick, intuitive shortcut for copying visual elements between different workspaces. This guide explains the exact mechanics of this transfer, including how layer order, positioning, and visual attributes are handled during the process.

The Immediate Result: Duplication

When you drag a layer thumbnail from the Layers dockable dialog of one image and drop it onto the canvas of another open image tab, GIMP instantly creates an exact copy of the source layer inside the target document. The original layer remains completely untouched in the source file.

Layer Placement in the Stack

The newly imported layer is placed directly above whichever layer was currently active in the destination document's layer stack. If you need it higher or lower in the hierarchy, you can reorder it afterward using the standard layer controls or by dragging it within the target document's Layers panel.

Canvas Positioning and Dimensions

The imported layer retains its original pixel dimensions, regardless of the destination image's canvas size:

  • Larger Canvases: If the target canvas is larger than the imported layer, the layer appears at its native size, placed where your cursor released the drag.
  • Smaller Canvases: If the target canvas is smaller, the imported layer will extend beyond the visible canvas boundary. The hidden pixels are not cropped or deleted; you can reposition the layer at any time using the Move Tool (M) to reveal different parts of the image.

Preservation of Layer Attributes

GIMP transfers most layer attributes seamlessly during this operation:

  • Blending Modes and Opacity: The layer's blend mode (such as Multiply, Screen, or Overlay) and opacity percentage are maintained.
  • Layer Masks: If the original layer has an active layer mask, the mask is copied alongside the layer data and remains linked.
  • Alpha Channel: Transparency settings are fully preserved.

Color Profile and Mode Adjustments

If the source and target documents use different color modes, GIMP automatically adapts the transferred layer to match the destination project:

  • Moving a layer from an RGB document into an Indexed or Grayscale document converts the layer's colors to match the target document's palette or grayscale profile.
  • Moving a layer from a Grayscale document into an RGB canvas allows the grayscale layer to exist inside the full-color workspace without altering the rest of the project.

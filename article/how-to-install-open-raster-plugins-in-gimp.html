How to Install OpenRaster Plugins in GIMP

This guide provides a straightforward procedure for installing OpenRaster (ORA) interchange format plugins in GIMP to enable seamless layered image sharing between applications like Krita, MyPaint, and GIMP. While recent versions of GIMP include native OpenRaster support, installing updated or custom third-party Python plugins ensures compatibility with newer specifications. Below, you will find the exact steps to locate GIMP's plugin directory, add the required script files, configure permissions, and verify the installation.

Step 1: Check Built-in Support

Modern versions of GIMP (version 2.8 and newer) include basic OpenRaster import and export capabilities by default. To check if your installation already supports it:

  1. Open GIMP.
  2. Go to File > Open and check the file format drop-down list for OpenRaster image (*.ora).
  3. If it is missing, or if you need an updated plugin with enhanced features, proceed with the manual installation steps below.

Step 2: Obtain the OpenRaster Plugin

  1. Download the OpenRaster plugin file (typically named openraster.py or packaged in a .zip archive) from your chosen source or repository.
  2. If the file is compressed, extract it to access the .py script.

Step 3: Locate GIMP's Plug-ins Folder

To ensure the plugin loads correctly, place it in GIMP's user plug-ins directory:

  1. Launch GIMP.
  2. Navigate to Edit > Preferences (or GIMP > Preferences on macOS).
  3. In the left panel, scroll down and expand the Folders section.
  4. Click on Plug-ins.
  5. Select the user-specific path (usually located within your user profile directory) and click the Show file location in file manager button (the filing cabinet icon).

Default folder paths:

  • Windows: C:\Users\<Your-Username>\AppData\Roaming\GIMP\<version>\plug-ins
  • macOS: /Users/<Your-Username>/Library/Application Support/GIMP/<version>/plug-ins
  • Linux: ~/.config/GIMP/<version>/plug-ins

Step 4: Install the Plugin File

  1. Copy the openraster.py file.
  2. Paste it directly into the plug-ins folder you located in Step 3.

Step 5: Configure Permissions (Linux and macOS Only)

On Unix-based systems, Python plugins must be marked as executable:

  1. Open your terminal.
  2. Navigate to your plug-ins directory: 
    cd ~/.config/GIMP/<version>/plug-ins
  3. Run the following command to make the script executable: 
    chmod +x openraster.py

Step 6: Restart GIMP and Verify

  1. Close GIMP completely and reopen it.
  2. Go to File > Open to confirm that .ora files can now be selected.
  3. Go to File > Export As..., expand Select File Type (By Extension), and ensure OpenRaster image (*.ora) is available as an export target.

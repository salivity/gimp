How to Import Apple HEIC and HEIF Photos in GIMP

Modern versions of GIMP provide native support for importing High Efficiency Image Container (HEIC) and High Efficiency Image File (HEIF) formats used by Apple iPhones and other modern smartphones. Starting with version 2.10.22, GIMP integrates standard decoding libraries that allow users to open, edit, and export these files without third-party plugins. This article covers how GIMP processes HEIC/HEIF files, how the import workflow behaves across different operating systems, and how to address potential compatibility or color profile issues.

Native Support via libheif

GIMP handles HEIC and HEIF files using the open-source libheif library. When you open a .heic or .heif file, GIMP detects the container format and automatically parses the compressed HEVC (H.265) image data into an editable raster image.

The import process is identical to standard image formats:

  1. Go to File > Open or drag and drop the image directly into the GIMP canvas.
  2. GIMP unpacks the compressed data and loads the image into a standard RGB layer.
  3. If an embedded color profile (such as Apple's Display P3) is detected, GIMP displays a dialog asking whether to keep the embedded profile or convert it to your default working space (typically sRGB).

Operating System Differences

While GIMP natively includes HEIC support, availability depends on how the software is packaged on your operating system:

  • Windows: The official standard installer from the GIMP website includes the necessary libheif components. You do not need to purchase or install the HEVC video extensions from the Microsoft Store for GIMP to read the files.
  • macOS: Standard GIMP DMG packages bundle the HEIC decoder by default, enabling direct import on modern macOS versions.
  • Linux: Most modern distributions include HEIC support in GIMP by default. However, if using minimal package installations, you may need to install the libheif or gimp-heif package via your package manager. The Flatpak and Snap releases of GIMP come pre-configured with complete HEIC support.

Color Depth and Metadata Handling

Apple devices frequently capture HEIC photos with 10-bit or 12-bit color depth, especially when HDR or Deep Fusion is enabled. GIMP's GEGL-based processing engine imports this high-bit-depth data directly, preserving tonal range and preventing banding during the editing process.

Additionally, GIMP reads and retains the EXIF, XMP, and IPTC metadata embedded in the HEIC container, preserving capture data such as GPS location, camera settings, and timestamps.

Limitations with Apple-Specific Features

While standard HEIC images import cleanly, certain proprietary Apple features require specific handling:

  • Live Photos: GIMP only extracts the primary, high-resolution still frame. The paired short video clip (.mov) is ignored.
  • Portrait Mode (Depth Maps): iOS often embeds a separate depth map inside the HEIC container. GIMP typically imports the rendered primary image with the depth blur applied, but it does not automatically separate the depth map into an editable layer mask.
  • Burst Photos: When multiple images are saved within a single HEIC container, GIMP generally opens the selected cover photo rather than expanding every shot as individual layers.

How to Use the Gradient Map Filter in GIMP

The Gradient Map filter in GIMP is a powerful tool for color grading and stylizing images by replacing the existing brightness values of a layer with colors sampled from an active gradient. Shadows correspond to the left side of the gradient, highlights correspond to the right, and midtones fill the space in between. This guide walks you through creating a custom color gradient tailored to your desired tonal ranges and applying it directly to your project for precise color mapping.

1. Prepare Your Layer

  1. Open your image in GIMP.
  2. Duplicate the base layer by right-clicking it in the Layers panel and selecting Duplicate Layer. Working on a duplicate preserves your original artwork and allows for blending adjustments later.
  3. If necessary, adjust the contrast of this duplicate layer using Colors > Levels or Colors > Curves. Stronger contrast yields clearer separation between the mapped colors.

2. Create a Custom Gradient

To map specific tones to exact colors, you must build a custom gradient:

  1. Open the Gradients dockable dialog by navigating to Windows > Dockable Dialogs > Gradients.
  2. Click the Create a new gradient icon (the blank page symbol) at the bottom of the dialog. The Gradient Editor window will open.
  3. Right-click inside the gradient preview area to access the segment controls:
    • Left Endpoint Color: Sets the color for the darkest tones (pure blacks/shadows). Right-click and choose Left Endpoint's Color to pick your shadow hue.
    • Right Endpoint Color: Sets the color for the brightest tones (pure whites/highlights). Right-click and choose Right Endpoint's Color to assign your highlight hue.
  4. To map specific midtones, right-click the gradient strip and choose Split Segment at Midpoint. This creates a new stop.
  5. Click and drag the small white and black triangles below the gradient strip to position where the colors transition.
  6. Right-click a segment and modify Left Endpoint's Color or Right Endpoint's Color to assign distinct colors across your shadows, three-quarter tones, midtones, and highlights.
  7. Name and save your gradient. Ensure it remains highlighted as the active gradient in the Gradients panel.

3. Apply the Gradient Map Filter

  1. Select the target layer in the Layers panel.
  2. Go to the top menu and select Colors > Map > Gradient Map.
  3. GIMP will instantly replace the tonal values of the layer with the color range of the active gradient:
    • Luminance values near 0 (black) map to the leftmost color.
    • Luminance values near 255 (white) map to the rightmost color.
    • Intermediate grayscale values map sequentially along the gradient spectrum.

4. Fine-Tune the Result

  • Adjust Blend Modes: Change the mapped layer’s blend mode in the Layers panel (such as Overlay, Soft Light, or Color) to blend the new color scheme naturally with original details.
  • Modify Opacity: Lower the layer opacity slider to reduce the intensity of the color effect.
  • Invert Mapping: If the colors appear backward (shadow colors appearing in highlights), reverse the gradient in the Gradient Editor by right-clicking and selecting Flip Segment, then reapply the filter.

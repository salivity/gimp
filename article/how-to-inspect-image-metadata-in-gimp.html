How to Inspect Image Metadata in GIMP

Image metadata contains crucial technical and descriptive information about a photo, including camera settings, copyright details, and location data. This guide provides a straightforward walkthrough on how to inspect, read, and understand Exif, XMP, and IPTC metadata using the built-in tools available in GNU Image Manipulation Program (GIMP).

Steps to View Metadata in GIMP

  1. Open your image: Launch GIMP and open the image file you want to inspect by going to File > Open or dragging the file into the workspace.
  2. Access the metadata tool: In the top menu bar, click on Image, hover over Metadata, and select View Metadata.
  3. Browse the metadata tabs: A dedicated window will appear with multiple tabs organizing the embedded data:
    • Exif: Contains hardware and capture details recorded by the camera, such as camera make/model, shutter speed, aperture (F-number), ISO, focal length, date and time of capture, and GPS coordinates.
    • IPTC: Contains industry-standard editorial data, such as the creator's name, copyright notice, image title, description, and keywords.
    • XMP: Displays XML-based metadata standard developed by Adobe, which often mirrors or extends Exif and IPTC fields, including editing history, color profiles, and custom tags.

How to Edit or Remove Metadata

If you need to modify or delete specific metadata fields instead of just viewing them:

  1. Go to Image > Metadata > Edit Metadata.
  2. Navigate through the available categories (Description, Copyright, Origin, Location, Camera) to add, change, or clear values.
  3. Click Write Metadata to apply your changes to the working image file.

Preserving or Stripping Metadata on Export

When saving your final image (e.g., via File > Export As...):

  • In the export dialog box for formats like JPEG or PNG, expand the Advanced Options section.
  • Check or uncheck Save Exif data, Save XMP data, and Save IPTC data depending on whether you want to preserve privacy by stripping metadata or retain information for archival purposes.

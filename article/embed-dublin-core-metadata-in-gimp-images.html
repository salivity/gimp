Embed Dublin Core Metadata in GIMP Images

Embedding Dublin Core metadata into your images ensures your digital assets carry standardized descriptive information, such as creator details, rights statements, and titles, wherever they travel. GIMP provides a native Metadata Editor that interfaces with the Extensible Metadata Platform (XMP) structure, allowing users to embed Dublin Core schema properties directly into their image files. This guide details how to locate the editor, configure Dublin Core attributes, and export the file while preserving this metadata.

Step 1: Open the Metadata Editor

  1. Launch GIMP and open the image you want to configure.
  2. Navigate to the top menu and select Image.
  3. Hover over Metadata and click on Edit Metadata.

Step 2: Input Dublin Core Information

The GIMP Metadata Editor organizes metadata into several functional tabs that map directly to standard Dublin Core (dc:) properties:

  • Description Tab:
    • Image Title: Corresponds to dc:title. Enter a concise, identifiable name for the asset.
    • Description / Caption: Corresponds to dc:description. Provide an explanation or contextual summary of the image.
    • Keywords: Corresponds to dc:subject. Add relevant search terms separated by commas or line breaks.
  • Copyright / Rights Tab:
    • Copyright Notice: Corresponds to dc:rights. State the copyright holder, year, or licensing terms (such as Creative Commons licenses).
    • Usage Terms: Specify any constraints or permissions regarding image reproduction.
  • Creator / Origin Tab:
    • Artist / Creator: Corresponds to dc:creator. Enter the name of the photographer, designer, or organization responsible for the work.
    • Credit: Enter appropriate attribution lines.
    • Date Created: Corresponds to dc:date. Input the creation date in standard YYYY-MM-DD format if not automatically populated.

Step 3: Write the Metadata to the Active Project

Once all relevant Dublin Core fields are filled out:

  1. Click the Write Metadata button in the lower-right corner of the editor window.
  2. This action commits the changes to GIMP's active image buffer.

Step 4: Export with Preserved XMP Data

To ensure the Dublin Core schema is permanently embedded in the final output file:

  1. Go to File > Export As...
  2. Choose a file format that natively supports embedded XMP/Dublin Core metadata, such as JPEG, TIFF, or WebP.
  3. Click Export.
  4. In the format-specific export dialog that appears, expand the Advanced Options section (if available).
  5. Ensure the Save XMP data and Save Exif data checkboxes are selected.
  6. Click Export to finalize the image file.

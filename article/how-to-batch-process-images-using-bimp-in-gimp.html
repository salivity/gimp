How to Batch Process Images Using BIMP in GIMP

Batch processing allows you to apply the same edits—such as resizing, watermarking, format conversion, and color adjustments—to hundreds of photos simultaneously. While GIMP does not include an advanced batch processor by default, the Batch Image Manipulation Plugin (BIMP) integrates directly into the software to automate repetitive tasks efficiently. This guide outlines how to set up BIMP, configure image manipulation rules, and execute batch edits on multiple files in GIMP.

1. Install the BIMP Plugin

Before starting, ensure BIMP is installed on your system:

  • Windows: Download the Windows installer from the official BIMP repository or plugin registry and run the setup wizard while GIMP is closed.
  • Linux: Install BIMP via your distribution package manager (e.g., sudo apt install gimp-plugin-bimp on Debian/Ubuntu) or compile it from source.
  • macOS: Download the pre-compiled binary package or install it via Homebrew/MacPorts depending on your GIMP installation method.

Restart GIMP once the installation is complete.

2. Open the BIMP Interface

  1. Launch GIMP.
  2. Navigate to the top menu and select File > Batch Image Manipulation....
  3. The BIMP interface will open in a separate window.

3. Add Input Images

In the Input images section at the top of the BIMP window:

  • Click Add images to select specific files individually.
  • Click Add folders to import an entire directory of photos.
  • Check Include subfolders if your source folder contains nested subdirectories of images.

4. Set Manipulation Rules

In the Manipulation set section, click Add to choose the modifications you want to apply. You can stack multiple operations:

  • Resize: Set new dimensions by pixels or percentage, and choose whether to maintain the aspect ratio.
  • Crop: Define specific pixel areas or aspect ratios to trim from the images.
  • Flip or Rotate: Apply orientation adjustments to all images uniformly.
  • Color Correction: Adjust brightness, contrast, levels, or convert images to grayscale.
  • Watermark: Overlay a logo or text onto a designated position on every image.
  • Change Format and Compression: Choose an output format (such as JPEG, PNG, or WebP) and adjust quality/compression levels.
  • Rename with a Pattern: Define naming conventions using prefixes, suffixes, original filenames, or auto-incrementing numbers.
  • Other GIMP Procedure: Run custom GIMP scripts or native functions on the batch.

5. Choose the Output Location

At the bottom of the window, locate the Output folder section:

  1. Click the folder icon to select the destination directory where processed files should be saved.
  2. Ensure you choose a different folder from your original files to avoid accidentally overwriting source images.

6. Execute the Batch Process

  1. Review the list of operations in your manipulation set to verify the order of execution.
  2. Click the Apply button in the bottom right corner.
  3. A progress bar will show the processing status. Once completed, navigate to your designated output folder to review the finished images.

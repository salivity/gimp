How to Set PDF Page Range and DPI in GIMP

Importing a PDF into GIMP requires rasterizing vector content into pixels, making page selection and resolution settings critical for the final output quality. When opening a PDF file, GIMP provides a dedicated "Import from PDF" dialog window where you can designate specific page ranges, choose whether to import pages as separate images or individual layers, and define a custom target dots per inch (DPI) resolution to maintain image clarity.

Step 1: Open the PDF File

  1. Launch GIMP.
  2. Click File in the top menu and select Open (or press Ctrl + O on Windows/Linux, Cmd + O on macOS).
  3. Navigate to your PDF file, select it, and click Open.

Step 2: Specify the Page Range

The "Import from PDF" dialog box will appear automatically. To choose which pages to import:

  • Select a continuous range: Click the first page you want to import, hold down the Shift key, and click the last page in the range.
  • Select non-consecutive pages: Hold the Ctrl key (Windows/Linux) or Cmd key (macOS) and click each individual page you want to import.
  • Select all pages: Click the Select All button below the page preview pane.

Choose how these pages open using the Open pages as dropdown:

  • Select Layers to place every selected page into a single document as separate layers.
  • Select Images to open each page as its own separate document tab in GIMP.

Step 3: Set the Target DPI Resolution

By default, GIMP often imports PDFs at 100 pixels per inch (PPI/DPI), which can produce low-resolution, blurry results.

  1. Locate the Resolution field at the bottom right of the import dialog.
  2. Change the value to your desired DPI:
    • Enter 72 or 96 for standard web and screen use.
    • Enter 300 for high-quality standard printing.
    • Enter 600 or higher for detailed line art or large-format output.
  3. Ensure the unit measurement dropdown next to the value is set to pixels/in.
  4. Increasing the DPI will automatically scale the pixel dimensions (width and height) displayed directly above the resolution box.

Step 4: Finalize the Import

Once your pages are selected and the resolution is configured, click the Import button in the lower-right corner. GIMP will process the document and render the selected pages at your specified resolution.

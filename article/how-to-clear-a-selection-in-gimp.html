How to Clear a Selection in GIMP

An active selection in GIMP—indicated by the moving dashed outline known as "marching ants"—can be removed instantly depending on whether you want to dismiss the selection boundary or delete the image data inside it. This guide covers the fastest keyboard shortcuts and menu commands to deselect your active area completely or clear the contents within that selection.

The Fastest Way: Dismiss the Selection Boundary (Deselect)

If you want to remove the active selection boundary so that no pixels are selected, use the Select None command.

  • Windows / Linux Shortcut: Press Shift + Ctrl + A
  • macOS Shortcut: Press Shift + Command + A
  • Menu Navigation: Click Select in the top menu bar, then choose None.

Using this shortcut immediately drops the selection, allowing you to edit the entire layer or canvas again without restrictions.

Alternative: Clear the Pixels Inside the Selection

If your goal is to delete the image contents located inside the active selection rather than removing the outline:

  • Keyboard Shortcut: Press the Delete key (or Backspace depending on your OS configuration).
  • Menu Navigation: Click Edit in the top menu bar, then select Clear.

This action removes the pixels within the active area, leaving it transparent (if the layer has an alpha channel) or filling it with the current background color. To completely remove the selection boundary afterward, follow up with Shift + Ctrl + A.

How to Connect Path Endpoints in GIMP

Connecting two open endpoints of a path in GIMP allows you to combine separate subpaths or close an open line into a solid shape ready for stroking or selection. This guide explains the exact steps to merge two open endpoints seamlessly using the Paths tool and a simple keyboard shortcut.

Step 1: Select the Paths Tool

Open your project in GIMP and activate the Paths Tool by pressing the shortcut key B or by selecting it from the Tools panel. Ensure the Tool Options dock is set to Design mode, which is the default mode used for creating and manipulating nodes.

Step 2: Make the Path Active

Go to the Paths dialog (usually grouped near the Layers tab). Click on the path layer containing the segments you want to connect. Click inside the canvas on an existing segment of the path to make its nodes visible and editable.

Note: If your two endpoints belong to entirely different path layers, right-click one in the Paths dialog, choose Merge Visible Paths, and make sure both are visible before proceeding.

Step 3: Select the First Endpoint

Click directly on one of the open endpoints you want to connect. When selected, the node will change appearance (typically becoming hollow or showing directional handles), indicating that it is the active point of the path.

Step 4: Connect to the Second Endpoint

  1. Hover your cursor over the second open endpoint.
  2. Hold down the Ctrl key (on Windows/Linux) or Cmd key (on macOS). You will see the mouse cursor change to show a small connecting chain/loop symbol next to the cursor.
  3. While still holding the modifier key, click directly on the second endpoint.

GIMP will instantly draw a new segment between the two nodes, linking them together into a continuous path. If both endpoints belonged to the same open stroke, this action completes and closes the shape.

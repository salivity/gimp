How to Reposition Gradient Stops in GIMP

GIMP’s on-canvas Gradient tool allows you to manipulate color transitions directly within your workspace rather than relying solely on dialog menus. By utilizing interactive on-canvas stop widgets—represented by square markers along the gradient line—you can dynamically reposition color nodes, modify blending distances, and fine-tune your color transitions in real time. This guide outlines how to activate the tool, locate these widgets, and drag color stops along the gradient vector to achieve precise positioning.

1. Activate the Gradient Tool

Select the Gradient Tool from the main toolbox or press the keyboard shortcut G. In the Tool Options dock, ensure your desired base gradient and shape (such as Linear or Radial) are selected.

2. Draw the Initial Gradient Vector

Click and drag across your canvas or active selection to establish the gradient's direction and length. Releasing the mouse button reveals the interactive on-canvas line with endpoints and intermediate markers.

3. Identify the Stop Widgets

On the gradient line, GIMP displays two primary types of interactive widgets:

  • Square Handles: These represent color stops (nodes) where specific colors are anchored. The starting and ending points are squares, as are any custom color stops added between them.
  • Round/Diamond Handles: These represent midpoints between two color stops, controlling the balance and transition rate between adjacent colors.

4. Reposition Color Nodes (Stops)

To reposition an intermediate color stop:

  1. Hover your cursor over the square stop widget you wish to move until the cursor indicates it can interact with the point.
  2. Click and hold the square handle.
  3. Drag the handle forward or backward along the gradient line. The color blend will update interactively across the canvas.
  4. Release the mouse button at the desired location.

To reposition the start or end nodes, click and drag the outer square handles. Unlike intermediate stops, moving the endpoints changes the overall length, orientation, and angle of the entire gradient.

5. Add and Adjust New Stops

If your gradient requires more color transitions:

  • Click anywhere directly on the gradient line where there is no existing widget. GIMP will insert a new square stop node.
  • Click and drag this newly created square widget along the line to place it at the exact percentage or position you require.

6. Fine-Tune Position via Tool Options

For mathematically precise placement:

  1. Click the square stop handle to make it the active stop (it will change color to show it is selected).
  2. Look at the floating gradient bar on the canvas or the Tool Options panel.
  3. Adjust the Position numerical slider to set the exact position of the stop as a percentage (from 0% to 100%) along the segment.

7. Commit the Changes

Once the color stops are in their correct positions, press Enter or switch to another tool to commit the gradient to the layer.

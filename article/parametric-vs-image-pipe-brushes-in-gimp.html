Parametric vs Image Pipe Brushes in GIMP

In GIMP, understanding your toolset is vital for efficient digital painting, and two of the most distinct brush formats available are parametric brushes (.vbr) and image pipe brushes (.gih). While parametric brushes are procedurally generated shapes that offer instant mathematical adjustments to size, shape, and hardness, image pipe brushes are multi-layered raster sprites that spray textured, colored, or sequential patterns across the canvas. This guide breaks down their core technical differences, customization options, and primary use cases to help you choose the right tool for your workflow.

What Is a Parametric Brush (.vbr)?

A parametric brush, saved with the .vbr (Vector Brush) extension, is a mathematically calculated shape rather than a pixel-based image. GIMP generates these brushes using pure geometry, allowing you to create standard shapes such as circles, squares, and diamonds.

The primary advantage of parametric brushes is their on-the-fly customizability. Through the Brush Editor dialog, you can adjust parameters like radius, hardness, aspect ratio, angle, and the number of spikes without losing quality. Because they rely on formulas rather than raster images, .vbr files have a negligible file size and remain sharp at virtually any dimension. However, they are strictly monochrome; they act as masks that only paint with your chosen active foreground color.

What Is an Image Pipe Brush (.gih)?

An image pipe brush, saved with the .gih (GIMP Image Hose) extension, is a collection of raster images stored in a single brush file. Instead of rendering a static shape, the brush "pipes" or sprays different images onto the canvas as you draw.

Image pipe brushes can be configured to react dynamically to input variables. GIMP can cycle through the brush's image layers based on stroke direction, drawing speed, tablet pressure, tilt, or random distribution. Additionally, .gih brushes support full-color (RGB) graphics with built-in transparency. This makes them ideal for complex, textured elements like foliage, footprints, chains, hair strands, or scattered debris. Because they rely on pre-rendered bitmaps, scaling them up beyond their native resolution will cause pixelation.

Key Differences

  • Underlying Architecture: Parametric brushes (.vbr) are vector-like mathematical shapes. Image pipe brushes (.gih) are multi-layered raster bitmaps.
  • Color Capabilities: Parametric brushes only stamp the active foreground color. Image pipes can preserve full RGB color palettes, gradients, and pre-baked shading.
  • Dynamic Variation: Parametric brushes render a consistent shape along a stroke. Image pipes can alternate shapes, angles, and colors dynamically with each dab based on stylus input or randomized settings.
  • Flexibility and Editing: Parametric brushes can be reshaped and fine-tuned instantly inside GIMP's interface. Image pipe brushes must be designed layer-by-layer in a separate image project before being exported as a .gih file.
  • Resource Impact: Parametric brushes require minimal memory and disk space. Image pipe brushes can become heavy on system resources if they contain dozens of high-resolution layers.

When to Use Each

Choose parametric brushes (.vbr) for foundational digital artwork tasks such as sketching, inking, basic shading, and clean-line illustration where you need precise control over edge softness and geometric dimensions.

Choose image pipe brushes (.gih) when you need to paint complex natural elements, repeating visual textures, or animated sequences where variety and rich color detail cannot be achieved using a single static stamp.

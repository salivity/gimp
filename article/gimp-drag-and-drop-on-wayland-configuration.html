GIMP Drag and Drop on Wayland Configuration

Drag-and-drop operations between native Wayland file managers and GIMP often fail because stable versions of GIMP (such as GIMP 2.10) rely on the legacy GTK 2 toolkit, which runs via the XWayland compatibility layer. When a native Wayland application attempts to send file URIs to an XWayland client, the Wayland compositor may fail to translate the drop event or the mime type payload correctly. This guide outlines the exact steps to configure your environment, launcher, and package settings to restore drag-and-drop functionality for opening images in GIMP on Wayland.

Force the X11 Backend on Desktop Launchers

If your desktop session runs on Wayland, the most reliable way to ensure the compositor bridges drag-and-drop data to GTK 2 applications is to explicitly set the GDK backend to X11.

  1. Copy the system GIMP desktop entry to your local user directory:

    cp /usr/share/applications/gimp.desktop ~/.local/share/applications/

  2. Open the file in a text editor:

    nano ~/.local/share/applications/gimp.desktop

  3. Locate the Exec= line and prepend the environment variable env GDK_BACKEND=x11:

    Exec=env GDK_BACKEND=x11 gimp-2.10 %U

  4. Save the file and update the desktop database:

    update-desktop-database ~/.local/share/applications

Configure Flatpak Permissions for Wayland Sessions

If you are running GIMP as a Flatpak, sandbox permissions can block file drag-and-drop payloads passing through the Wayland-to-X11 bridge.

  1. Grant the Flatpak package fallback X11 and filesystem permissions via the terminal:

    flatpak override --user --socket=fallback-x11 org.gimp.GIMP
flatpak override --user --socket=x11 org.gimp.GIMP

  2. Alternatively, force the Flatpak instance to run under the X11 backend:

    flatpak override --user --env=GDK_BACKEND=x11 org.gimp.GIMP

Enable Native Wayland Protocols via GIMP 3.0

The underlying architectural issue is resolved in GIMP 3.0, which transitions the application to the GTK 3 toolkit and supports native Wayland drag-and-drop protocols without requiring XWayland translation.

If your distribution offers GIMP 3.0 release candidates or development packages:

  1. Install the GIMP 3.x package or flatpak branch:

    flatpak install flathub-beta org.gimp.GIMP

  2. Ensure the package is allowed native Wayland socket access:

    flatpak override --user --socket=wayland org.gimp.GIMP

  3. Run GIMP directly without forcing X11 variables, allowing the native Wayland clipboard and drag-and-drop interfaces (wl_data_device) to negotiate file transfers directly with Wayland file managers like GNOME Files (Nautilus) or KDE Dolphin.

How to Set Precise Anchor Point for Scaling in GIMP

Scaling layers around an exact point in GIMP requires defining a transformation pivot and applying numerical dimensions. While standard scaling defaults to the center or top-left corner, you can position the anchor to an exact pixel coordinate by combining GIMP's precision guides with the Scale Tool's movable origin point.

1. Set the Exact Coordinates with Guides

Because the Scale dialog does not feature direct numerical inputs for the pivot point itself, precision guides serve as the target for the anchor:

  1. Go to Image > Guides > New Guide...
  2. Choose the Horizontal orientation, enter your desired pixel position, and click OK.
  3. Repeat the process by selecting Image > Guides > New Guide..., choosing Vertical, entering the matching pixel coordinate, and clicking OK.
  4. Verify that snapping is active by checking View > Snap to Guides.

2. Activate the Scale Tool

  1. In the Layers panel, select the layer you wish to scale.
  2. Select the Scale Tool from the toolbox or press Shift + S.
  3. Click anywhere on the layer within the canvas to open the on-canvas controls and the floating Scale dialog box.

3. Move the Anchor Pivot

  1. Locate the small circle with crosshairs in the center of the selected layer; this is the scale origin (pivot point).
  2. Click and drag this crosshair directly to the intersection of your horizontal and vertical guides.
  3. The crosshair will snap directly to the pixel-perfect intersection of the guides, locking your scaling anchor into place.

4. Apply Numerical Scaling

  1. In the floating Scale dialog, enter your exact desired dimensions in the Width and Height input fields.
  2. Ensure the chain link icon next to the dimensions is locked if you want to maintain the aspect ratio, or unlocked if scaling independently.
  3. The layer will expand or contract relative to the snapped pivot point rather than the default center.
  4. Click the Scale button (or press Enter) to finalize the transformation.

5. Clean Up Guides

Once the transformation is complete, remove the positioning guides by going to Image > Guides > Remove all Guides.

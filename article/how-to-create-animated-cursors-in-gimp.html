How to Create Animated Cursors in GIMP

This guide explains how to design and compile animated mouse cursors (.ani) using layer stacks in GIMP. You will learn how to properly configure your canvas dimensions, draw sequential frames across separate layers, control animation timing, preview your playback, and export the final product for use in Windows.

1. Set Up the Canvas

  1. Open GIMP and go to File > New.
  2. Set the dimensions to standard cursor sizes: 32 × 32 pixels (standard resolution) or 48 × 48 pixels (high-DPI displays).
  3. Expand Advanced Options, ensure Color Space is set to RGB color, and set Fill with to Transparency.
  4. Click OK.

2. Build the Animation Frame by Frame

GIMP uses layers to represent individual animation frames, playing from the bottom layer upward.

  1. First Frame (Bottom Layer): Draw your base cursor shape. Use the Pencil Tool instead of the Paintbrush to keep edges sharp and pixel-perfect.
  2. Additional Frames: Create a new transparent layer for each subsequent frame of the animation by clicking Layer > New Layer.
  3. Sequence Order: Ensure the starting frame is at the very bottom of the Layers panel and the final frame is at the top.
  4. Define Timing: Rename each layer to specify its duration. Double-click the layer name and add the delay in milliseconds in parentheses, for example: Frame 1 (100ms) or Frame 2 (50ms).

3. Establish the Hotspot Coordinate

The "hotspot" is the exact pixel that registers a click (typically the tip of an arrow or the center of a crosshair). Note the X and Y pixel coordinates of your cursor’s active point from the bottom-left status bar in GIMP, as you will need to input these coordinates during the export or compilation stage.

4. Preview the Animation

  1. Go to Filters > Animation > Playback.
  2. Click the Play button in the playback window to verify frame pacing and motion smoothness.
  3. Close the preview window and adjust individual layer designs or millisecond tags if necessary.

5. Export to .ANI Format

GIMP requires an additional step to finalize the file into the Windows .ani format:

  • Using a GIMP ANI Plugin: If you have installed the third-party GIMP Animated Cursor plugin, go to File > Export As, type your filename with the .ani extension (e.g., cursor.ani), click Export, and enter your hotspot coordinates and frame rates in the prompt.
  • Using a Cursor Compiler (Standard Method):
    1. Go to File > Export As and save the project as an animated GIF or export individual layers as PNGs.
    2. If exporting as GIF, ensure As Animation is checked and select One frame per layer (replace) under Frame Disposal.
    3. Import the resulting GIF or PNG sequence into a free cursor utility (such as RealWorld Cursor Editor) to assign the designated hotspot coordinate and save the file directly as a native Windows .ani file.

6. Apply the Cursor in Windows

  1. Open Windows Settings > Bluetooth & devices > Mouse.
  2. Click Additional mouse settings to open the Mouse Properties dialog.
  3. Switch to the Pointers tab.
  4. Select the pointer role you want to modify (e.g., Working in Background), click Browse, select your .ani file, and click Apply.

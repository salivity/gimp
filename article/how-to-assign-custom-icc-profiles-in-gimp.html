How to Assign Custom ICC Profiles in GIMP

Using custom ICC camera calibration profiles ensures that the colors captured by your camera sensor are rendered accurately on your screen and in your final export. This guide details the exact steps required to add a custom ICC or ICM profile to GIMP and assign it directly to an active image, correcting sensor-specific color casts and maintaining precise color fidelity throughout your editing workflow.

1. Prepare Your ICC Profile File

Ensure your custom ICC profile file (ending in .icc or .icm) is saved on your local drive. This file is typically generated using a color target (such as a ColorChecker) and calibration software.

2. Add the Profile to GIMP’s Profile Directory (Optional)

While you can browse to any folder directly, adding the profile to GIMP’s default directory makes it permanently accessible in profile drop-down menus:

  1. Open GIMP.
  2. Navigate to Edit > Preferences.
  3. In the left panel, expand Folders and select Color Profiles.
  4. Note the listed directory paths or click the Add Folder icon to add the folder where your custom camera ICC profiles are stored.
  5. Click OK to save the preference.

3. Open Your Image in GIMP

Open the image you want to calibrate via File > Open. If GIMP prompts you with a color profile mismatch dialog upon opening, keep the embedded profile for now or leave the image untagged so the custom profile can be assigned properly.

4. Assign the Custom ICC Profile

Assigning a profile changes how the existing pixel values are interpreted without modifying the underlying numbers:

  1. Go to the top menu and select Image > Color Management > Assign Color Profile....
  2. In the dialog box that appears, open the drop-down menu next to Assign.
  3. If your profile appears in the list (from the configured folders), select it.
  4. If it is not in the list, click Select color profile from disk..., browse to the location of your custom .icc or .icm file, select it, and click Open.
  5. Click Assign to apply the profile.

5. Verify the Color Assignment

Once applied, the image's appearance will update immediately in the canvas to reflect the custom camera calibration profile. You can confirm the current profile by looking at the image title bar or by navigating to Image > Color Management > Image Color Profile.

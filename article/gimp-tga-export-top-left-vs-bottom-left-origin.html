GIMP TGA Export: Top-Left vs Bottom-Left Origin

This guide explains how to configure the image origin point—either bottom-left or top-left—when exporting Targa (TGA) files in GIMP. Because different rendering engines, 3D packages, and legacy applications interpret vertical texture coordinates differently, setting the correct origin ensures your textures display right-side up without requiring manual flipping.

How to Configure TGA Origin in GIMP

  1. Open the Export Menu: With your image open in GIMP, navigate to the top menu and select File > Export As... (or press Shift + Ctrl + E).
  2. Select the TGA Format: In the file dialog, append the .tga extension to your file name, or expand the Select File Type (By Extension) menu at the bottom and choose TarGA image. Click Export.
  3. Locate the Origin Setting: The Export Image as TGA dialog window will appear. Look for the Origin section, which provides a dropdown menu or radio buttons depending on your GIMP version.
  4. Choose the Desired Origin:
    • Bottom left: The traditional Targa specification standard. Use this if your target software adheres strictly to legacy Truevision standards or if your engine flips textures rendered with a modern top-left origin.
    • Top left: The standard convention for modern computer graphics and web formats. Choose this if you are importing the asset into modern game engines (like Unreal Engine or Unity) or DirectX-based tools that expect the coordinate space to start from the upper-left corner.
  5. Complete Export: Ensure other settings (such as RLE compression) match your requirements, then click Export to save the file.

Troubleshooting Inverted Textures

If your texture appears upside down when imported into an external application:

  • Return to GIMP and re-export the file via File > Export As....
  • In the TGA options window, switch the Origin setting to the alternate option (from Top-Left to Bottom-Left, or vice versa).
  • Overwrite the file and reload it inside your target application to verify orientation.

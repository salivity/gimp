How to Join Two Paths into a Closed Outline in GIMP

Connecting separate vector components into a single closed outline in GIMP requires using the Paths Tool in Design mode to bridge open endpoints. This article outlines the exact procedure for combining distinct path segments into the same layer, linking their open vertices together, and sealing the final shape into a unified, closed vector contour.

1. Place Components on the Same Path Layer

Before two independent path components can be linked, they must exist within the exact same path item:

  • Open the Paths Dialog (Windows > Dockable Dialogs > Paths).
  • If the components are on separate path layers, make both visible, right-click either one in the Paths dialog, and select Merge Visible Paths.
  • Select the merged path layer to make it active.

2. Activate the Paths Tool

  • Select the Paths Tool from the Toolbox or press the shortcut key B.
  • In the Tool Options dock, verify that the mode is set to Design.

3. Connect the First Pair of Endpoints

  • Click directly on one of the open terminal nodes of the first path component. The node will change color (usually turning hollow or highlighted), indicating it is active.
  • Click directly on an open terminal node of the second path component. GIMP will draw a new vector segment between the two nodes, merging the two independent components into one continuous line.

4. Close the Outline

To convert the open path into a fully closed outline:

  • Click on one of the remaining open endpoints at either end of the combined path.
  • Press and hold the Ctrl key (the cursor will display a small infinity/loop symbol next to it).
  • While holding Ctrl, click the opposite remaining open endpoint.

A final connecting line segment will generate between the two points, turning the independent components into a single, seamless, closed vector outline.

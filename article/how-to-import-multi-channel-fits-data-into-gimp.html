How to Import Multi-Channel FITS Data into GIMP

Opening multi-channel Flexible Image Transport System (FITS) files in GIMP requires extracting the individual monochromatic image extensions, stretching their dynamic range, and combining them into a full-color composite. This guide provides a straightforward process for loading multi-channel or multi-file FITS astronomical datasets into GIMP, mapping the data to standard color channels, and preparing the composite image for post-processing.

Step 1: Open the FITS Data as Layers

Astronomical FITS datasets typically arrive either as a single multi-extension file containing multiple data arrays (Header Data Units) or as separate single-channel files (such as Red, Green, Blue, or narrowband filters like H-alpha, OIII, and SII).

  1. Launch GIMP.
  2. If your data is in a single multi-extension FITS file:
    • Go to File > Open and select the FITS file.
    • In the FITS import dialog, ensure all desired image extensions are selected so that GIMP imports each data channel as an independent layer.
  3. If your data consists of separate FITS files for each channel:
    • Go to File > Open as Layers...
    • Select all relevant FITS files simultaneously and click Open.

Step 2: Set the Image Precision

FITS astronomical data often contains high-bit-depth information (16-bit integer or 32-bit floating point). To preserve maximum dynamic range during processing:

  1. Navigate to Image > Precision.
  2. Select 32-bit floating point (or 16-bit integer if working on lower-spec hardware).
  3. Choose Linear light to maintain scientific data linearity during initial adjustments.

Step 3: Perform Initial Histogram Stretching

Raw FITS images appear almost completely black because astronomical signal is concentrated in a tiny fraction of the dynamic range. Each channel layer must be stretched before compositing:

  1. Select a layer in the Layers panel.
  2. Go to Colors > Levels or Colors > Curves.
  3. Move the white point slider toward the data histogram peak, or apply an exponential/logarithmic curve lift to reveal faint details without clipping the bright core features.
  4. Repeat this step individually for each channel layer until the signal in each filter is clearly visible.

Step 4: Combine Channels into a Color Composite

To merge the monochromatic layers into a single color image, use GIMP’s channel composition tool:

  1. Go to Colors > Components > Compose...
  2. In the Compose dialog, set the Color model to RGB.
  3. Map each FITS layer to its corresponding color channel:
    • For standard broadband data, assign the Red, Green, and Blue filter layers to their respective Red, Green, and Blue dropdowns.
    • For narrowband data (such as the Hubble Palette/SHO), map SII to Red, H-alpha to Green, and OIII to Blue.
  4. Click OK. GIMP will generate a new RGB image document containing the combined color data.

Step 5: Balance and Fine-Tune the Result

  1. In the newly generated color image, navigate to Colors > Color Balance to adjust the background neutralization (removing unwanted color casts from the sky background).
  2. Use Colors > Curves to refine color contrast and separate overlapping emissions.
  3. Once satisfied with the composition, save your working file as an .xcf file or export it via File > Export As... to TIFF, PNG, or JPEG.

How to Copy a Layer Mask to Another Layer in GIMP

Copying a layer mask from one layer to another in GIMP is a quick process that allows you to reuse complex selections without recreating them from scratch. This guide explains the direct drag-and-drop method within the Layers dialog, along with a reliable selection-based alternative to duplicate a mask accurately across layers.

Method 1: The Direct Drag-and-Drop Method

The fastest way to duplicate a mask directly inside the Layers dialog is by dragging it.

  1. Open the Layers dialog by pressing Ctrl + L (or Cmd + L on macOS) if it is not already visible.
  2. Locate the source layer that contains the layer mask you want to copy. You will see two thumbnails: the layer content thumbnail on the left and the layer mask thumbnail on the right.
  3. Click and hold the layer mask thumbnail (the black-and-white icon).
  4. Drag the mask thumbnail and drop it directly onto the name or preview of the target layer in the Layers dialog.
  5. Release the mouse button. A duplicate of the layer mask will instantly appear next to the target layer.

Note: If the target layer already possesses a layer mask, delete or apply the existing mask before dropping a new one onto it.

Method 2: The "Mask to Selection" Method

If you prefer precision or need to edit the shape before applying it, you can transfer the mask using an active selection entirely through the Layers dialog context menu.

  1. In the Layers dialog, right-click the mask thumbnail on the source layer.
  2. Select Mask to Selection from the context menu. This creates a running selection outline (marching ants) based on the mask's white and gray values.
  3. Click on the target layer in the Layers dialog to make it active.
  4. Right-click the target layer and choose Add Layer Mask... (or click the mask icon at the bottom of the Layers dialog).
  5. In the dialog box that appears, select Selection under the "Initialize Layer Mask to:" options.
  6. Click Add. The selection will be converted into a new mask on the target layer.
  7. Press Ctrl + Shift + A (or Cmd + Shift + A on macOS) to deselect the active selection.

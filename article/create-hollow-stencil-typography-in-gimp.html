Create Hollow Stencil Typography in GIMP

Creating hollow, stencil-style typography in GIMP involves converting standard text into editable vector paths, cutting out bridge gaps to mimic physical stencils, and subtracting an inner offset to produce an outline effect. By leveraging GIMP’s path and selection conversion tools, you can perform precise Boolean subtractions that transform solid digital glyphs into industrial, hollow vector designs ready for graphic layouts or vinyl cutting.

Step 1: Generate the Base Text and Convert to Path

  1. Open GIMP and create a new project with your desired dimensions.
  2. Select the Text Tool (T) and choose a thick, heavy typeface such as Impact, Montserrat Black, or Arial Black. Heavy fonts provide sufficient surface area for bridge cuts and hollow outlines.
  3. Type your text onto the canvas and adjust the tracking and size as needed.
  4. Right-click the text layer in the Layers Dialog and select Text to Path. This generates a vector representation of your typography in the Paths Dialog. You can hide the original text layer.

Step 2: Create the Hollow Outline via Vector Subtraction

  1. Go to the Paths Dialog, right-click your text path, and select Path to Selection (Shift + V).
  2. Go to Select > Shrink from the top menu. Enter a pixel value corresponding to the desired thickness of your hollow borders (for example, 4 to 8 pixels) and click OK.
  3. Invert the logic to isolate the outline: Go to Select > To Path. This creates a new path representing the inner boundary.
  4. To extract the hollow shell, return to the original path in the Paths Dialog, right-click it, and choose Path to Selection.
  5. Right-click the shrunk inner path, and choose Subtract from Selection. You will now have a selection representing only the hollow outer borders of the letters.
  6. Convert this hollow selection back into a clean vector: Go to Select > To Path. Rename this path to "Hollow Text."

Step 3: Cut Stencil Bridges

Traditional stencils require "bridges"—breaks in enclosed letterforms (such as O, P, B, A, and D)—to hold inner counter-spaces in place.

  1. Ensure the "Hollow Text" path is active and visible. Right-click it and choose Path to Selection.
  2. Select the Rectangle Select Tool (R).
  3. In the Tool Options dock on the left, change the Mode to Subtract from the current selection (or hold down the Ctrl key).
  4. Draw narrow rectangles vertically or horizontally across the loops of enclosed letters (e.g., cutting through the top and bottom of the "O" or the stem of the "P"). Each drawn rectangle will immediately cut away that portion of the active selection.
  5. Once all necessary bridge gaps are subtracted, go to Select > To Path. Rename this path to "Final Stencil Path."

Step 4: Render the Stencil Typography

  1. Create a new transparent layer in the Layers Dialog and name it "Rendered Stencil."
  2. Go to the Paths Dialog, right-click "Final Stencil Path," and select Fill Path to fill the hollow stencil design with your active foreground color.
  3. Alternatively, select Path to Selection, then use the Bucket Fill Tool or apply gradients and textures within the active selection bounds.
  4. Deselect all areas by pressing Shift + Ctrl + A to inspect the clean, vector-defined hollow stencil result.

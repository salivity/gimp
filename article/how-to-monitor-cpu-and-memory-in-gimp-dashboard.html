How to Monitor CPU and Memory in GIMP Dashboard

GIMP includes a built-in Dashboard dockable dialog designed to track real-time resource consumption, including CPU utilization, memory cache, and swap space. This guide provides a straightforward walkthrough on how to open, configure, and customize the Dashboard dialog to monitor your system's hardware performance while working on demanding image editing tasks.

Step 1: Open the Dashboard Dialog

  1. Launch GIMP.
  2. Navigate to the top menu and select Windows.
  3. Hover over Dockable Dialogs.
  4. Click on Dashboard from the submenu.

The Dashboard panel will appear on your workspace. You can drag its tab to dock it alongside your other panels (such as Layers or Tool Options) for continuous visibility.

Step 2: Select CPU and Memory Metrics

By default, the Dashboard may display several hardware meters. You can configure it to show only the metrics you need:

  1. Click the small Configure this tab icon (the small arrow in the top-right corner of the Dashboard dock).
  2. Navigate to the Dashboard Menu.
  3. Under the available groups, toggle the metrics you want to monitor:
    • CPU: Displays overall CPU usage and the activity of worker threads handling GEGL operations.
    • Memory: Tracks physical RAM usage allocated by GIMP.
    • Cache: Shows the amount of cache currently holding tile and image data.
    • Swap: Displays how much data is currently being written to or read from the disk cache when RAM limits are exceeded.

Step 3: Adjust the Update Rate and History Duration

To control how frequently the data refreshes and how much historical data is shown:

  1. Open the Dashboard tab menu (the configure arrow).
  2. Go to Dashboard Menu > Update Rate to select how frequently performance data is polled (e.g., 0.25s, 0.5s, or 1s). Lower values provide smoother graphs but use slightly more background processing.
  3. Go to Dashboard Menu > History Duration to set the time window displayed across the horizontal axis of the graphs (e.g., 15 seconds, 1 minute, or 5 minutes).

Step 4: Configure Performance Limits (Optional)

If the Dashboard indicates that memory or CPU thresholds are being hit frequently, you can adjust GIMP's internal allocation settings:

  1. Go to Edit > Preferences.
  2. Select the System Resources (or Resource Consumption) tab from the left sidebar.
  3. Adjust the Tile cache limit to allocate more or less RAM to GIMP before it resorts to disk swapping.
  4. Modify the Number of threads to use to optimize multi-core CPU usage for image processing operations.
  5. Click OK to apply the changes.

How to Create Procedural Noise Brushes in GIMP

Custom procedural brush tips allow digital artists to paint rich textures, foliage, organic surfaces, and grit with dynamic randomness. This guide explains how to generate a custom brush tip in GIMP by rendering grayscale noise maps, shaping them with radial masks, and exporting them as functional brush assets (.gbr) for your painting workflow.

1. Create a Square Canvas

  1. Open GIMP and create a new image (File > New).
  2. Set the dimensions to a square size, such as 512 × 512 px or 1024 × 1024 px. Higher resolutions allow for crisp scaling down, though extremely large sizes can impact brush responsiveness.
  3. Under Advanced Options, ensure Color space is set to Grayscale and Fill with is set to White.

2. Generate the Procedural Noise Map

GIMP includes built-in procedural render engines to generate seamless grayscale noise patterns:

  1. Navigate to Filters > Render > Noise > Solid Noise (or Perlin Noise / Simplex Noise depending on your GIMP version).
  2. Check the Turbulent option if you want sharp, chaotic variations ideal for rough textures, or leave it unchecked for smooth, smoky variations.
  3. Adjust the X Size and Y Size sliders to control the frequency and scale of the noise features.
  4. Increase the Detail slider to add micro-grit to the procedural pattern.
  5. Click OK to apply the noise to your layer.

3. Adjust Tonal Range and Contrast

To ensure your brush registers distinct light and dark areas:

  1. Open Colors > Levels or Colors > Curves.
  2. Push the black point inward to create deep, solid values, and pull the white point inward to eliminate muddy grays.
  3. Note that in GIMP grayscale brushes, black represents full opacity (paint), gray represents semi-transparency, and white represents full transparency.
  4. If your noise has dark values where you want transparent areas, invert the colors using Colors > Invert.

4. Create Edge Falloff with a Mask

A raw noise square creates harsh edges when stamped. You need to constrain the noise into a natural brush silhouette:

  1. Add an Alpha Channel by right-clicking the layer in the Layers panel and choosing Add Alpha Channel (if not already enabled).
  2. Right-click the layer and select Add Layer Mask, choosing White (full opacity).
  3. Select the Gradient Tool (G). Set the gradient to FG to BG (Black to White) and the shape to Radial.
  4. Drag the gradient from the center of the canvas toward the edges on the layer mask. This ensures the procedural noise gently fades to transparency along the perimeter.
  5. Right-click the layer mask and choose Apply Layer Mask.

5. Export as a GIMP Brush (.gbr)

  1. Go to File > Export As....
  2. Name your file with the extension .gbr (for example, procedural_noise_tip.gbr).
  3. Set the save destination to your GIMP brushes directory:
    • Windows: C:\Users\[Username]\AppData\Roaming\GIMP\2.10\brushes
    • Linux: ~/.config/GIMP/2.10/brushes/
    • macOS: ~/Library/Application Support/GIMP/2.10/brushes/
  4. Click Export. In the export prompt:
    • Set the Description (this is the name that appears in the GIMP UI).
    • Set the Spacing percentage (a value between 10% and 25% provides a smooth continuous stroke, while higher values create distinct stamp effects).
  5. Click Export again to finalize the file.

6. Load and Test the Custom Brush

  1. Open the Brushes dialog panel (Windows > Dockable Dialogs > Brushes).
  2. Click the Refresh icon at the bottom right of the panel.
  3. Search for your brush by the description name set during export.
  4. Select the Paintbrush Tool (P), pick your custom tip, and test it on a blank canvas.
  5. For best results, pair this procedural tip with Paint Dynamics such as random angle jitter, size dynamics, and opacity fade to maximize natural variation.

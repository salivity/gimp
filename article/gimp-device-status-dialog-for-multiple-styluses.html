GIMP Device Status Dialog for Multiple Styluses

The Device Status dockable dialog in GIMP provides a real-time visual dashboard that displays the currently active input devices and their independently assigned tool properties. When working with multiple hardware styluses on a graphics tablet, this dialog allows artists to track, configure, and seamlessly switch between different physical pens without manually reconfiguring tool presets, colors, or brush dynamics each time a different stylus touches the tablet surface.

Dedicated Tool Memory per Stylus

GIMP treats each recognized input device—including the core pointer, mouse, and individual tablet styluses—as a distinct entity. High-end drawing tablets assign unique hardware IDs to different styluses, such as an art pen, an airbrush pen, or standard grip pens.

The primary purpose of the Device Status dialog is to reflect these individual assignments by showing:

  • Active Tool: The specific tool mapped to the stylus (e.g., Paintbrush, Ink Tool, or Eraser).
  • Foreground and Background Colors: Unique color selections retained specifically for that stylus.
  • Brush and Size: The selected brush tip, aspect ratio, and size linked to the pen.
  • Pattern, Gradient, and Dynamics: Tablet-specific pressure and tilt curves associated with that physical device.

Preventing Workflow Disruption

Without the Device Status dialog, switching between multiple physical styluses can lead to confusion, as changes made with one stylus might not visibly update the primary Toolbox until that device touches the active canvas.

The dialog eliminates guesswork by providing an immediate readout of what each stylus is configured to do the moment it enters the tablet's proximity. For example, an illustrator can dedicate one physical pen entirely to linework with a fine inking brush and black ink, and a secondary pen to soft blending with low-opacity watercolor dynamics. The Device Status window ensures the user can confirm these mappings at a glance, preventing accidental marks with the wrong settings.

Visualizing Dual-Ended Styluses

Most standard tablet pens feature both a drawing tip and an eraser end. GIMP registers these two ends as separate input devices. The Device Status dialog allows creators to easily verify that the physical eraser tip is correctly assigned to the Erase tool rather than a standard brush, and that its size and opacity properties are properly balanced relative to the drawing tip.

Accessing the Dialog

To open this panel in GIMP, navigate to Windows > Dockable Dialogs > Device Status. Once opened, it can be docked into any existing panel alongside the Tool Options or Layers dialog for constant visibility while drawing.

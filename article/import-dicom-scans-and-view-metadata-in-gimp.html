Import DICOM Scans and View Metadata in GIMP

This guide explains how to import DICOM (Digital Imaging and Communications in Medicine) files into the GNU Image Manipulation Program (GIMP) and inspect embedded slice metadata directly within the software. By utilizing GIMP’s built-in file handlers, users can view high-bit-depth medical imaging slices, manage multi-slice datasets as layers, and extract vital diagnostic tags without requiring proprietary PACS viewers.

Importing DICOM Files into GIMP

GIMP features native support for single-frame DICOM files (.dcm extension) through its integrated file-loading plug-in.

  1. Open a Single Slice:

    • Launch GIMP.
    • Go to File > Open.
    • Locate your DICOM file (.dcm or extensionless DICOM files) and click Open.
    • GIMP automatically reads the grayscale pixel data and opens it in an image window.

  2. Open a Series as Layers:

    • If working with an anatomical volume or a sequence of continuous slices:
    • Go to File > Open as Layers.
    • Select all relevant .dcm files in the directory and click Open.
    • Each slice loads as an individual layer in chronological or alphabetical order, allowing you to cycle through the depth of the scan using the Layers dialog.

Handling Dynamic Range and Bit Depth

Medical scans commonly use 12-bit or 16-bit integer formats. GIMP handles high bit-depth precision natively:

  • Go to Image > Precision to verify that the image is set to 16-bit integer or higher, preserving radiological density information.
  • If the scan appears pitch-black or washed out due to narrow windowing, adjust the visualization by navigating to Colors > Levels or Colors > Curves to match the desired Window Width (WW) and Window Level (WL) values.

Inspecting Slice Metadata

DICOM files store essential acquisition and patient data within a standardized header prepended to the raw image data. To read these tags in GIMP:

  1. Access the Metadata Viewer:
    • Navigate to the top menu and select Image > Metadata > View Metadata.
  2. Review DICOM Header Tags:
    • The Metadata Viewer displays embedded information categorized across different tabs (such as Exif, XMP, or general tags depending on how the DICOM parser maps the elements).
    • Key metadata fields typically include:
      • Modality: Identifies the imaging technique (e.g., CT, MR, CR, US).
      • Patient Data: Patient name, ID, and acquisition date (if not anonymized).
      • Scan Parameters: Slice thickness, pixel spacing, KVP, and exposure time.
      • Window Center/Width: Original display settings recommended by the scanner.
  3. Alternative Method via Image Properties:
    • Go to Image > Image Properties.
    • Switch to the Comment or Properties tab to see raw header notes or embedded text generated during the import process.

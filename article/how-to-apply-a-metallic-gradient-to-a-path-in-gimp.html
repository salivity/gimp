How to Apply a Metallic Gradient to a Path in GIMP

Applying a metallic gradient to an active path outline in GIMP allows you to create realistic gold, chrome, or silver borders and contours for text, logos, and illustrations. This process involves converting the path into a defined stroke selection, selecting a built-in or custom metallic gradient preset, and rendering the gradient across the active selection on a dedicated layer.

Step 1: Create a Dedicated Layer

  1. Open the Layers panel (Ctrl + L).
  2. Click the Create a new layer button at the bottom of the panel.
  3. Name the layer (e.g., "Metallic Outline"), set Fill with to Transparency, and click OK. Keeping the outline on a separate layer preserves the rest of your artwork.

Step 2: Convert the Active Path to an Outline Selection

  1. Open the Paths panel (Windows > Dockable Dialogs > Paths).
  2. Right-click your active path and select Path to Selection (or press Shift + V).
  3. Go to the top menu and select Select > Border....
  4. In the dialog box, enter your desired outline width in pixels (e.g., 4 to 10 px depending on canvas resolution).
  5. Choose Hard or Smooth edge style based on your preference and click OK. The selection will transform from a solid interior to a hollow border contour.

Step 3: Configure the Metallic Gradient

  1. Select the Gradient Tool from the Toolbox or press G.
  2. In the Tool Options panel on the left, click the gradient preview icon to open the gradient selector.
  3. Choose a metallic preset from the list, such as Gold, Crown molding, Brushed Aluminium, or Flare Glow.
  4. Set the Shape option to Linear (recommended for a consistent directional light source) or Radial depending on the desired reflection style.

Step 4: Apply the Gradient Across the Outline

  1. Click and hold inside the image canvas on one side of your outlined path.
  2. Drag the cursor across the entire selection in the direction you want the metallic reflection to run (typically diagonally from top-left to bottom-right to simulate overhead light).
  3. Release the mouse button to preview the gradient. Adjust the interactive endpoints or color stops directly on the canvas to refine the highlight and shadow distribution.
  4. Press Enter to commit the gradient fill.

Step 5: Clean Up the Selection

  1. Go to the top menu and select Select > None (or press Ctrl + Shift + A) to remove the selection boundary.
  2. The active path outline will now be filled with a smooth, reflective metallic finish.

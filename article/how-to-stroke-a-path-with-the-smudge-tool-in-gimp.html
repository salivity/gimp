How to Stroke a Path with the Smudge Tool in GIMP

GIMP allows artists to automate manual brush strokes along precise vector paths, including using the Smudge tool to blend pixels and generate fluid, dynamic motion trails. This guide explains the exact method for configuring your brush settings, drawing a vector guide, and using the "Stroke Path" function to generate seamless directional smudges along any custom curve.

Step 1: Prepare Your Artwork Layer

Because the Smudge tool distorts and drags existing color data rather than applying new pigment, you must apply the effect to a layer containing pixels.

  1. Select the layer containing the graphic, subject, or color spot you want to stretch into a motion trail.
  2. If you want to preserve your original layer, duplicate it by pressing Shift + Ctrl + D (or Shift + Cmd + D on macOS) and work on the duplicate.

Step 2: Draw the Vector Path

The motion trail will follow the exact trajectory of a vector line.

  1. Select the Paths Tool from the Toolbox or press the shortcut key B.
  2. Click on the canvas to place anchor points along the direction you want the motion trail to flow, starting directly on the pixels you wish to smudge.
  3. Click and drag the handles between nodes to create smooth curves that match the intended movement.

Step 3: Configure the Smudge Tool Settings

The Stroke Path command inherits whatever settings are currently active on the chosen paint tool.

  1. Select the Smudge Tool from the Toolbox (keyboard shortcut S).
  2. In the Tool Options panel, choose a brush tip. A soft, round brush creates smooth, vapor-like trails, while a textured brush creates speed-line effects.
  3. Set the Size to dictate the thickness of the motion streak.
  4. Adjust the Rate slider. A higher rate (between 60% and 90%) pulls pixels farther along the path, while a lower rate creates subtle, short-distance blending.
  5. In the Dynamics section, optionally select Fade Tapering or Pressure Opacity if you want the motion trail to thin out or fade toward the end of the path.

Step 4: Stroke the Path

Once your tool settings are ready, apply the stroke along the vector line.

  1. Open the Paths Dialog dock (accessible via Windows > Dockable Dialogs > Paths if not visible).
  2. Ensure your active path is selected in the list.
  3. Go to the top menu and select Edit > Stroke Path... (alternatively, click the Paint along the path icon at the bottom of the Paths Dialog).
  4. In the dialog box that appears, select the Stroke with a paint tool radio button.
  5. From the drop-down menu, select Smudge.
  6. Check Emulate brush dynamics if you configured your brush to fade or taper along the stroke.
  7. Click Stroke.

GIMP will instantly pull the color data along the vector curve according to your Smudge settings, producing a precise and uniform motion trail. If the effect needs to be longer or more pronounced, you can repeat the stroke by pressing Ctrl + Z to undo, increasing the Smudge Rate, and running the command again.

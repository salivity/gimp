Procedural Rusted Metal Texture in GIMP

Creating realistic rusted metal sheet textures in GIMP relies on combining procedural noise filters, layer masks, and bump mapping rather than hand-painting. By generating controlled procedural masks using Solid Noise and Curves, you can naturally separate oxidized rust patches from the bare metal underneath while adding realistic depth, pitting, and edge wear.

Step 1: Create the Base Metal Layer

  1. Open GIMP and create a new image (e.g., 2048×2048 pixels) with a medium-gray background (#7A7A7A).
  2. Go to Filters > Noise > RGB Noise and add a subtle amount of grain to avoid flat surfaces.
  3. For brushed metal, apply Filters > Blur > Linear Motion Blur horizontally with a length of 15–25 pixels.
  4. Duplicate this layer and set the duplicate's blend mode to Overlay at 30% opacity to enhance surface contrast.

Step 2: Generate the Rust Layer

  1. Create a new layer above the base metal and name it Rust Base.
  2. Fill the layer with a deep rust color (#4A2311).
  3. Go to Filters > Render > Noise > Solid Noise. Check Turbulent, set the detail level to 5, and adjust the X/Y size to around 4.0 to create an uneven organic base.
  4. Create a layer above it named Rust Highlights, fill it with an orange-brown shade (#A04416), and render Filters > Render > Noise > Plasma.
  5. Set the Rust Highlights blend mode to Grain Merge or Overlay at 60% opacity and merge it down into the Rust Base layer.

Step 3: Create the Procedural Mask

  1. Add a Layer Mask to the Rust Base layer initialized to White (full opacity).
  2. Ensure the mask is selected (indicated by the white outline around its thumbnail in the Layers panel).
  3. Go to Filters > Render > Noise > Solid Noise. Check Turbulent, maximize detail to 15, and set scales high enough to produce broad contrasting patches.
  4. Press Ctrl + L to open Levels (or go to Colors > Levels) on the mask.
  5. Push the black and white input sliders toward the center to dramatically increase contrast. This isolates the noise into defined, irregular islands where the rust cuts off sharply against the metal.

Step 4: Add Rust Edge Peeling and Depth

  1. Select the Layer Mask and duplicate the mask channel by going to Colors > Invert on a temporary copy or applying Filters > Edge-Detect > Edge on the mask to capture the borders.
  2. With the Rust Base layer selected, navigate to Filters > Map > Bump Map.
  3. Set the Aux Input (bump map source) to the layer mask itself.
  4. Increase the depth slightly (around 2 to 4) and set the elevation to 45. This casts micro-shadows along the borders where the rust flakes off the bare metal.

Step 5: Final Texture Pitting and Color Pass

  1. Add a new transparent layer on top named Pitting and set its blend mode to Multiply.
  2. Render Filters > Render > Noise > Simplex Noise at a very small scale.
  3. Apply Colors > Threshold to isolate only small black dots, creating corrosion pits across both metal and rust. Lower layer opacity to 25%.
  4. Create a top New from Visible layer and use Colors > Color Temperature or Curves to unify the overall contrast and lighting of the metal sheet.

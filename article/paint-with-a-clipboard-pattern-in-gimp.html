Paint with a Clipboard Pattern in GIMP

This guide explains how to use GIMP's dynamic clipboard feature to paint with any copied image as an active pattern using standard painting tools. By utilizing GIMP’s automatic clipboard-to-pattern assignment, you can instantly turn any copied selection into a usable pattern without saving custom files to your hard drive.

The Clipboard Pattern Method

Whenever you copy pixels in GIMP, the application automatically places that data into the very first slot of the Patterns dialog under the name Clipboard Image. You can access and paint with this dynamic pattern across multiple standard tools.

Method 1: Using the Clone Tool

The most direct way to paint freehand using a pattern is via the Clone Tool.

  1. Select and copy the area you want to use as a pattern by pressing Ctrl + C (or Cmd + C on macOS).
  2. Select the Clone Tool (C) from the Toolbox.
  3. In the Tool Options dockable, locate the Source setting and switch it from Image to Pattern.
  4. Click the pattern preview box to open the pattern list, and select the first item, labeled Clipboard Image.
  5. Adjust brush size, opacity, and spacing in Tool Options, then click and drag on your canvas to paint with the active pattern.

Method 2: Using the Bucket Fill Tool

If you need to fill larger continuous areas or selections with the copied pattern:

  1. Copy your desired pattern source to the clipboard (Ctrl + C).
  2. Select the Bucket Fill Tool (Shift + B).
  3. In the Tool Options dockable, set the Fill Type to Pattern Fill.
  4. Click the pattern thumbnail and select the Clipboard Image pattern.
  5. Click on the target area or active selection to apply the pattern fill.

Method 3: Using the Paintbrush with a Clipboard Brush

If your goal is to stamp or brush the exact image data with full color using standard brush tools (Paintbrush, Pencil, Airbrush):

  1. Copy your target artwork to the clipboard (Ctrl + C).
  2. Select the Paintbrush Tool (P).
  3. In Tool Options, click on the Brush thumbnail.
  4. Select the very first brush in the list, named Clipboard Image. Unlike traditional grayscale brushes, this generates a full-color brush directly from your clipboard contents, allowing you to paint directly on the canvas.

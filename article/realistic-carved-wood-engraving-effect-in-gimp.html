Realistic Carved Wood Engraving Effect in GIMP

Creating a realistic carved-wood engraving effect in GIMP involves combining a high-resolution wood texture with vector graphics or text, then using layer blending, blur filters, and bump mapping to simulate depth, natural bevels, and light interaction. This guide provides a straightforward step-by-step procedure to transform flat 2D designs into convincing, recessed wood-carved artwork.

1. Set Up the Project and Base Texture

  1. Open GIMP and go to File > New to create a canvas of your preferred dimensions (e.g., 1920x1080 pixels).
  2. Go to File > Open as Layers and import a high-resolution wood grain texture.
  3. Rename this layer to "Wood Base".

2. Add and Format Your Graphic or Text

  1. Select the Text Tool to add your text, or go to File > Open as Layers to import a black-and-white silhouette or logo.
  2. Use a bold, thick font or graphic for the best engraving visibility.
  3. Position and scale your design using the Move and Scale tools.
  4. If using text, right-click the text layer in the Layers panel and select Discard Text Information to convert it into a standard raster layer.
  5. Rename this layer to "Engraving".

3. Create the Carved Cavity

  1. Right-click the "Engraving" layer and choose Alpha to Selection.
  2. Select the "Wood Base" layer and press Ctrl + C then Ctrl + V to copy the underlying wood texture.
  3. Click the New Layer button in the Layers panel to anchor the selection into its own layer.
  4. Rename this new layer to "Carved Fill" and place it directly above the "Wood Base" layer.
  5. Go to Colors > Curves or Colors > Levels on the "Carved Fill" layer, and pull the midpoint down to significantly darken this layer, simulating the deeper, shadowed interior of a wood cut.

4. Add Depth Using Bump Mapping

  1. Hide all layers except the original "Engraving" layer (the black text/graphic).
  2. Create a new white layer beneath the "Engraving" layer, right-click the "Engraving" layer, and select Merge Down. This creates a black-and-white mask.
  3. Go to Filters > Blur > Gaussian Blur and apply a subtle blur (around 3 to 6 pixels, depending on canvas size) to soften the edges.
  4. Rename this layer to "Height Map" and hide its visibility.
  5. Select the "Carved Fill" layer and make it visible.
  6. Go to Filters > Map > Bump Map.
  7. Set the Aux Input to your "Height Map" layer.
  8. Adjust the Depth and Elevation sliders until the edges show a distinct, chiseled indentation. Set the light direction to match the natural light of your wood texture. Click OK.

5. Create Highlights and Inner Shadows

  1. Select the "Engraving" selection again by right-clicking the "Carved Fill" layer and selecting Alpha to Selection.
  2. Create a new transparent layer on top and name it "Inner Shadow".
  3. With the selection active, go to Select > Invert.
  4. Go to Filters > Light and Shadow > Drop Shadow.
  5. Set the shadow color to black, reduce the opacity to roughly 60–75%, and set the offset slightly downward to simulate overhead lighting casting a shadow inside the top of the cut.
  6. Click OK, then go to Select > None.

6. Blend Natural Grain and Final Details

  1. Duplicate the "Wood Base" layer and move it to the very top of the layer stack.
  2. Change the layer mode of this top layer to Overlay or Soft Light and lower the opacity to roughly 30–50%. This forces the original wood grain texture to show through the shadows and highlights of the carved areas.
  3. To add a polished rim highlight, create a new transparent layer below "Inner Shadow", stroke the selection with a 1-pixel white line, apply a light Gaussian blur (1–2 pixels), set the layer mode to Overlay, and reduce opacity to 40% to mimic the unpolished bare wood edge catching the light.

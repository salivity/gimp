GIMP Quick Mask Mode Keyboard Shortcut

This guide explains how to instantly toggle Quick Mask mode on and off in GIMP using the default keyboard shortcut. It covers how the shortcut works, how to use the feature to refine image selections, alternative methods to activate it, and how to change the shortcut if needed.

The Shortcut: Shift + Q

The default keyboard shortcut to toggle Quick Mask mode on and off in GIMP is Shift + Q.

Pressing this key combination instantly activates Quick Mask mode over your active image layer. Pressing Shift + Q a second time disables the mode and converts your mask adjustments back into an active selection (indicated by "marching ants").

How Quick Mask Works

Quick Mask allows you to paint selections using standard brush tools instead of relying solely on vector or marquee selection tools.

  1. Press Shift + Q to activate Quick Mask. By default, a translucent red overlay covers the unselected parts of your image.
  2. Select the Paintbrush Tool (shortcut: P).
  3. Paint with White to add to the selection (remove the red mask).
  4. Paint with Black to subtract from the selection (add red mask).
  5. Paint with Gray or adjust brush opacity to create soft, feathered edges or semi-transparent selections.
  6. Press Shift + Q again to exit Quick Mask mode. Your painted area will immediately turn into an active selection boundary.

Alternative Ways to Toggle Quick Mask

If you do not want to use the keyboard shortcut, you can toggle Quick Mask using the interface:

  • Lower-Left Button: Click the small dashed square icon located at the bottom-left corner of the image canvas window (just below the vertical ruler).
  • Menu Bar: Navigate to Select > Toggle Quick Mask.

Customizing the Shortcut

If Shift + Q does not work or conflicts with another custom setup, you can customize it:

  1. Go to Edit > Keyboard Shortcuts.
  2. Type Quick Mask into the search bar.
  3. Locate Toggle Quick Mask under the Select category.
  4. Click the shortcut field and press your preferred new key combination.
  5. Click Save to apply the changes.

Create Realistic Glass Condensation in GIMP

Creating realistic liquid droplet condensation on glass in GIMP involves generating randomized moisture shapes, smoothing them into organic droplet contours, and applying multi-layered light refraction, highlight, and shadow effects. This guide walks you through setting up a realistic backdrop, generating both macro-droplets and micro-mist using procedural noise and threshold adjustments, and rendering three-dimensional depth so the condensation appears to naturally interact with light and background imagery.

Step 1: Prepare the Background and Glass Base

  1. Open GIMP and load your background image.
  2. Duplicate the background layer and name it Blurred Background.
  3. Apply a blur to simulate the depth of field through wet glass by going to Filters > Blur > Gaussian Blur. Set the size to around 15–20 px and click OK.
  4. Create a new transparent layer on top and name it Glass Tint. Fill it with a very dark blue or neutral gray at 10% to 15% opacity to establish the pane's surface.

Step 2: Generate the Droplet Map

  1. Create a new transparent layer named Droplets Base.
  2. Fill the layer with white.
  3. Go to Filters > Render > Noise > Solid Noise. Check Turbulent, maximize the Detail slider, and set the X and Y Size to approximately 4.0–6.0 to create an uneven texture. Click OK.
  4. Go to Colors > Threshold. Move the black-point slider far to the right until only small, scattered black islands remain against a white background. These shapes will become your droplets.
  5. Smooth the jagged edges by applying Filters > Blur > Gaussian Blur (around 3–5 px), followed immediately by Colors > Levels or Threshold again to snap the blurred edges into smooth, rounded droplet profiles.
  6. Go to Colors > Color to Alpha and convert the white area to transparency, leaving only the dark droplet shapes.

Step 3: Add Volume and Three-Dimensional Depth

  1. Invert the droplet colors so they are white by going to Colors > Invert.
  2. Change the Droplets Base layer mode to Overlay or Soft Light.
  3. Duplicate this layer and name it Droplet Highlights.
  4. Go to Filters > Distorts > Emboss (or use the GEGL Bump Map filter via Filters > Map > Bump Map). Set the type to Emboss, set the elevation to 45 degrees, and adjust the depth to create a subtle light rim on one side and a dark shadow rim on the opposite side.
  5. Set the Droplet Highlights layer mode to Screen or Dodge to isolate the bright reflection points.

Step 4: Create Realistic Refraction

  1. Make a selection of your droplets by right-clicking the Droplets Base layer and selecting Alpha to Selection.
  2. Select the Blurred Background layer.
  3. Go to Filters > Distorts > Lens Distortion or Filters > Distorts > Ripple to slightly shift the pixels inside the selection. This simulates the way light bends as it passes through curved water droplets.
  4. Deselect everything by pressing Ctrl + Shift + A.

Step 5: Add Fine Condensation Mist

  1. Create a new transparent layer above all previous layers named Fine Mist.
  2. Go to Filters > Render > Noise > Simplex Noise or RGB Noise to create a very dense, fine grain.
  3. Lower the Fine Mist layer opacity to between 15% and 25%.
  4. Set the layer mode to Screen.
  5. Use a soft, low-opacity Eraser Tool or a layer mask with a soft brush to paint away streaks or patches, simulating random areas where larger droplets have wiped through the condensation.

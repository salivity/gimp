Use GIMP Clipboard Brush for Pattern Stamping

This guide explains how to quickly configure and use GIMP’s dynamic clipboard brush feature to turn any copied selection into an immediate, reusable pattern stamp. By leveraging the automated clipboard brush alongside proper brush dynamic settings, you can effortlessly stamp custom textures, repeating motifs, or graphics without manually exporting and saving dedicated brush files to your system.

Step 1: Copy the Source Pattern to Your Clipboard

  1. Open the image containing the graphic or texture you want to stamp.
  2. Use the Rectangle Select Tool (R) or Ellipse Select Tool (E) to outline the desired pattern.
  3. Press Ctrl + C (Windows/Linux) or Cmd + C (macOS) to copy the selection to your clipboard. GIMP automatically generates a temporary brush from this copied data.

Step 2: Select the Clipboard Brush

  1. Select the Paintbrush Tool (P) from the Toolbox.
  2. Open the Brushes Dialog dockable dialog (Shift + Ctrl + B or navigate to Windows > Dockable Dialogs > Brushes).
  3. Click on the very first icon in the brush grid, which is labeled Clipboard Image. This dynamic brush always reflects your current clipboard contents.

Step 3: Configure Tool Options for Stamping

To ensure the brush behaves like a single, crisp stamp rather than a blended stroke, adjust the following settings in the Tool Options panel:

  • Size: Scale the brush up or down to match your desired stamp dimension.
  • Aspect Ratio and Angle: Adjust these if you need to rotate or distort the stamp orientation.
  • Spacing: Increase the spacing value (e.g., to 100% or higher) if you plan on clicking and dragging, preventing the pattern from overlapping into a solid line.
  • Dynamics: Set Dynamics to Dynamics Off. This ensures the stamp remains at 100% opacity, native size, and full color fidelity with a single click.

Step 4: Apply the Stamp to the Canvas

  1. Create a new transparent layer via Layer > New Layer to keep your stamped elements non-destructive.
  2. Hover the cursor over the target location on the canvas.
  3. Left-click once to apply a single, clean pattern stamp.

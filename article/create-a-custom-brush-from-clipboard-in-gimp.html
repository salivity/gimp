Create a Custom Brush from Clipboard in GIMP

This guide explains how to quickly generate a custom brush tip in GIMP directly from an active selection or copied graphic on your clipboard. GIMP features a built-in dynamic clipboard function that immediately converts copied pixels into a usable brush tip without requiring file exports, as well as a direct command to save that clipboard data as a permanent brush preset for future use.

Using the Temporary Clipboard Brush

  1. Make a Selection: Open your image and use any selection tool—such as the Rectangle Select, Ellipse Select, or Free Select tool—to outline the shape you want to use as a brush tip.
  2. Copy the Pixels: Press Ctrl + C (Windows/Linux) or Cmd + C (macOS), or navigate to Edit > Copy. If your artwork spans multiple layers, go to Edit > Copy Visible (Ctrl + Shift + C) instead.
  3. Activate the Paintbrush Tool: Select the Paintbrush tool from the Toolbox or press the P key.
  4. Select the Clipboard Brush: Open the Brushes dockable dialog (Windows > Dockable Dialogs > Brushes). The very first brush displayed in the grid is the dynamic Clipboard Image brush. Click it to set your copied selection as the active brush tip.

The brush is now ready to use. Any adjustments to size, aspect ratio, angle, and opacity can be made directly in the Tool Options dock. Note that this brush tip will update automatically whenever you copy a new selection.

Saving the Clipboard Selection as a Permanent Brush

To preserve your custom brush so it does not disappear when you copy new data or close GIMP, save it directly from the clipboard:

  1. Copy your desired selection to the clipboard using Edit > Copy or Edit > Copy Visible.
  2. Go to the top menu and click Edit > Paste as > New Brush....
  3. In the pop-up dialog, enter a Brush name to identify it in your library.
  4. Set the default Spacing percentage (a spacing between 10% and 25% provides a smooth, continuous stroke for most shapes).
  5. Click OK.

GIMP will save the brush file into your user profile's brushes folder and instantly display it inside your permanent Brushes dialog list.

How to Create a Feathered Border in GIMP

Creating a soft, feathered frame around an image in GIMP is a quick way to draw focus to your subject and give your photos a polished, professional look. This guide walks you through setting up a dedicated frame layer, using the Border selection tool to establish the frame's width, applying feathering to soften the edges, and filling the boundary with your desired color.

Step 1: Prepare a Dedicated Frame Layer

Open your image in GIMP. Before making any selections, create a new layer to hold your border so your original image remains untouched:

  1. Go to the menu and click Layer > New Layer... (or click the New Layer icon at the bottom of the Layers dock).
  2. Set the Fill with option to Transparency.
  3. Name the layer "Frame" and click OK. Ensure this new layer is selected.

Step 2: Select the Canvas Area

Define the base boundary that the border will follow:

  1. Navigate to Select > All (or press Ctrl + A on Windows/Linux, Cmd + A on Mac) to select the entire image canvas.
  2. Alternatively, use the Rectangle Select Tool (R) to draw a smaller box inside the canvas if you want the frame positioned further inward.

Step 3: Use the Border Selection Tool

Transform your solid rectangular selection into a hollow perimeter frame:

  1. Go to Select > Border... to open the Border Selection dialog.
  2. In the Border selection by field, enter the desired thickness of your frame in pixels (e.g., 20 to 50 px depending on image resolution).
  3. Set the Border style to Smooth or Hard.
  4. Check the box labeled Feather border directly inside this dialog if available, or leave it unchecked to control feathering precisely in the next step.
  5. Click OK. Your selection will change from a solid box into a ribbon-like boundary along the edges.

Step 4: Feather the Boundary

If you did not check the feather option in the previous step, or if you need a softer transition:

  1. Go to Select > Feather....
  2. Enter the radius in pixels for how gradual you want the fade to be (typically half the border width creates a balanced blur).
  3. Click OK.

Step 5: Fill the Border

With the feathered selection active and your "Frame" layer highlighted:

  1. Choose your desired border color by setting the Foreground Color in the toolbox (such as white or black).
  2. Go to Edit > Fill with FG Color (or press Ctrl + ,).
  3. Clear the active selection marquee by going to Select > None (or press Shift + Ctrl + A).

You now have a smoothly blended, feathered boundary frame that you can further customize by adjusting the "Frame" layer's opacity or blending mode in the Layers panel.

How to Stroke a Path with Airbrush in GIMP

Stroking an open Bezier path using the Airbrush tool in GIMP allows you to apply smooth, feathered paint strokes along a mathematically precise vector curve. This guide explains the exact procedure for configuring the Airbrush settings, drawing an open path with the Paths Tool, and rendering the final stroke onto your image layer.

Step 1: Prepare the Target Layer

  1. Open your project in GIMP.
  2. Go to the Layers panel on the right side of the screen.
  3. Click the Create a new layer button (or press Shift + Ctrl + N) so that the stroked path is rendered onto its own layer rather than directly onto your background artwork.
  4. Ensure this new layer is active and selected.

Step 2: Configure the Airbrush Tool

Before stroking a path, GIMP requires you to pre-configure the tool's settings, as it will apply whatever parameters are currently set.

  1. Select the Airbrush Tool from the Toolbox (keyboard shortcut: A).
  2. In the Tool Options panel, configure your desired settings:
    • Color: Choose your desired foreground color from the color swatch.
    • Brush: Select a soft-edged brush (such as 2. Hardness 050 or a standard round soft brush).
    • Size: Adjust the brush diameter to control the thickness of the line.
    • Rate and Flow: Increase or decrease these values to manage paint density and speed.
    • Dynamics: Choose a dynamic profile (such as Pressure Opacity or Dynamics Off) depending on whether you want thickness and opacity variation.

Step 3: Draw the Open Bezier Path

  1. Select the Paths Tool from the Toolbox (keyboard shortcut: B).
  2. Click on the canvas to place the initial anchor point.
  3. Click elsewhere on the canvas to place subsequent points, dragging your mouse cursor to extend direction handles and form curved Bezier segments.
  4. Leave the path open by simply not clicking on the starting anchor point.

Step 4: Stroke the Path with the Airbrush

  1. With the path still active, go to the top menu and select Edit > Stroke Path... (Alternatively, right-click the path in the Paths dockable dialog and choose Stroke Path...).
  2. In the Stroke Path dialog box, select the Stroke with a paint tool radio button.
  3. From the drop-down menu next to Paint tool:, select Airbrush.
  4. Check the Emulate brush dynamics box if you want GIMP to automatically simulate pressure variation along the path from start to finish. Leave it unchecked for a uniform application.
  5. Click the Stroke button.

Step 5: Finalize and Deselect

  1. Once the stroke renders onto your layer, select any other tool (such as the Rectangle Select Tool or Move Tool) to exit path editing.
  2. If the red vector path line is still visible, open the Paths tab (next to the Layers tab) and click the eye icon next to your path to hide it, revealing your finished airbrushed stroke.

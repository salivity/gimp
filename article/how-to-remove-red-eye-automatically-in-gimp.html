How to Remove Red-Eye Automatically in GIMP

This guide explains how to quickly and automatically eliminate red-eye artifacts from your photos using the built-in Red Eye Removal filter in GIMP. By making a simple selection and applying the filter, you can restore natural pupil color in portrait photos taken with direct flash without manually painting over the eyes.

Step 1: Open the Image in GIMP

Launch GIMP and open your target image by going to File > Open, selecting your image file, and clicking Open.

Step 2: Select the Red Eye Area

While the filter can run on an entire image, selecting only the eyes ensures the filter does not accidentally alter other red or warm tones in the photo.

  1. Zoom in on the subject's eyes using the Zoom Tool (or by holding Ctrl and scrolling the mouse wheel).
  2. Choose a selection tool from the toolbox, such as the Ellipse Select Tool (E) or the Free Select Tool (Lasso tool, F).
  3. Create a selection around the pupil or the entire eye containing the red artifact. To select both eyes at once, hold the Shift key while making the second selection.

Step 3: Apply the Red Eye Removal Filter

  1. Navigate to the top menu and select Filters > Enhance > Red Eye Removal...
  2. A dialog box will appear with a Threshold slider and a live preview.
  3. Adjust the Threshold slider:
    • A lower threshold makes the filter less sensitive, replacing only deep red tones.
    • A higher threshold expands the color range targeted for darkening.
    • Set the slider to a level where the red color is neutralized to a natural dark pupil without creating harsh borders.
  4. Click OK to apply the effect.

Step 4: Deselect and Save

  1. Clear the active selection by going to Select > None (or press Ctrl + Shift + A).
  2. Zoom out to view the entire portrait and verify that the correction looks natural.
  3. Save your project as an XCF file via File > Save, or export the final image to JPEG or PNG format via File > Export As....

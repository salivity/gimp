Create Custom Pixel Art Brushes in GIMP

This guide outlines the complete workflow for creating and configuring custom pixel-art brushes in GIMP to achieve sharp, non-anti-aliased lines. By designing an asset on a micro-canvas, exporting it in GIMP’s native brush format, and pairing it strictly with the Pencil tool, you eliminate unwanted semi-transparent edge pixels and guarantee crisp, single-pixel precision across your artwork.

Step 1: Create the Brush Canvas

  1. Open GIMP and create a new document via File > New.
  2. Set the canvas dimensions to match your desired brush size. For a standard single-pixel brush, set both Width and Height to 1 pixel. For custom dither or cluster shapes, use a small canvas such as 3x3 or 5x5 pixels.
  3. Expand Advanced Options in the dialogue and set Color Space to Grayscale.
  4. Set Fill with to Transparency, then click OK.

Step 2: Draw the Brush Tip

  1. Zoom in fully using the Magnifier or by pressing the + key until the individual pixels fill your view.
  2. Select the Pencil Tool (N). Do not use the Paintbrush tool, as the Paintbrush applies anti-aliasing by default.
  3. Set your foreground color to pure black (#000000). In GIMP brush files, black represents full opacity, white represents full transparency, and shades of gray represent semi-transparency.
  4. Click on the canvas to place your pixel or shape. Ensure there are no gray or feathering values present.

Step 3: Export the Brush to GIMP's Directory

  1. Go to File > Export As....
  2. Navigate to your GIMP user brush directory. You can confirm your exact path inside GIMP by checking Edit > Preferences > Folders > Brushes.
    • On Windows, this is typically: C:\Users\<Username>\AppData\Roaming\GIMP\2.10\brushes
    • On Linux: ~/.config/GIMP/2.10/brushes
    • On macOS: ~/Library/Application Support/GIMP/2.10/brushes
  3. Name the file with a .gbr extension (for example, pixel_1px.gbr) and click Export.
  4. An export dialog will appear. Enter a descriptive Description (this is the name that appears inside GIMP's interface) and set the Spacing to 100% for distinct stamp behavior, or between 1% and 10% for continuous, unbroken lines. Click Export.

Step 4: Load and Configure the Brush for Drawing

  1. Open the Brushes dockable dialog (Windows > Dockable Dialogs > Brushes).
  2. Click the Refresh Brushes button (the circular arrow icon at the bottom of the panel) to load your new brush without restarting GIMP.
  3. Locate and select your newly created brush from the list.
  4. Switch to the Pencil Tool (N).
  5. Open the Tool Options panel and apply the following settings:
    • Size: Set to the native size of your brush (e.g., 1.00).
    • Dynamics: Set to Dynamics Off to prevent pressure-sensitive opacity or scaling changes.
    • Smooth Stroke: Unchecked to eliminate lag and algorithmic line smoothing.
    • Jitter: Unchecked.

With these steps complete, drawing on any layer with the Pencil tool produces pure, hard-edged strokes with zero anti-aliasing artifacts.

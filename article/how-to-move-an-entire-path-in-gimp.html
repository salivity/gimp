How to Move an Entire Path in GIMP

Moving a complete Bezier path or an individual path component in GIMP without accidentally shifting its anchor nodes is a straightforward process once you select the correct tool mode. This guide outlines how to relocate an entire path or single component across the canvas using the Move Tool and the Paths Tool.

Method 1: Using the Move Tool (Recommended for Full Paths)

The Move Tool provides the quickest way to move all components of an active path simultaneously.

  1. Select the Move Tool from the Toolbox or press the shortcut key M.
  2. Go to the Tool Options dockable dialog (typically located below the Toolbox).
  3. Under the Move: section at the top, click the Path icon (represented by a red curve with nodes) instead of the default Layer icon.
  4. Ensure the target path is visible by opening the Paths Dialog (Windows > Dockable Dialogs > Paths) and clicking the eye icon next to the path name.
  5. Click directly on any stroke of the path on the canvas and drag it to the new position. Alternatively, use the keyboard arrow keys to nudge the path pixel by pixel.

Method 2: Using the Paths Tool (For Specific Components)

If your path contains multiple disconnected components and you only want to move one of them without affecting the others or altering node handles, use the Paths Tool.

  1. Select the Paths Tool from the Toolbox or press B.
  2. Look at the Tool Options panel.
  3. Under Edit Mode, select the Move radio button (by default, it is set to Design).
  4. Click anywhere on the specific path component you want to relocate and drag it across the canvas. Only the selected component will move; its shape, curvature, and individual nodes will remain intact.

Quick Shortcut: While working in Design mode with the Paths Tool, you can temporarily switch to Move mode by pressing and holding the Alt key (or Alt + Shift depending on your operating system and window manager settings) while dragging the component.

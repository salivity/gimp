Prevent GIMP Scanning Network Drives for Fonts

GIMP often suffers from excessively slow startup times when it attempts to index fonts located on mapped network drives, UNC paths, or redirected network user profiles. This article explains how to stop GIMP from scanning these network locations by adjusting font search paths in GIMP’s preferences, modifying the underlying Fontconfig configuration files, and utilizing startup flags to restore fast loading times.

1. Remove Network Paths from GIMP Font Preferences

The first step is to ensure that GIMP is not directly configured to search network locations for fonts.

  1. Open GIMP and navigate to Edit > Preferences (or GIMP > Preferences on macOS).
  2. In the left panel, scroll down and expand the Folders section.
  3. Select Fonts.
  4. Review the directory list on the right. If any mapped network drives (e.g., Z:\Fonts) or network UNC paths (e.g., \\server\share\fonts) appear in the list, select them and click the Delete (trash can) icon.
  5. Ensure only local paths, such as C:\Program Files\GIMP 2\share\gimp\2.0\fonts or local user directories, remain.
  6. Click OK and restart GIMP.

2. Modify Fontconfig to Exclude Network Locations

GIMP relies on the Fontconfig library to index fonts from the host operating system. If your user profile or standard system folders are redirected to a network location, Fontconfig will attempt to scan them on startup.

  1. Close GIMP completely.
  2. Locate your GIMP installation's Fontconfig directory.
    • On Windows, this is typically located at:
      C:\Program Files\GIMP 2\etc\fonts\
    • On Linux, user configurations are typically in:
      ~/.config/fontconfig/fonts.conf or /etc/fonts/fonts.conf
  3. Open the fonts.conf file (or local.conf if present) using a text editor with administrative privileges.
  4. Search for <dir> tags. These tags specify the directories Fontconfig scans for fonts.
  5. Identify any entries pointing to network locations, redirected user directories (such as WINDOWSFONTDIR resolving to a network location, or paths referencing AppData\Roaming on a network share).
  6. Remove the problematic <dir> entries or explicitly change them to point strictly to local directories (e.g., C:\Windows\Fonts).
  7. Save the file and restart GIMP.

3. Clear the Fontconfig Cache

If network paths were previously scanned, stale cache files can cause repeated hangs during initialization.

  1. Navigate to your local temporary or cache folder:
    • Windows: %LOCALAPPDATA%\fontconfig\cache or %USERPROFILE%\.cache\fontconfig
    • Linux: ~/.cache/fontconfig
  2. Delete all files inside this cache directory.
  3. Launch GIMP. It will rebuild the font cache once using only the local directories specified in your updated configuration.

4. Temporary Bypass: Disable Font Loading via Command Line

If you need to open GIMP immediately without scanning any fonts at all, launch the application using the --no-fonts command-line switch.

  • Windows: Open the Command Prompt or Run dialog (Win + R) and run:
    "C:\Program Files\GIMP 2\bin\gimp-2.10.exe" --no-fonts
  • Linux: Run gimp --no-fonts in the terminal.

This parameter instructs GIMP to skip the font enumeration step entirely, bypassing all network checks for that session.

How to Create Animated WebP Files in GIMP

Creating animated WebP files in GIMP is a simple process that allows you to produce lightweight, high-quality animations as modern alternatives to GIFs. This guide provides a direct walkthrough on how to arrange your frames using layers, preview your sequence, and export the final project as an animated WebP file using GIMP's built-in export settings.

1. Set Up Your Frames as Layers

In GIMP, each layer represents an individual frame of your animation.

  • Open GIMP and create a new project with your desired dimensions, or open an existing series of images as layers by selecting File > Open as Layers....
  • Organize your layers in the Layers panel. The bottom layer acts as the first frame of the animation, and the top layer acts as the last frame.
  • (Optional) Customize individual frame timings and transitions directly in layer names. Double-click a layer name and append the duration and disposal method, for example: Frame 1 (150ms) (replace) or Frame 2 (200ms) (combine).

2. Preview the Animation

Before exporting, ensure the timing and sequence run smoothly:

  • Navigate to Filters > Animation > Playback....
  • Use the playback controls in the pop-up window to play, pause, or step through your animation frames to verify the motion.

3. Export to WebP

Once your layers are finalized:

  • Go to File > Export As....
  • Name your file with the .webp extension (e.g., animation.webp) or select WebP image from the Select File Type (By Extension) menu at the bottom.
  • Click Export to open the WebP export dialog window.

4. Configure WebP Animation Settings

In the export configuration window, adjust the following settings:

  • Check the As animation box to enable multi-frame encoding.
  • Check Loop forever if you want the animation to repeat continuously.
  • Set the Default delay between frames (in milliseconds) for any layers that do not have custom durations defined in their names.
  • Choose your preferred frame disposal method under Frame disposal: select Use default, Combine, or Replace.
  • Adjust the Image quality slider according to your preferred balance between visual fidelity and file size (Lossless encoding is also available).
  • Click Export to generate your animated WebP file.

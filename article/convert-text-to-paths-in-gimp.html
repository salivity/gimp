Convert Text to Paths in GIMP

Converting live text into vector paths in GIMP allows you to manipulate letterforms as scalable shapes, customize typography, and export clean vector outlines for other software. This guide covers how to quickly transform any active text layer into an independent, scalable vector path using GIMP's built-in vector toolset.

Step 1: Create and Finalize Your Text

Before converting your text to a path, set your desired font, baseline, and general proportions.

  1. Select the Text Tool (keyboard shortcut T) from the toolbox.
  2. Click onto your canvas and type your text.
  3. Use the on-canvas formatting box or the Tool Options dock to choose your font family, style, and size.

Step 2: Convert the Text to a Path

GIMP makes the actual conversion process straightforward through the Layers panel or the main menu.

  1. Locate your text layer in the Layers panel on the right.
  2. Right-click the text layer and select Text to Path. Alternatively, go to the top menu and select Layer > Text to Path.

Once clicked, the original text layer remains unchanged, and GIMP generates a new vector path matching the exact outlines of your glyphs.

Step 3: Access and View the Vector Path

The newly created path is stored separately from your raster layers.

  1. Switch to the Paths tab (usually docked beside the Layers and Channels tabs; if not visible, open it via Windows > Dockable Dialogs > Paths).
  2. You will see a new item named after your text.
  3. Click the empty box to the left of the path preview thumbnail to toggle the eye icon on. This makes the vector outline visible on your canvas as a red line.

Step 4: Edit or Scale the Vector Path

Because the text is now a pure vector path, it can be transformed without any loss of quality.

  • To modify shapes: Select the Paths Tool (shortcut B) and click anywhere on the path outline to reveal the control nodes and handles. You can click and drag individual nodes to warp or customize the letter shapes.
  • To scale or transform: Select the Unified Transform Tool (shortcut Shift + T), set the tool's transform target to Path in the Tool Options panel, and resize or rotate the path freely.

Step 5: Render or Export the Path

A path itself does not automatically appear in your final exported image; it must be rendered or exported separately.

  • Fill or Stroke: In the Paths tab, right-click your path and select either Fill Path to color it in with your foreground color, or Stroke Path to trace the outline with a brush or solid line.
  • Export as SVG: Right-click the path in the Paths tab, select Export Path..., choose a destination, and save it as an .svg file to use in vector software such as Inkscape or Adobe Illustrator.

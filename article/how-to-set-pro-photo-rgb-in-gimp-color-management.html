How to Set ProPhoto RGB in GIMP Color Management

Configuring GIMP to use ProPhoto RGB as your default working space enables you to preserve maximum color data and dynamic range throughout your editing process. This guide provides a straightforward walkthrough on obtaining a suitable ProPhoto ICC profile, setting it as your default RGB profile within GIMP’s preferences, and configuring precision settings to prevent color banding in a wide-gamut workflow.

1. Acquire a ProPhoto RGB Profile

GIMP does not always bundle a ProPhoto RGB profile by default. Before configuring the software, you must ensure you have a valid ICC profile on your system:

  • Download a standard ProPhoto RGB (or ROMM RGB) .icc or .icm file from a reputable color management source or your camera manufacturer's software.
  • Place the file in an accessible folder or your operating system’s default color directory (e.g., C:\Windows\System32\spool\drivers\color on Windows, or /usr/share/color/icc on Linux).

2. Access GIMP’s Color Management Preferences

  1. Launch GIMP.
  2. Navigate to the preferences menu:
    • Windows/Linux: Go to Edit > Preferences.
    • macOS: Go to GIMP > Preferences.
  3. In the left-hand sidebar of the Preferences window, select Color Management.

3. Set the Default RGB Profile

  1. Ensure the Image display mode is set to Color-managed display.
  2. Locate the RGB profile dropdown under the Profiles section.
  3. Click the dropdown menu and select Select color profile from disk....
  4. Browse to the location where your ProPhoto RGB ICC profile is saved, select it, and click Open.
  5. The ProPhoto RGB profile is now assigned as your default working color space for RGB images.

4. Adjust Import Policies

Under the same Color Management tab, locate the Image profile policy:

  • Set this option to Convert to preferred RGB profile if you want GIMP to automatically convert imported images into the ProPhoto RGB space upon opening.
  • Alternatively, set it to Ask what to do if you prefer manual confirmation for each file with an embedded profile.

5. Set Default Image Precision

Because ProPhoto RGB is an exceptionally large color gamut, working in an 8-bit color depth will cause severe posterization and color banding.

  1. While still in the Preferences dialog, go to Default Image in the left sidebar.
  2. Under the Precision setting, change the default from 8-bit integer to either 16-bit floating point or 32-bit floating point.
  3. Click OK at the bottom of the Preferences dialog to save all your changes.

GIMP is now configured to create new documents in the ProPhoto RGB color space with high bit-depth precision.

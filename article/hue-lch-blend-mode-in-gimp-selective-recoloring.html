Hue LCH Blend Mode in GIMP Selective Recoloring

The Hue (LCH) blend mode in GIMP is an advanced compositing tool designed to modify the underlying color hue of an image while precisely preserving its perceived lightness and chroma (saturation). By utilizing a perceptually uniform color space, it allows editors to selectively recolor objects, clothing, or backgrounds naturally without introducing tonal clipping, artificial darkening, or loss of texture details.

How Hue (LCH) Works

The LCH color model separates an image into three distinct visual components: Lightness (perceived brightness), Chroma (saturation or color purity), and Hue (the actual color family, such as red, green, or blue).

When a layer is set to the Hue (LCH) blend mode, GIMP extracts only the Hue values from the top (active) layer and applies them directly to the bottom (target) layer. Crucially, the target layer retains 100% of its original Lightness and Chroma values.

Why Use LCH Over Standard HSV Hue

Traditional color blending in photo editing software relies on the HSV (Hue, Saturation, Value) or HSL models. These mathematical models do not account for how human eyes perceive brightness across different spectrums—for example, human vision naturally perceives pure yellow as significantly brighter than pure blue.

Using standard HSV Hue to change a blue object to yellow often causes the object to look unnaturally washed out, while changing yellow to blue creates muddy, dark artifacts. The Hue (LCH) blend mode solves this by operating in a perceptually uniform space. When you change the hue using LCH:

  • Shadows and Highlights Remain Intact: Deep shadows and bright highlights keep their exact tonal depth.
  • Textures are Preserved: Surface details, grain, and fabric weaves are not flattened by color changes.
  • No Unwanted Lightness Shifts: The recolored area maintains the correct perceived luminescence relative to the rest of the image.

Practical Workflow for Selective Recoloring

  1. Create a Recolor Layer: Add a transparent layer above your target image or duplicate the base layer.
  2. Set the Mode: Change the layer blend mode to Hue (LCH) (located under the Color category in GIMP's layer mode dropdown).
  3. Apply the New Color: Paint over the desired area using a brush set to the replacement color, or fill the entire layer with a solid color.
  4. Isolate with a Layer Mask: Add a white or black layer mask to the recolor layer, then use soft brushes or selection tools to restrict the color change precisely to the target subject.

This workflow ensures non-destructive, realistic selective recoloring that blends seamlessly with the natural lighting and shadows of the original photograph.

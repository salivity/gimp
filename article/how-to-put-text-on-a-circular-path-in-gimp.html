How to Put Text on a Circular Path in GIMP

Conforming typography to a circular vector path in GIMP allows you to create professional badges, logos, and curved headers without quality loss. This process involves drawing a circular vector path, creating your source text, mapping that text to the vector curve using GIMP's built-in alignment tools, and then rendering the resulting vector path into a solid raster layer. Following the precise steps below will ensure your text flows cleanly along the perimeter of any circle.

1. Create the Circular Path

  1. Open your project in GIMP and add guides to locate the center via Image > Guides > New Guide (by Percent) at 50% horizontal and 50% vertical.
  2. Select the Ellipse Select Tool (E). In the Tool Options, check Fixed: Aspect ratio (set to 1:1) to ensure a perfect circle.
  3. Click and drag from the center outward while holding Shift and Ctrl to draw your circle selection.
  4. Convert the selection to a vector path by clicking Select > To Path.
  5. Deselect the active marquee by clicking Select > None (Shift + Ctrl + A).
  6. Open the Paths Dialog (Windows > Dockable Dialogs > Paths) and click the eye icon next to your new path to make it visible.

2. Prepare the Typography

  1. Choose the Text Tool (T) and click anywhere on the canvas.
  2. Type your phrase, choose your font family, and adjust the font size.
  3. Adjust the kerning (letter spacing) in the Text Tool options if necessary. Keep in mind that tight text will compress on inward curves and stretch on outward curves.

3. Attach Text to the Path

  1. With your text layer selected in the Layers Dialog, right-click the layer and choose Text along Path (or navigate to Layer > Text along Path).
  2. GIMP creates a brand-new path in the shape of your curved text along the circular guide. The original text layer remains unaltered and can be hidden.

4. Correct Text Orientation and Alignment

By default, the text might appear at an undesired angle or upside down depending on path direction.

  1. Select the Rotate Tool (Shift + R).
  2. In the Tool Options, switch the Transform mode from Layer to Path (the icon resembling a vector curve).
  3. Click on the canvas and rotate the curved text path until the typography is centered at the top, bottom, or desired location. Click Rotate to confirm.

5. Render the Curved Text

Because GIMP creates the warped text as an outline vector path, you must render it into pixels to complete the design.

  1. Create a new transparent layer in the Layers Dialog and name it "Curved Text".
  2. In the Paths Dialog, ensure your rotated text path is selected.
  3. Click the Paint along the path (Stroke Path) button at the bottom of the Paths Dialog, or go to Edit > Fill Path to fill the text outlines with your current foreground color.
  4. Toggle the visibility off for all paths in the Paths Dialog to view your final, clean typography.

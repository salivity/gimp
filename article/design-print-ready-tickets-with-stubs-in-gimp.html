Design Print-Ready Tickets with Stubs in GIMP

Creating custom event tickets with perforated tear-off stubs in GIMP is a straightforward process that combines precise canvas setup, visual branding, and layout guides. This guide walks you through setting up standard print dimensions at 300 DPI, defining the stub separation boundary, drawing clear dashed perforation lines, adding essential event details and numbering zones, and exporting a high-resolution, print-ready file.

Step 1: Set Up the Canvas for Print

  1. Open GIMP and navigate to File > New.
  2. Change the measurement unit dropdown to Inches.
  3. Set the Width to 5.75 inches and the Height to 2.25 inches (this accounts for a standard 5.5" x 2" ticket with a 0.125" print bleed on all sides).
  4. Click Advanced Options and ensure both X resolution and Y resolution are set to 300.00 pixels per inch.
  5. Set the Color space to RGB color and click OK.

Step 2: Establish Layout Guides and Bleed Margins

  1. Go to Image > Guides > New Guide (by Percent).
  2. Add horizontal and vertical guides to mark your bleed margins:
    • Go to Image > Guides > New Guide..., select Horizontal, and enter 0.125 in (and repeat for the bottom margin at 2.125 in).
    • Add vertical bleed guides at 0.125 in and 5.625 in.
  3. Set the guide for the tear-off stub line:
    • Add a vertical guide where the stub should detach, typically 1.5 to 2 inches from the right edge (e.g., at 3.75 in).

Step 3: Design the Ticket Artwork

  1. Create a new layer named Background and fill it with your base color or pattern using the Bucket Fill Tool (Shift + B).
  2. Use the Text Tool (T) to place the primary event details (Event Title, Date, Time, Venue, and Price) inside the main ticket area, keeping all text safely within the 0.125-inch safe margins.
  3. Duplicate essential event details (such as the event name, date, and seat number) onto the stub section so the organizer retains relevant information after the stub is detached.
  4. Leave dedicated blank rectangular spaces on both the main body and the stub for serial numbers or barcodes.

Step 4: Draw the Tear-Off Perforation Line

  1. Create a new transparent layer and name it Perforation Line.
  2. Select the Pencil Tool (N) or Paintbrush Tool (P) and choose a basic round brush with a small pixel size (e.g., 2 to 4 pixels).
  3. Select the Paths Tool (B) and click once at the top guide mark of your stub separator, then click directly below at the bottom guide mark to create a straight vertical path.
  4. Go to Edit > Stroke Path.
  5. Select Stroke line, choose your line width (e.g., 2 px), and expand the Line Style section.
  6. Change the Dash preset to Dashes or Dots, then click Stroke.
  7. (Optional) Add a small scissor icon or the text "Tear Here" alongside the dashed line to clearly indicate the tear boundary.

Step 5: Export as a Print-Ready File

  1. Review all text and graphics to ensure nothing extends into the bleed area unless intended as background trim.
  2. Go to File > Export As....
  3. Name your file and select PDF or TIFF from the file format list to preserve print quality without lossy compression.
  4. If exporting to PDF, check Apply layer masks and ensure image quality is set to maximum.
  5. Click Export to generate the final file ready for your professional printer or home cutter.

Configure MyPaint Dry Media and Pastels in GIMP

GIMP features native integration with the MyPaint brush engine, allowing digital artists to access natural-feeling dry media like pastels, chalk, and charcoal directly inside their workflow. This guide explains how to activate the MyPaint Brush tool, navigate the brush library to find dry media presets, configure dynamics for realistic pastel blending, and import external MyPaint brush packs to expand your creative toolkit.

1. Select the MyPaint Brush Tool

To begin using the MyPaint engine in GIMP:

  1. Open your project or create a new canvas in GIMP.
  2. Select the MyPaint Brush Tool from the main Toolbox, or press the default keyboard shortcut Y.
  3. Ensure the Tool Options dockable dialog is visible (Windows > Dockable Dialogs > Tool Options) to access basic parameters like size, opacity, and hardness.

2. Open the MyPaint Brushes Dialog

Unlike standard GIMP raster brushes, MyPaint presets reside in a dedicated library window:

  1. Go to the top menu and select Windows > Dockable Dialogs > MyPaint Brushes.
  2. Dock this panel next to your standard Brush or Layer panel for easy access.
  3. In the search bar at the top or bottom of the MyPaint Brushes panel, type keywords such as pastel, chalk, charcoal, or dry.

3. Select and Test Dry Media Presets

GIMP bundles standard MyPaint brush collections, including David Revoy’s Deevad set:

  • Pastel Presets: Look for brushes named pastel, soft pastel, or oil pastel. These offer soft edge transitions and realistic texture build-up.
  • Chalk and Charcoal: Look for charcoal, chalk, or coarse. These presets mimic the rough grain of dry pigments interacting with textured paper.

Select a preset and make test strokes on a transparent or textured background layer to evaluate the behavior of the grain.

4. Configure Tool Options for Realistic Pastel Effects

Dry media heavily rely on pen pressure and stroke speed to simulate friction and pigment release. Adjust the following settings in the Tool Options panel:

  • Radius: Controls the core thickness of the stroke. Keep this moderately wide for blocking in pastel strokes.
  • Opaque: Controls the maximum paint density. Lowering this value slightly allows you to glaze and build layers gradually, mimicking physical chalk or pastel.
  • Hardness: Adjusts edge softness. Lower hardness values blend smoothly into underlying colors, while higher values create sharp, crumbly edges.
  • Pressure Sensitivity: If you are using a graphics tablet, ensure pen pressure is enabled in GIMP's Input Devices settings so that stroke opacity and radius dynamically respond to your touch.

5. Install Additional MyPaint Dry Media Brushes (Optional)

If the default presets do not have the specific dry media textures you need, you can add custom MyPaint brush packs (.myb files along with their corresponding .png previews):

  1. Download a MyPaint brush pack specifically designed for pastels or dry media.
  2. In GIMP, go to Edit > Preferences.
  3. Expand the Folders list on the left and select MyPaint Brushes.
  4. Note the user directory path listed (for example, ~/.config/GIMP/2.10/mypaint-brushes/ on Linux or %APPDATA%\GIMP\2.10\mypaint-brushes\ on Windows).
  5. Extract the downloaded .myb and .png files into this designated folder.
  6. Return to GIMP and click the Refresh button at the bottom of the MyPaint Brushes dockable dialog to load the new dry media presets.

How to Distribute Layers Vertically in GIMP

This guide explains how to arrange multiple layers along the vertical axis with consistent pixel spacing using GIMP's Align tool. By selecting target layers, defining a reference source, setting a specific pixel offset, and applying vertical distribution, you can quickly achieve precise, uniform layout alignment without manual measurement.

1. Select the Align Tool

Activate the Align tool from the Toolbox or press the shortcut key Q. You can also access it through the menu by navigating to Tools > Transform Tools > Align.

2. Choose the Reference Base

In the Tool Options dock, locate the Relative to drop-down menu. Set the reference base according to your project needs:

  • First item: Uses the first layer you click as the fixed reference point.
  • Image: Uses the overall image canvas boundaries as the reference.
  • Selection: Restricts the reference area to an active selection marquee.

3. Select the Target Layers on the Canvas

Hold down the Shift key and click each layer directly on the canvas that you want to include in the distribution. A small square handle will appear at the corners of each selected layer, confirming they are grouped for the alignment operation.

4. Set the Pixel Offset

In the Tool Options panel, find the Distribute section:

  1. Locate the Offset entry field below the distribution buttons.
  2. Enter the exact pixel value you want to place between each layer's anchor points.

5. Apply the Vertical Distribution

Click the appropriate vertical distribution button depending on how you want the anchor points aligned:

  • Distribute vertical centers: Evenly spaces the vertical center anchor points of the selected layers using the specified pixel offset.
  • Distribute top edges: Spaces the top bounding edges of each layer by the set pixel offset.
  • Distribute bottom edges: Spaces the bottom bounding edges of each layer by the set pixel offset.

Once clicked, GIMP immediately updates the layer positions on the canvas to reflect the uniform vertical offset.

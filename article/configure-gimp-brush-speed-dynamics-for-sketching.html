Configure GIMP Brush Speed Dynamics for Sketching

This guide explains how to configure custom brush dynamics in GIMP by mapping drawing speed to essential brush parameters such as size, opacity, and angle. By leveraging GIMP's Paint Dynamics Matrix and Dynamics Curves, artists can simulate the responsive feel of traditional charcoal and ink, enabling fluid, expressive gesture sketching that reacts naturally to the velocity of hand movements.

1. Create a New Paint Dynamic

To avoid altering default presets, create a dedicated dynamics profile for gesture sketching:

  1. Open GIMP and navigate to Windows > Dockable Dialogs > Paint Dynamics.
  2. Click the Create a new dynamics icon (the blank page symbol) at the bottom of the Paint Dynamics dialog.
  3. Name your new preset (e.g., Gesture Sketching Speed). The Paint Dynamics Editor dialog will open automatically.

2. Map Speed to Brush Behaviors in the Matrix

In the Paint Dynamics Editor, locate the Speed column in the mapping matrix. Check the following boxes to establish gesture-responsive behavior:

  • Speed to Size: Check this box to alter line thickness based on stroke speed. By default, faster strokes create thinner lines, which mimics lifting a pen during rapid flicking motions.
  • Speed to Opacity: Check this box so quick construction strokes remain faint and transparent, while slower, deliberate contour strokes appear darker and more opaque.
  • Speed to Force or Flow (Optional): Check this box if using textured brushes (like chalk or pencil) to deposit less pigment during swift sweeps across the canvas.

3. Fine-Tune the Dynamic Curves

The checkbox matrix provides a linear response, which can feel abrupt during fast hand movements. Adjust the response curves to make the dynamic feel natural:

  1. In the Paint Dynamics Editor, select the Dynamics Properties tab or click on the specific mapped property (e.g., Size or Opacity) from the curve dropdown menu.
  2. Ensure the active dynamic input is set to Velocity (Speed).
  3. Adjust the curve graph:
    • For Tapering (Thin on Fast Strokes): Pull the curve downward on the right side of the graph. A slight concave curve produces smooth, gradual tapering instead of an immediate drop-off.
    • For Expanding (Thick on Fast Strokes): Invert the curve so that lower speeds register at the bottom left and higher speeds rise toward the top right.
    • For Soft Construction Lines: Create a steep exponential curve under Opacity so opacity stays below 30% until your stroke slows significantly.

4. Optimize Tool Options for Gesture Drawing

Apply your new dynamics profile to the Paintbrush or MyPaint Brush tool and adjust brush behavior:

  1. Select the Paintbrush Tool (P).
  2. In the Tool Options panel, set Dynamics to your newly created preset.
  3. Lower Brush Spacing to between 1.0% and 5.0% in the Brush settings to prevent visible stepping or stuttering during high-speed strokes.
  4. Disable Smooth Stroke (stabilization) or keep its weight low (around 10–20) to prevent latency from smoothing out your quick hand gestures.

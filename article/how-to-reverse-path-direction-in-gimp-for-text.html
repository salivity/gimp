How to Reverse Path Direction in GIMP for Text

When applying text along a vector path in GIMP, characters follow the direction in which the path nodes were originally drawn, often leaving the text upside down or reading backward. While GIMP does not feature a dedicated one-click "reverse path" button, you can reverse the direction and orientation of a path by using the Flip Tool set to Path mode. This guide explains how to flip your path's vector trajectory so your linked text reads correctly.

Step 1: Open the Paths Dialog and Select the Path

  1. Open the Paths dialog dock (go to Windows > Dockable Dialogs > Paths if it is not visible).
  2. Click on the path you want to modify to make it active.
  3. Toggle the eye icon next to the path to make it visible on your canvas.

Step 2: Configure the Flip Tool for Paths

  1. Select the Flip Tool from the Toolbox, or press Shift + P (or Shift + F, depending on your GIMP version shortcuts).
  2. Look at the Tool Options panel (usually located beneath the Toolbox).
  3. Under the Transform section at the top of the Tool Options, click the Path icon (the red vector curve with nodes). This ensures the tool affects the vector path rather than the active layer or selection.
  4. Set the Direction to Horizontal or Vertical depending on your layout:
    • For open lines or curves: Flipping horizontally reverses the start and end nodes, which inverts the direction the text flows.
    • For circles and circular arches: Flipping vertically will flip the orientation from outside the curve to inside (or top to bottom).

Step 3: Flip the Path

  1. Click anywhere on the path in the canvas window.
  2. GIMP will immediately reverse the coordinate order and orientation of the path's anchor points.

Step 4: Re-align the Path (For Symmetrical Shapes)

If you are placing text at the bottom of a circle or badge:

  1. Flipping the circle vertically inverts the text orientation, but it also mirrors the position of the curve.
  2. Select the Flip Tool again, change the direction to Horizontal, and click the path once more.
  3. Alternatively, switch the Rotate Tool to Path mode and rotate the circle 180 degrees to return the anchor points to the bottom while maintaining the reversed path direction.

Step 5: Reapply Text Along Path

  1. Select your text layer in the Layers dialog.
  2. In the top menu, click Layer > Text along Path (or right-click the text layer and choose Text along Path).
  3. The new text path will generate along the reversed vector, oriented right-side up.
  4. Go to the Paths dialog, select the newly generated text path, and fill or stroke it on a new transparent layer using Edit > Fill Path or Edit > Stroke Path.

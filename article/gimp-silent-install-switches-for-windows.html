GIMP Silent Install Switches for Windows

This guide provides a comprehensive overview of the command-line switches used for silent and unattended installations of GIMP on Microsoft Windows. Because the official GIMP Windows installer is built using Inno Setup, administrators can use standard Inno Setup parameters to automate deployment across managed environments without user interaction.

Primary Silent Installation Switches

The official GIMP installer (gimp-x.xx.x-setup.exe) supports several command-line arguments to control the user interface and installation behavior:

  • /SILENT: Runs the installer without prompting the user for input. The installation wizard window and a progress bar are still visible on the screen.
  • /VERYSILENT: Runs the installer completely in the background. No installation window or progress bar is displayed to the user.
  • /SUPPRESSMSGBOXES: Automatically dismisses message boxes that might halt an automated script. When used with /SILENT or /VERYSILENT, this option accepts default choices for all prompts.
  • /NORESTART: Prevents the installer from restarting the computer automatically if a reboot is required to complete the setup.
  • /SP-: Skips the initial "This will install..." prompt at the beginning of the setup wizard.

Configuration and Customization Switches

To customize the installation path, permissions, and logging, the following switches are available:

  • /ALLUSERS: Instructs the installer to perform a machine-wide installation for all users on the system (requires administrative privileges).
  • /CURRENTUSER: Limits the installation to the profile of the user currently executing the command.
  • /DIR="C:\Path\To\Target": Overrides the default installation directory. Ensure the path is enclosed in double quotes if it contains spaces.
  • /LOG="C:\Path\To\install.log": Generates a detailed plain-text log file tracking the installation process, which is useful for troubleshooting failed deployments.

Example Commands

For a completely silent, machine-wide installation with logging and no automatic reboot, run the following command in an elevated Command Prompt or deployment tool:

gimp-2.10.36-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /ALLUSERS /LOG="C:\Temp\gimp_install.log"

To silently install GIMP to a custom directory:

gimp-2.10.36-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="C:\Program Files\Graphics\GIMP"

Uninstallation

GIMP can also be removed silently by targeting the uninstaller created in the program's installation directory:

"C:\Program Files\GIMP 2\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

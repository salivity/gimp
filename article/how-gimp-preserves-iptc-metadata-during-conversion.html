How GIMP Preserves IPTC Metadata During Conversion

This article explains how the GNU Image Manipulation Program (GIMP) retains IPTC copyright, creator, and licensing metadata when converting images between different file formats. You will learn how GIMP processes embedded metadata through its underlying libraries, how to manage and verify your rights information, and the exact export settings required to prevent licensing data from being stripped during conversion.

Metadata Handling Architecture in GIMP

GIMP manages metadata using the gexiv2 library, a GObject-based wrapper around the industry-standard Exiv2 metadata library. When an image containing IPTC (International Press Telecommunications Council) data is opened, GIMP reads and maps the legacy IPTC-IIM blocks alongside Exif and modern XMP (Extensible Metadata Platform) schemas.

Because modern IPTC standards (such as the IPTC Core and IPTC Extension) are natively structured as XMP packets, GIMP synchronizes these fields internally. This ensures that essential rights expressions—such as Creator/Artist, Copyright Notice, Copyright Status, and Web Statement of Rights (Licensing URL)—remain intact in memory during editing and processing.

Viewing and Editing IPTC Metadata

Before exporting or converting a file, you can verify and adjust metadata fields directly within the editor:

  1. Go to Image > Metadata > Edit Metadata.
  2. Navigate to the IPTC tab to view traditional fields such as By-line (Creator), Copyright Notice, and Credit.
  3. Navigate to the XMP or Rights sections to view modernized licensing terms, including specific copyright URLs or creative commons licensing declarations.
  4. Make any necessary additions or corrections, then click Write Metadata to apply the changes to the active project session.

Preserving Metadata During File Export

GIMP does not use a traditional "Save As" function for changing image extensions; instead, it uses the Export workflow. File conversion occurs when you save an image into a new format via File > Export As....

To ensure IPTC, creator, and licensing metadata are written to the converted file:

  1. Select your target format (e.g., JPEG, TIFF, or WebP) and click Export.
  2. In the format-specific export dialog that appears, click to expand the Advanced Options section (if it is collapsed).
  3. Ensure the following checkboxes are enabled:
    • Save Exif data
    • Save XMP data
    • Save IPTC data (available for formats supporting legacy IPTC-IIM)
    • Save thumbnail (optional, does not impact legal metadata)
  4. Complete the process by clicking Export.

If these options are unchecked, GIMP will strip the metadata to reduce file size, completely removing all licensing and copyright assertions.

Format-Specific Considerations

The ability to preserve IPTC and licensing metadata depends significantly on the destination file container:

  • JPEG and TIFF: Provide the highest level of compatibility. GIMP embeds both legacy IPTC-IIM blocks and modern XMP packets containing the IPTC Core schema into these formats.
  • WebP: Fully supports XMP data. GIMP encapsulates IPTC metadata within WebP's native XMP chunk during export.
  • PNG: GIMP can write XMP metadata into standard text chunks (eXmp / iTXt). However, legacy IPTC-IIM is not natively supported in PNG, so rights data is maintained exclusively via the embedded XMP wrapper.
  • GIF and BMP: These formats have minimal to no standard support for IPTC or XMP data. Converting to these legacy formats will result in the loss of embedded copyright information.

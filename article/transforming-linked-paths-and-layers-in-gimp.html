Transforming Linked Paths and Layers in GIMP

In GIMP, connecting assets using the chain link icon allows users to apply simultaneous modifications across different project elements. When a vector path is linked to a layer, any transformation applied to that layer—such as scaling, rotating, moving, shearing, or perspective shifting—automatically applies the exact same geometric changes to the path. This mechanism ensures that the alignment, proportions, and spatial relationship between your raster artwork and vector outlines remain synchronized without requiring manual realignment.

The Behavior of Linked Paths During Transformation

When the chain link icon is toggled on for both an active layer and a vector path in their respective dialogs (Layers dialog and Paths dialog), GIMP treats them as a single transform group.

Applying any transformation tool to the layer yields the following results on the linked path:

  • Move: Shifting the layer across the canvas moves the vector path by the identical coordinate offset.
  • Scale: Resizing the layer scales the vector path proportionally. The path’s anchor points and control handles recalculate relative to the transform origin.
  • Rotate: Rotating the layer spins the vector path around the chosen center of rotation by the exact same angle.
  • Shear and Perspective: Distorting the layer shifts the path's anchor nodes to match the altered perspective grid.
  • Flip: Horizontally or vertically flipping the layer mirrors the vector path along the same axis.

Preservation of Vector Quality

A critical aspect of this process is that the vector path does not get rasterized. While standard pixel layers might lose quality or experience interpolation artifacts when scaled or rotated repeatedly, linked vector paths retain their mathematical definitions. GIMP recalculates the coordinates of the Bézier curves and anchor points directly, meaning the resulting path remains crisp, fully editable, and infinitely scalable after the transformation is confirmed.

Contrast with Unlinked Paths

If the chain link icon is inactive on the path, transforming the layer will leave the path entirely unaffected. The path will remain in its original position, size, and orientation on the canvas, which can break the alignment between line art, selection outlines, and painted layers. To prevent accidental edits or desynchronization, the link toggle can be turned on or off at any time via the Paths dialog.
